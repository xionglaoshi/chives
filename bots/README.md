# Chives Bot 名册

[投资专家](http://127.0.0.1:8888/#/bot/expert)是默认入口。每个岗位的能力、委派对象和定时任务由本目录的清单定义。

| 岗位 | 分工 |
|---|---|
| [投资专家](expert/bot.yaml) | Chives 的默认入口，接住用户的问题并分派给合适的 bot，同时负责盯盘、持仓诊断与模拟盘演练。 |
| [个股分析师](equity-analyst/bot.yaml) | 对单只或一组 A 股做财报、估值、盈利预期、评级与交易方案的深度分析。 |
| [研究员](research/bot.yaml) | 回答一个具体研究问题，做政策、行业、公司事件与事实的检索和交叉核对。 |
| [主升浪](zhushenglang/bot.yaml) | 只按主升浪策略引擎的结果，汇报首板观察池与主升浪阶段池的每日变化与复核要点。 |
| [报告员](report-builder/bot.yaml) | 把已完成的分析组装成可交付的报告、图表与文档，不改数字、不生产新结论。 |
