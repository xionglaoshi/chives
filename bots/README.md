# Chives Bot 名册

[总调度](operator/bot.yaml)（`operator`）是唯一常驻岗位，默认接待提问及工作台「问AI」的附件和提示词。它可亲自处理任务，也可向已聘用成员委派。用户负责创建、移除、聘用和解聘其他成员。

每个岗位在 `bots/<id>/bot.yaml` 定义身份和职责。维护者在系统部署岗位，用户可在终端「聘用管理」或网页「Bot市场」聘用与解聘。总调度的初始资产包括所有已登记技能和研究工具，用户可在档案中逐项调整。

总调度可分段读取本地文档，在个人文档、下载、桌面、已有的 WPS 文档库及自己的工作区保存文本，也可读写共享用户 Wiki。部署者可用 `CHIVES_OPERATOR_DOCUMENT_DIRS` 增加文档目录（系统路径分隔符分隔）。本地数据库工具列出并只读查询 Chives 的数据及运行目录中的 SQLite 库。修改用户属性使用专用写入工具，记录旧值、新值、证据、理由和任务号。名册和程序文件由用户维护。
