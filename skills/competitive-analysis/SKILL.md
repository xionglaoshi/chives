# A 股竞争格局与护城河（competitive-analysis）

产品是一张**真正的比较**：同一报告期、同一指标定义、同一口径，每个数字带来源与日期。口径不同的数字放在一起，看起来像分析，其实不是。

证据标签、来源分层、新鲜度与就绪姿态遵循 `research-conventions`。相对估值细节交 `comps-analysis`，行业全景交 `sector-overview`，个股结论交 `stock-analysis`。定位轴见 `references/frameworks.md`，单位经济性见 `references/unit-economics.md`，补充表格见 `references/schemas.md`，交付格式见 `references/presentation.md`。

## 边界

- 只做研究，不下单、不给仓位、不写买入名单。
- 每个同行指标带 `as-of` 与一个证据标签；没有日期的数字不进表。
- 份额、客户数、TAM 这类公司自述标 `company claim`；第三方测算标 `street estimate` 并写机构与年份。
- 取不到写 `not disclosed` 并说明查过什么；承重指标缺失时，要么删掉依赖它的结论，要么给区间并标 `assumption`。

## 第 1 步：定问题与指标

先写一句话：这张表要回答什么（份额变化、盈利质量、估值差异、谁在抢谁的市场）。指标由这句话推出。

A 股常用行业指标：

| 行业 | 3–5 个核心指标 |
|---|---|
| 白酒/食品 | 批价、渠道库存、吨价、合同负债、销售费用率 |
| 新能源车/锂电 | 销量/装机、单位盈利（元/Wh）、产能利用率、海外占比 |
| 光伏/风电 | 组件/风机价格、开工率、库存、海外出货 |
| 半导体 | 稼动率、库存周转、资本开支、国产替代收入 |
| 医药 | 集采放量、创新药收入、销售费用率、研发资本化 |
| 银行 | 净息差、不良率、拨备覆盖、核心资本 |
| 券商 | 经纪市占、两融余额、投行储备、自营收益 |
| 家电 | 内外销、均价、渠道库存、原材料成本 |
| 军工 | 合同负债、交付节奏、关联交易占比、回款 |
| 地产 | 销售、拿地、去化周期、短债缺口 |

指标一旦选定，**所有同行用同一套**；某家不披露就写 `not disclosed`，不换指标。

## 第 2 步：建同行集合

- 主体行业/概念：`company_profile(code)` 取三级行业与概念板块。
- 行业/概念排行与成分：`market_sectors(kind="industry"/"concept", sort, limit)`；给 `code` 取成分。`code` 只能来自排行结果（`BKxxxx`、`new_*`、`gn_*`）。
- 指数成分：`company_profile(index="沪深300", limit=500)`；行业指数成分以板块成分为主。
- 逐一核对主业：概念板块里的“蹭概念”公司要剔除，并写明剔除理由；同行 5–10 家，太多则分层（龙头/二线/跨界）。
- 分类口径差异看 `basis`；两套分类不混用。

**完成判据**：同行名单、纳入理由、剔除理由、数据日期齐全；没有用记忆补名单。

## 第 3 步：统一口径

| 项 | 要求 |
|---|---|
| 报告期 | 同一报告期；例外在单元格标 `(2026Q3)` vs `(2026H1)` |
| 指标定义 | 毛利率是否含运费、扣非是否剔除政府补助、销量是台还是 GWh，写一次全表统一 |
| 单位 | 金额元或亿元二选一；比例百分数；每股元 |
| 估值 | PE TTM / PB MRQ / EV-EBITDA 标清；亏损公司 PE 写 `n/a`，不用负值 |
| 价格日期 | 同一交易日；用 `market_quote` 的 `quote_time` 或 `market_bars` 日期 |
| 数据来源 | 每个数字写工具/公告与日期；同一指标全表只取一个来源 |

**完成判据**：口径说明写在表前；没有同一张表混用两个报告期或两种估值口径。

## 第 4 步：比较表

### 规模与盈利

| 公司 | 代码 | 营收（亿元） | 营收增速 | 归母（亿元） | 扣非增速 | 毛利率 | ROE | 经营现金流/净利润 | 报告期 |
|---|---|---|---|---|---|---|---|---|---|

数据来自 `company_financials`；增速用同一口径；经营现金流/净利润 < 0.7 要标红并写原因。

### 份额与经营

| 公司 | 核心指标 1 | 核心指标 2 | 核心指标 3 | 份额 | 口径/来源 | as-of |
|---|---|---|---|---|---|---|

份额没有公开数据时写 `not disclosed`，不用“约”编；可以给“按披露口径推算的上限/下限”并标 `assumption`。

### 估值

| 公司 | 股价 | 总市值 | PE TTM | PB MRQ | PS TTM | 分位（3 年） | 数据时间 |
|---|---|---|---|---|---|---|---|

`company_valuation(scope="stock")` 一次一只；分位缺失写 `null` 及原因。行业对照单列，注明静态 PE 口径。

### 图形（可选）

- 2×2 定位图：两个真正决定竞争胜负的轴（成本 vs 差异化、聚焦 vs 全品类），不要用“品牌力 vs 技术力”这类无法量化的轴。
- 份额趋势堆叠图；价格-毛利率散点。
- 数据落 `data/`，图落 `charts/`，图注写来源与日期。

**完成判据**：三张表都完成或有明确缺口；每个数字有来源与日期；图形（若有）可追溯到数据。

## 第 5 步：护城河评估

一行一种护城河，**观察与判断分列**：

| 护城河 | 观察到的证据 | 评级 | 为什么这证据支持评级 | 反证/削弱因素 |
|---|---|---|---|---|
| 网络效应 | 用户/商户双边数据、跨边增长 | 强/中/弱 | 一句 | |
| 转换成本 | 认证/切换周期、续约率、嵌入流程 | | | |
| 规模经济 | 单位成本随产量下降、最小有效规模 | | | |
| 无形资产 | 品牌溢价、专利/牌照、数据/配方 | | | |
| 成本优势 | 资源禀赋、一体化、区位 | | | |

评级是 `judgement`，必须和观察分列；观察栏空着却给“强”，就是意见不是分析。

再写三件事：可持续的优势（对应上面哪行）、结构性脆弱点（难修复的）、当前状态与趋势的背离（份额在升但毛利在降，等等）。

## 第 6 步：结论与反证

- **谁在赢、靠什么、能否持续**：一段话，引用表中数字。
- **反证**：至少两条与结论相反的可观察证据（份额、价格、毛利、客户流失、政策）。
- **失效条件**：什么数据出现会推翻结论，写成阈值或日期。
- **情景（如用于投资语境）**：乐观/基准/悲观，各写驱动与概率；概率要么加总为 1，要么标“illustrative”不给加权。

**完成判据**：结论引用具体行；反证与失效条件可观察；没有把“行业第一”直接等同“护城河强”。

## 输出与自检

Markdown 交付，路径遵守 T149（`reports/<主题>/`）。结构：问题 → 同行集合 → 口径 → 比较表 → 护城河 → 结论/反证/失效条件 → 来源与缺口。

- [ ] 同行集合有纳入/剔除理由。
- [ ] 同一报告期、同一指标定义、同一估值口径。
- [ ] 每个数字有来源与日期；缺失写 `not disclosed` 并说明查过什么。
- [ ] 护城河观察与评级分列。
- [ ] 至少两条反证与可观察的失效条件。
- [ ] 没有评级、目标价、仓位建议（这些交 `trade-pitch`/`risk-boundary`）。
