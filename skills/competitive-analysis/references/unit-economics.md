# 单位经济性（competitive-analysis 参考）

当竞争集合的胜负由“单店/单客户/单产品赚不赚钱”决定时，用单位经济性比较。**同一套定义用于每一家**：拿 A 的净留存比 B 的毛留存，不是比较。

A 股披露很少直接给 CAC/LTV，多数要推导；推导值标 `model-derived`，把输入列在旁边，不冒充披露值。

## 通用指标

| 指标 | 定义 | A 股取数 |
|---|---|---|
| 单店收入 | 门店收入 / 期末门店数（或加权门店数） | 年报“门店数量”与分渠道收入 |
| 单店毛利 | 门店毛利 / 门店数 | 分渠道成本 |
| 坪效 | 收入 / 营业面积 | 年报/官网；没有就写 `not disclosed` |
| 单客户收入（ARPU） | 收入 / 付费客户数 | 运营商、软件、教育等披露客户数时 |
| 客户获取成本（CAC） | 销售费用 / 新增客户数 | 新增客户数常不披露，缺就写 `not disclosed` |
| 客户生命周期价值（LTV） | ARPU × 毛利率 / 流失率 | 流失率不披露时不给 LTV |
| CAC 回收期 | CAC /（ARPU × 毛利率）× 12 个月 | 推导值标 `model-derived` |
| 单位盈利 | 净利润或毛利 / 销量（元/台、元/Wh、元/吨） | 制造类核心指标 |
| 产能利用率 | 实际产量 / 设计产能 | 年报/公告 |
| 库存周转天数 | 平均存货 / 营业成本 × 365 | `company_financials` |
| 应收周转天数 | 平均应收 / 营收 × 365 | 同上 |

## 阈值只作提示

订阅/连锁类可参考：CAC 回收期 < 12 个月较好，> 24 个月偏弱；净留存 > 110% 较好，< 100% 需解释；单店收入连续两季下滑是警示。**这些不是 A 股统一标准**，用的时候写“参考区间，非行业标准”。

制造类看：单位盈利与产能利用率的组合——利用率升、单位盈利降，通常是价格战；利用率降、单位盈利升，可能是产品结构改善或成本滞后。

## 常见陷阱

- **门店/客户数口径**：期末数、平均数、加盟/直营混算，会让单店收入差出一大截。
- **销售费用包含品牌广告**：CAC 被高估；要说明口径。
- **用毛利率代替贡献毛利**：漏掉履约、渠道、售后成本。
- **跨报告期比较**：半年报单店收入与年报不可直接比。
- **把推导值当披露值**：必须标 `model-derived` 并给输入。

以上为研究框架，不构成投资建议。
