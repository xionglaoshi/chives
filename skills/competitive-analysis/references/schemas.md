# 补充表格格式（competitive-analysis 参考）

## 并购/交易表

| 买方 | 标的 | 公告日 | 交易对价（亿元） | 估值倍数 | 支付方式 | 战略逻辑 | 来源 |
|---|---|---|---|---|---|---|---|

倍数必须写口径（EV/营收、EV/EBITDA、PE）；亏损标的写 `n/a`。A 股交易要查 `company_announcements` 原文，不用媒体转述。

## 情景表

| 情景 | 概率 | 关键假设 | 对份额/毛利的影响 | 可观察验证点 |
|---|---|---|---|---|
| 乐观 | | 具体、可量化 | | 日期 + 指标 |
| 基准 | | | | |
| 悲观 | | | | |

概率要么互斥且加总为 1，要么标“illustrative”，不给加权值。

## 竞争事件表

| 日期 | 公司 | 事件 | 类型（降价/扩产/并购/政策） | 对谁有影响 | 影响机制 | 来源 |
|---|---|---|---|---|---|---|

“影响机制”必须写到份额、价格、成本或客户，不写“加剧竞争”。

## 护城河记分卡

| 护城河 | 观察 | 评级 | 支持理由 | 削弱因素 | 下一次验证 |
|---|---|---|---|---|---|

观察栏空着就不评级；评级是 `judgement`，与观察分列。

以上为研究框架，不构成投资建议。
