# 交付与呈现（competitive-analysis 参考）

交付默认 Markdown，不再要求 deck/PPT；需要图表时用 matplotlib 生成 PNG，路径遵守 T149。

## 文档结构

1. 一句话结论 + 3 个关键数字。
2. 问题与同行集合（纳入/剔除理由）。
3. 口径说明（报告期、定义、单位、估值口径）。
4. 规模与盈利表。
5. 份额与经营指标表。
6. 估值表。
7. 护城河记分卡。
8. 结论、反证、失效条件。
9. 来源与缺口。

## 表格排版

- 一张表只回答一个问题；列数控制在 10 列内，超出拆表。
- 数字右对齐；单位写在列头或表注，不重复在每个单元格。
- 缺失用 `not disclosed`，不用 `-`、`0` 或空白。
- 判断性列（评级、结论）用文字，不用色块代替。

## 图

- 定位矩阵：轴带单位与年份，点用简称标注；分区线标“作者判断”。
- 份额趋势：堆叠面积/柱状，标口径（收入/销量）。
- 估值散点：PE 或 PB 对增速/ROE，标异常点与原因。
- 图注：来源、口径、数据截止日；颜色只表达一个含义。

## 交给自己/别人的边界

- 需要目标价、买卖建议 → `trade-pitch`。
- 需要行业全景、政策链 → `sector-overview`。
- 需要单只股票的完整结论 → `stock-analysis`。
- 需要正式排版/多图长文 → `report-generate`。

以上为研究框架，不构成投资建议。
