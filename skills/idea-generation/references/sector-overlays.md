# A 股行业估值基准与筛选陷阱

`idea-generation` 的展开参考。候选跨行业、或某个筛选指标异常好看时读。

一条总规则：**单一倍数跨行业排名，排的是会计口径，不是生意**。行业内部用本行业的估值基准；跨行业只比“ROIC 对资金成本”或“自由现金流收益率”，并写明再投资需求。

## 银行

- **基准**：PB 配 ROE；PE 用正常化信用成本后的利润。
- **不适用的通用指标**：EV/EBITDA、PS。银行的“收入”是利差与手续费，企业价值没有意义。
- **陷阱**：不良率与拨备覆盖率同时“改善”但逾期贷款在升；利润靠拨备释放；净息差被高收益资产短期撑住；再融资摊薄。
- **A 股补充**：关注资本充足率、拨备覆盖率、关注类贷款迁徙；分红率与核心一级资本充足率要一起看。

## 券商与保险

- **券商基准**：PB 配 ROE，成交额与两融余额是周期变量；PE 在成交低迷期失真。
- **保险基准**：PEV / PB 配 ROE，PE 用正常化投资收益与准备金假设。
- **陷阱**：券商利润靠自营投资收益、经纪业务市占率下滑；保险新业务价值增速与代理人数量背离；准备金假设调整改变利润。
- **A 股补充**：券商合并预期会推高估值，但没有落地时间表时只是预期；保险的权益仓位放大利润波动。

## 房地产与建筑

- **基准**：NAV 折价、PB、合同销售与结转毛利率；建筑看订单/收入与应收周转。
- **不适用**：PE，因为结算周期与减值让当期利润失真。
- **陷阱**：存货跌价准备不足；合作项目出表；预售资金监管；应收账款与合同资产减值；地方财政回款。
- **A 股补充**：三道红线、保交楼、城投应收；重组与壳价值容易让 PB 失真。

## 白酒与食品饮料

- **基准**：PE 配预收款/合同负债与批价；PEG 只在增长稳定时用；现金流收益率。
- **陷阱**：渠道压货导致预收款与收入背离；批价下跌先于报表；销售费用率下降被当成效率提升；提价带来的一次性囤货。
- **A 股补充**：关注合同负债、经销商数量、批价（公开渠道，标来源与日期）、大股东减持。

## 医药与医疗器械

- **基准**：PE/PEG 配研发管线与商业化品种；创新药看管线折现（概率需来源），器械看医院覆盖与集采。
- **陷阱**：集采降价幅度超预期；研发资本化比例上升；销售费用合规风险；单一品种依赖；商誉减值。
- **A 股补充**：集采、医保谈判、DRG/DIP 支付改革是估值变量；中药看提价与渠道库存。

## 半导体与电子

- **基准**：PB 或 PS 配周期位置；设计公司看 PS/净利润弹性，制造看 PB/折旧；设备看订单与验收。
- **不适用**：用当期 PE 判断周期顶底，PE 在盈利低点最高。
- **陷阱**：库存周期被当成需求复苏；政府补助与研发加计扣除推高利润；大客户集中；资本开支高峰后的折旧压力。
- **A 股补充**：国产替代叙事容易给出高 PS；关注存货周转、合同负债、产能利用率。

## 新能源与电力设备

- **基准**：PE 配产能利用率与单位盈利；周期底部用 PB 或 EV/装机；储能/光伏看现金流与应收。
- **陷阱**：产能过剩导致价格战；应收账款与票据；海外贸易壁垒；补贴退坡；一体化降本被高估。
- **A 股补充**：产业链价格（硅料、锂盐、组件）是先行变量，标来源与日期；关注在建工程与固定资产周转。

## 周期（煤炭、有色、化工、钢铁）

- **基准**：PB 配 ROE 的周期中枢；EV/EBITDA 用中周期价格；资源品看储量与成本曲线。
- **陷阱**：现货高价被当成永续；资本开支高峰在利润高点；库存跌价；环保与安全限产。
- **A 股补充**：长协价与现货价、吨毛利、库存天数；高股息率要检查分红可持续性与资本开支。

## 公用事业与交运

- **基准**：PE 配允许收益率与资本开支；股息率配分红覆盖率；交运看 EV/EBITDA 或 PB。
- **陷阱**：资本开支被当成成长；电价/水价/运价管制；折旧政策变化；负债率上升。
- **A 股补充**：高股息策略下，分红率与自由现金流的匹配比股息率本身重要。

## 汽车与零部件

- **基准**：PE 配销量与单车盈利；零部件看客户结构、毛利率与产能利用率。
- **陷阱**：价格战导致单车盈利下滑；新能源补贴与积分收入；大客户依赖；海外建厂的一次性费用。
- **A 股补充**：月度销量是高频变量（标来源与日期）；关注应收账款与存货周转。

## 家电与消费

- **基准**：PE 配ROE 与分红率；渠道库存与终端零售是先行指标。
- **陷阱**：以旧换新补贴透支需求；原材料成本下行被当成永久；出口汇率与关税；渠道库存高企。
- **A 股补充**：地产链相关性；关注合同负债、销售费用率、分红率。

## 计算机与传媒

- **基准**：PS 配收入增速与现金流；订阅型看续费率；传媒看内容储备与广告周期。
- **陷阱**：研发资本化；项目制收入确认；商誉；政策监管；题材炒作推高估值但无利润。
- **A 股补充**：信创、AI 等主题要用订单/收入验证，不能用“签约/合作”公告替代收入。

## 跨行业比较的唯一允许方式

- 用 ROIC（或 ROE）对资金成本，配合再投资率与增长，比较“赚钱效率”，不比较 PE 绝对值。
- 用自由现金流收益率，并写明资本开支是维护性还是扩张性。
- 任何跨行业排名都要写“行业估值基准不同，排名仅作研究排序，不是买卖建议”。
