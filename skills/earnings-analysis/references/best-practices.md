# 质量门槛与失败模式（A 股版）

`earnings-analysis` 的交付前检查。三层按顺序跑：硬失败一票否决，交付清单查完整性，判断门问“这份点评值不值得读”。

## 第一层：硬失败

任一条命中就退回重写。这些都是读者看不出来、也救不回来的错误。

- 面向读者的数字没有可定位引用：只有公告名、没有页码/表名/章节，或只有工具名、没有报告期。
- 跨口径比较没有标签：归母对扣非、合并对母公司、营业收入对营业总收入、累计对单季、本币对美元。
- 把业绩预告、快报或互动易问答当成经审计的正式报表数字。
- 把卖方一致预期写成“公司预期”或“市场必然”。
- 文档里留下占位符：XX、TBD、模板括号、图表编号存在但图未嵌入。
- 两个小节对同一事件写了不同报告期。
- 预期为零、接近零或为负时仍计算“超预期百分比”。
- 引用评级或目标价却不写机构与日期，或把旧目标价说成“维持”。
- 把估值分位直接写成“低估/高估”或买卖结论。

## 第二层：交付清单

**分析**
- [ ] 第一句给出结论：超预告上限、落在区间、低于下限或无预告，并带数字。
- [ ] 归母与扣非都写了；差额超过营收增速能解释的范围时做了扣非质量桥。
- [ ] 2–3 个承重驱动，每个写清“什么变了、为什么、对下一期意味着什么”。
- [ ] 现金流结论是“印证”或“背离”，并点名科目与报告期。
- [ ] 预告/快报/一致预期三者的缺失状态分别写清，没有用一个替代另一个。
- [ ] 盈利预测更新到当年与下一年，旧值、新值、变化、理由齐全。
- [ ] 结论框四行都填了；多空对照两侧都有反证与验证时间。
- [ ] 每个投资逻辑支柱都有状态。

**来源**
- [ ] 每个数字、表格、引文都有“公告 + 页码/表名”或“工具 + 报告期/抓取时间”。
- [ ] 一致预期写了覆盖机构数、年份、抓取时间与“卖方预测汇总，不是事实”。
- [ ] 两源不一致时两个值都列，说明了差异与口径，没有取平均。
- [ ] 缺席数据用了四个词之一：未发布、未披露、未提供、取不到。
- [ ] 评级与目标价带机构与日期；研报只读标题时明确“未读正文”。
- [ ] 公告链接可打开；打不开的写“链接失效”，不把它当已验证。

**构建**
- [ ] 深度点评在 6–10 页、3–5 张表、2–4 张图；短模式按自己的合同检查。
- [ ] 每张图有编号、标题、来源与单位，且与相邻表格同单位。
- [ ] 报表数字与原文一致；每个推算值能从原始数重算。
- [ ] 报告期、代码、公司名前后一致；`A`/`E` 标记统一。
- [ ] 公告后 48 小时内交付，超时在文首说明。

## 第三层：判断门

过了前两层但读起来没用的稿子，卡在这里。逐条回答：

1. **变了什么？** 说的是“和上期/预告/预期相比哪里不同”，不是按时间顺序复述报告。
2. **影响什么？** 读者能指出一个被改动的预测、一个被强化的逻辑支柱，或一个被排除的风险。
3. **利润是真的吗？** 区分可重复与不可重复部分，预测调整跟着这个拆分走。
4. **反方在哪？** 最强反方观点被完整写出，再用“更弱/更晚/已计入/它成立”之一回答；成立就改结论。
5. **下一个验证点有日期吗？** 每个未决问题都指向真实报告期、公告日或可观察指标。

## 失败模式

| 失败 | 长什么样 | 修法 |
|---|---|---|
| 混口径 | 归母增速对扣非预期，或累计值对单季值 | 先统一口径，表头写清归母/扣非、累计/单季 |
| 把一次性收益当经营改善 | 政府补助、资产处置、投资收益推高利润，预测按表观利润上调 | 用扣非桥拆分，预测只跟可重复部分走 |
| 预告当正式报告 | 用预告区间中值代替实际值，或把快报当审计数 | 实际值只取正式报告；快报标“未经审计” |
| 预期对空 | 对零或负预期算百分比超预期 | 只给绝对差并说明百分比不可用 |
| 编指引 | 把“稳健增长”翻译成 3–5% 并喂进模型 | 保持定性；模型输入标“假设”并写敏感性 |
| 引语截断 | 互动易或说明会的一句话被截半，意思反转 | 引完整分句，带问答日期与问题 |
| 综述无结论 | 每个指标都讲了，没有结论、预测或反证 | 按判断门重写，围绕“变了什么”组织 |
| 行业套话 | “受益于行业景气”放在任何公司都成立 | 换成只对这家公司成立的那个数字 |

## 标题

标题就是结论，带数字与动作。

**好**
- “2026Q3：扣非只增 3%，利润落在预告上半段靠政府补助”
- “2026H1：毛利率回升 180bp，全年预测上调 4%”
- “2026Q3：收入低于预告下限，下调全年盈利预测 7%”

**差**
- “三季度业绩点评”——只有主题。
- “业绩表现良好”——形容词代替数字。
- “公司发布三季报”——对任何公司都成立。

## 交付消息

短，不重复正文：

```
[公司] 2026Q3 财报点评

结论：落在预告区间上半段 / 扣非同比 +3.0%
  营收 1,234.5 亿元（同比 +8.1%）；归母 210.3 亿元；扣非 205.1 亿元
预测：2026E 归母 268 亿元，前值 262 亿元；2027E 292 亿元，前值 285 亿元
评级/目标价：维持“增持”，目标价 1,850 元（中金，2026-10-26）；未自行设定
下一个验证点：2026 年年报预约披露日（company_earnings(kind="schedule")）
数据截至：2026-10-28 收盘；一致预期抓取于 2026-10-28
缺口：研报正文未读；分部数据仅来自年报原文
```
