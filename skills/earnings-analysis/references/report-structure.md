# A 股财报点评报告结构

`earnings-analysis` 的写作参考。按页组织 6–10 页深度点评；一页速评把同样的顺序压缩到一屏。所有页码、数字与引用规则见 `SKILL.md` 的“质量门槛”。

## 页面地图

| 页 | 内容 |
|---|---|
| 1 | 结论框、投资影响、更新后的盈利预测 |
| 2–3 | 业绩拆解：收入、利润率、扣非质量 |
| 4–5 | 经营数据、分部、现金流质量 |
| 6–7 | 多空对照、投资逻辑影响、预告与指引 |
| 8–9 | 估值、评级与目标价 |
| 10 | 附录（可选）：季度明细、公告清单 |

## 第 1 页：结论先行

页眉块：公司、代码、报告期、公告日、当前评级与方向（维持/上调/下调）、股价与时间、目标价（旧 → 新，若无则写“未给出”）。

结论框固定四行，不再加别的：

| 行 | 写什么 |
|---|---|
| 本期结论 | 超预告上限 / 落在区间 / 低于下限 / 无预告，一句话带数字 |
| 投资逻辑 | 强化、减弱、不变或混合，一句话给理由 |
| 盈利预测 | 下一期与全年方向、幅度、落地时间 |
| 下一个验证点 | 有日期的报告期、股东大会或公告事件；没有就写“无已排期事件”，并给可观察指标 |

### 三行对照表

```
2026 年三季报：归母净利润落在预告区间上半段

                    实际        预告区间       一致预期      差异
营业收入            1,234.5亿    —             1,210.0亿     +2.0%
归母净利润          210.3亿      200–215亿      208.0亿       落在区间
扣非归母净利润      205.1亿      未发布         无覆盖        仅列实际
```

表下必须有两行：一行是公告名 + 页码；一行是一致预期的数据时间、覆盖机构数与口径差异，并写“卖方预测汇总，不是事实”。

### 投资影响

3–4 条，每条先给结论再给证据，**以数字开头**：

```
- **归母净利润落在预告上半段，但扣非增速只有 3%，差额主要来自政府补助**

  归母净利润 210.3 亿元，落在 200–215 亿元预告区间的上半段；扣非归母 205.1 亿元，
  同比 +3.0%，低于营收的 +8.1%。非经常性损益合计 5.2 亿元，其中政府补助 3.8 亿元
  （2026 年三季度报告，第 58 页，“非经常性损益项目”）。把这部分剔除后，本期的
  经营改善幅度小于表观利润。
```

### 更新后的预测表

当年与下一年各一行，列：旧预测、新预测、变化、依据（一句话）。比率行用 bp，金额行用百分比；理由写在正文，不塞进表格。

## 第 2–3 页：业绩拆解

**收入**：实际对预告、对一致预期（若有）的差异，再拆产品/地区/渠道；给出最近 4–6 个报告期的单季趋势，列同比与环比。单季值来自累计值相减时，在表注写明公式。

**利润率**：毛利率、净利率、扣非净利率、ROE（加权）同窗口，逐项用 bp 表示变化；把“价格、成本、结构、并表、政府补助”分开写，不能只给一个“盈利能力提升”。

### 扣非质量桥

只要表观利润与扣非利润的差距超过营收增速能解释的范围，就做这张桥：

| 步骤 | 金额（亿元） | 来源与处理 |
|---|---|---|
| 归母净利润 | 210.3 | 三季报，第 12 页，合并利润表 |
| 非经常性损益合计 | −5.2 | 逐项列示：政府补助 3.8、资产处置 0.9、其他 0.5；来源第 58 页 |
| 所得税影响 | +0.6 | 按 15% 优惠税率还原，写明假设 |
| 扣非归母净利润 | 205.1 | 与报表“扣除非经常性损益”行核对 |

桥接后的结论写一句：本期利润里有多少能重复，多少不能。差距不大时写“未发现重大非经常性项目”，不复制整张桥。

## 第 4–5 页：经营数据、分部与现金

**经营数据**：这家公司真正被定价的 3–5 个指标，四个报告期宽；公司停止披露的指标保留行，写“未披露”。

**分部**：来自年报/半年报“主营业务分行业、分产品、分地区情况”，列收入、占比、毛利率、同比。分部之和与合并报表不一致时，写“分部间抵销/其他”口径。

**现金流**：经营现金流净额、资本开支、收现比、应收与存货变动，同窗口；一句话结论“现金印证利润”或“现金与利润背离”，背离点名科目。

## 第 6–7 页：多空对照与投资逻辑

### 多空对照

| 方向 | 一句话论点 | 本期什么变了 | 反证（可观察） | 何时验证 |
|---|---|---|---|---|
| 多 | | | | |
| 空 | | | | |

反证必须是一个可观察的数字或事件，带阈值；验证时间必须是真实报告期或公告日，不能编日期。看空一侧要写到最强，再给结论：更弱、更晚、已计入价格，或它成立（此时改结论）。

### 投资逻辑影响

每个支柱一段：原判断、本期状态（强化/不变/减弱）、150–200 字证据。本期没有信息量的支柱只写一行“不变”，不凑字数。

### 预告与指引

A 股多数公司不提供量化指引，只给业绩预告或经营讨论。有预告就桥接“本期实际 vs 预告区间”，并写下一期是否有预告、预约披露日；没有就明确“公司未提供量化指引”，不用卖方预测冒充公司指引。任何只出现在互动易或业绩说明会问答里的说法，标“问答口径，未经公告确认”。

## 第 8–9 页：估值、评级与目标价

- 当前 PE TTM、PB、市值与各自分位（窗口、样本数、剔除项）。
- 行业静态 PE 对照，表头写“行业口径为静态 PE，与个股 TTM 不同”。
- 评级与目标价：机构、日期、旧值/新值；没有新目标价就写“未给出”，不用旧目标价暗示维持。
- 若按人设规则给评级或目标价区间，必须写方法、假设、敏感性区间与失效条件；不写主观概率。

## 第 10 页：附录（可选）

季度明细、公告与报告清单（标题、日期、页码/链接）、一致预期原始行、指数与行业对照表。附录只放支撑正文的内容，不放新结论。

## 格式

- 图表标题在图上方，来源与口径在图下方；单位与相邻表格一致。
- 表格给来源行；同一张表只用一种币种与一种单位（元或亿元）。
- 期间标记统一：`2026Q3A`、`2026Q4E`；报告期同时写 `2026-09-30`。
- 小节标题写结论，不写主题：“利润落在预告上半段，扣非只增 3%”优于“利润分析”。
- 公告引用写成“公告名 + 页码 + 表名”；链接只作为补充，不能代替页码。

## 引用示例

```
归母净利润 210.3 亿元，落在 200–215 亿元预告区间的上半段。
  实际值：2026 年三季度报告，第 12 页，“合并利润表”。[链接]
  预告区间：2026 年前三季度业绩预告，2026-10-15，第 1 页，“本期业绩预计情况”。[链接]

2026E EPS 一致预期 16.64 元，覆盖 18 家机构，抓取于 2026-10-28。
  数据时间：company_consensus；主口径与另一套口径均值 16.71 元不一致，两者都列，不取平均。
  卖方预测汇总，不是事实。

经营现金流净额 180.2 亿元，低于归母净利润 30.1 亿元。

```
