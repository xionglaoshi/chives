# 开盘前的研究便笺

写给今天开盘前只有一分钟的读者。页首用北京时间标出截稿时刻和对应的 A 股交易日。从上一交易日收盘到现在，有哪一件事足以改变原有判断？如果没有，就写当前最值得核实的变化。保持只读；作战卡、计划更新和仓位操作交给另一个任务，晨报不调用 hub 工具。已有简报长度要求时遵从该要求。

- **先排时间。** 用可用的 `market_global` 等行情工具列美股、港股或 A50 合约的实际报价、涨跌幅、当地日期、时区和市场状态。休市市场沿用上次收盘需写出日期，期货夜盘与美股现货分行。没有实时值就写缺数。
- **公告比标题多核一步。** 检索隔夜披露、预告与修订，优先看与用户已授权的自选范围有关的事项。链接到公告原件，注明金额、单位和期间。媒体快讯放在单独一行，数字未经公告确认时标为待核。
- **把今天与昨天分开。** 今天列披露时间、解禁、停复牌和已知财经日程，时刻待定就写待定。昨天只用上一完整交易日的指数、涨跌家数、成交额或行业表现作为参照。假日简报列出下一交易日和仍可能发布的公告。
- **留两个观察点。** 例如「若订单利好已经反映在股价，开盘后看同业是否同步放量」；同时写清要看的时间窗口、证据以及什么情形下放弃这条解释。避免把隔夜海外走势直接外推为今天的个股涨跌。

正文先给一句判断，接着按时间列三到五条证据，最后列观察点和来源。时区、价格口径或公告时间容易混淆时，宁可少放一个数字。
