# 第 3 步：估值分析——详细流程

本文给出 `initiating-coverage` 第 3 步（估值分析）的分步做法。

## 步骤概览

**目的**：用 DCF、可比公司与可比交易做完整估值。

**前置输入**：⚠️ 开工前验证
- **必需**：第 2 步的财务模型
  - 预测利润表
  - 预测现金流量表
  - 收入与 EBITDA 预测
  - DCF 输入（无杠杆自由现金流）

**⚠️ 关键：第 2 步未完成，不得开始本步**

本步依赖第 2 步的模型。没有模型就开工，只会得到残篇。

**第 2 步未完成时**：立即停下，告知用户必须先完成第 2 步（财务建模）。不要用占位估值硬推。

**输出**：估值分析（4–6 页等效，约 1,400–2,100 字）+ 估值 CSV
- DCF 分析与敏感性表
- 可比公司分析
- 可比交易（如适用）
- 估值足球场
- 目标价与评级

## 分步估值流程

### 第 1 步：从模型取数

**从第 2 步的模型取：**

1. **预测财务（5 年）**
   - 逐年收入（2026E–2030E）
   - 逐年 EBITDA
   - 逐年 EBIT
   - 税率
   - 逐年折旧摊销
   - 逐年资本开支
   - 逐年营运资本变化

2. **无杠杆自由现金流**
   ```
   从模型的 DCF 输入分区取：

                    2026E   2027E   2028E   2029E   2030E
   EBIT            XXX     XXX     XXX     XXX     XXX
   ×（1 − 税率）
   = NOPAT         XXX     XXX     XXX     XXX     XXX
   + 折旧摊销      XXX     XXX     XXX     XXX     XXX
   − 资本开支      (XX)    (XX)    (XX)    (XX)    (XX)
   − 营运资本增加  (XX)    (XX)    (XX)    (XX)    (XX)
   = 无杠杆 FCF    XXX     XXX     XXX     XXX     XXX
   ```

3. **资产负债表数据（当前）**
   - 有息负债合计（短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券 + 租赁负债）
   - 货币资金 + 交易性金融资产
   - 净负债（有息负债 − 货币资金）
   - 少数股东权益
   - 稀释股本

4. **情景数据**
   - 乐观情景收入 CAGR 与永续利润率
   - 基准情景收入 CAGR 与永续利润率
   - 悲观情景收入 CAGR 与永续利润率

### 第 2 步：建 DCF

#### A. 计算 WACC

**1. 确定无风险利率**
   - 用 10 年期中国国债到期收益率
   - 从中国债券信息网或财政部公开数据用 `web_fetch` 取，旁边写抓取日期；不要用美国国债利率替代

**2. 确定股权成本（CAPM）**
   ```
   股权成本 = 无风险利率 + Beta × 股权风险溢价

   输入：
   - 无风险利率：[10 年期国债收益率，带 as-of 日期]
   - Beta：[用 `market_bars` 的个股与沪深 300 日收益率做回归，样本 2–3 年；或取可比公司 Beta 中位数；历史太短时写明]
   - 股权风险溢价：[公开的 ERP 序列，用 web_fetch 取；序列没有观测日期时，以抓取日期为 as-of 并标注]

   示例：
   股权成本 = 1.8% + 1.10 × 6.0% = 8.4%
   ```

**3. 确定债务成本**
   ```
   债务成本 = 当前借款利率或债券到期收益率

   没有交易债券时：
   债务成本 = 无风险利率 + 信用利差（按主体评级）

   示例：
   税前债务成本 = 4.0%
   税后债务成本 = 4.0% × (1 − 15%) = 3.4%
   ```

**4. 确定资本结构**
   ```
   用市值，不用账面值：

   股权市值（E）= 股价 × 总股本
   债务市值（D）= 有息负债（债券不交易时用账面值）
   总价值（V）= E + D

   股权权重 = E / V
   债务权重 = D / V

   示例：
   E = 500 亿元（90.9%）
   D = 50 亿元（9.1%）
   V = 550 亿元（100%）
   ```

**5. 计算 WACC**
   ```
   WACC =（E/V × 股权成本）+（D/V × 债务成本 ×（1 − 税率））

   示例：
   WACC =（90.9% × 8.4%）+（9.1% × 4.0% ×（1 − 15%））
   WACC = 7.64% + 0.31% = 7.95%

   基准情形取整：8.0%
   ```

#### B. 计算永续价值

**方法 1：永续增长（优先）**
```
永续价值 = FCF(2030) × (1 + g) / (WACC − g)

其中：
- FCF(2030) = 模型最后一年无杠杆 FCF
- g = 永续增长率（通常 1.5–3.0%）
  - 不应超过长期名义 GDP 增速
  - 基准情形用 2.5%

示例：
FCF(2030) = 50 亿元
g = 2.5%
WACC = 8.0%

永续价值 = 50 × 1.025 / (0.08 − 0.025)
永续价值 = 51.25 / 0.055 = 931.8 亿元
```

**方法 2：退出倍数（备选）**
```
永续价值 = EBITDA(2030) × 退出倍数

其中：
- 退出倍数 = 当前可比公司交易倍数中位数（如 10–14 倍 EBITDA）

示例：
EBITDA(2030) = 80 亿元
退出倍数 = 12 倍

永续价值 = 80 × 12 = 960 亿元
```

**选一种，或两种取平均并说明。**

#### C. 折现到现值

```
预测期 FCF 现值 = Σ [FCFt / (1 + WACC)^t]，t = 1 到 5

示例：
年份    FCF      折现因子              现值
       （亿元）
2026    25       1/(1.08)^1 = 0.9259  23.1
2027    32       1/(1.08)^2 = 0.8573  27.4
2028    39       1/(1.08)^3 = 0.7938  31.0
2029    45       1/(1.08)^4 = 0.7350  33.1
2030    50       1/(1.08)^5 = 0.6806  34.0
                             合计：   148.6

永续价值现值 = 931.8 / (1.08)^5 = 931.8 × 0.6806 = 634.2 亿元

企业价值 = 148.6 + 634.2 = 782.8 亿元
```

#### D. 企业价值到股权价值

```
企业价值                         782.8 亿元
− 净负债（有息负债 − 现金）       (20.0 亿元)
+ 非经营性资产                    0.0 亿元
− 少数股东权益                    (5.0 亿元)
− 永续债/优先股                   0.0 亿元
= 股权价值                        757.8 亿元

稀释股本                          50.0 亿股

每股价值 = 757.8 / 50.0 = 15.16 元

当前股价：14.00 元
隐含上行：8.3%
```

### 第 3 步：可比公司分析

#### A. 选择可比公司

**选择标准：**
- 同行业/同板块（首要）
- 相似商业模式
- 规模可比（市值、收入）
- 增长特征相似
- 地域相似

**确定 5–10 家可比公司：**
1. [对手 1] - 直接竞争者
2. [对手 2] - 直接竞争者
3. [对手 3] - 邻近玩家
4. [对手 4] - 相似商业模式
5. [对手 5] - 区域竞争者
6. [再加 3–5 家]

**逐个写明选择理由。** 同行集合来自 `market_sectors` 的行业/概念成分、`company_profile` 的行业分类，不能只挑公司自己列的对手。

#### B. 取可比公司财务

**每家可比公司取：**
- 当前股价（`market_quote`，记录 `quote_time`）
- 总股本与流通股本（稀释）
- 总市值与流通市值
- 有息负债与货币资金（算 EV）
- 企业价值
- LTM（最近十二个月）财务：
  - 营业收入
  - EBITDA
  - EBIT
  - 归母净利润
- NTM（未来十二个月）一致预期
- 营收增速
- EBITDA 利润率

**数据来源**，按层级（`research-conventions/references/evidence.md`）：
- A 股三表用 `company_financials`；行情用 `market_quote`、`market_bars`；估值分位用 `company_valuation`。每个倍数自己算，并写明推导
- 前瞻收入与 EPS 用 `company_consensus`（写明机构数、抓取日期）；A 股一致预期覆盖不全时，NTM 列写 `n/a`，或用有日期的公开卖方数据并写来源
- 前瞻 EBITDA 与前瞻净利润通常没有一致预期，EV/EBITDA（NTM）在无来源时写 `n/a`；P/E（NTM）用股价除以 NTM EPS，绝不用市值除以推算净利润
- 可比公司自己的定期报告用 `company_announcements` / `company_reports` 取，已披露实际数优先于任何调整序列

#### C. 计算估值倍数

**每家可比公司算：**
```
EV/营业收入（LTM）= 企业价值 / LTM 营业收入
EV/营业收入（NTM）= 企业价值 / NTM 营业收入（预测）
EV/EBITDA（LTM）= 企业价值 / LTM EBITDA
EV/EBITDA（NTM）= 企业价值 / NTM EBITDA（预测）
P/E（NTM）= 股价 / NTM EPS（预测）
```

#### E. 把倍数套到目标公司

**选主倍数（成熟公司通常用 EV/EBITDA）：**

```
目标公司 NTM EBITDA = 55 亿元（来自模型）

套中位数：
可比公司 EV/EBITDA（NTM）中位数 = 13.8 倍
隐含 EV = 55 × 13.8 = 759 亿元

套 25 分位（保守）：
25 分位 = 12.5 倍
隐含 EV = 55 × 12.5 = 687.5 亿元

套 75 分位（乐观）：
75 分位 = 14.1 倍
隐含 EV = 55 × 14.1 = 775.5 亿元

估值区间（可比）：687.5 – 775.5 亿元
中点：731.5 亿元

转为股权价值：
隐含 EV（中位数）        759.0 亿元
− 净负债                 (20.0 亿元)
− 少数股东权益           (5.0 亿元)
= 隐含股权价值           734.0 亿元

稀释股本                 50.0 亿股
隐含每股价值             14.68 元
```

**说明溢价/折价：**
- 目标收入增速 17% vs 可比中位数 17% → 持平
- 目标 EBITDA 利润率 23% vs 可比中位数 23% → 持平
- 目标市场位置 → [说明溢价/折价理由]
- **结论**：套中位数，不做调整；或写明调整幅度与依据

### 第 4 步：可比交易（可选）

**注意**：只在本行业/本公司并购相关时做。

#### A. 找相关交易

**找 5–10 笔并购：**
- 同行业，最近 3–5 年
- 规模相近（目标的 0.5–2 倍）
- 已公告且完成的交易

#### B. 套到目标公司

```
目标公司 LTM EBITDA = 50 亿元
可比交易 EV/EBITDA（LTM）中位数 = 15.8 倍

隐含 EV（可比交易）= 50 × 15.8 = 790 亿元

注：可比交易倍数通常比二级市场可比高 10–20%，

```

#### B. 权重理由

**常见权重：**
- DCF：40–60%（预测可靠时更高）
- 可比公司：25–40%（反映市场定价）
- 可比交易：10–25%（除非并购很可能发生，否则更低）

**本例：**
- DCF 50%：对预测信心较高
- 可比 40%：可比公司样本充分
- 可比交易 10%：短期并购可能性低

   - 潜在 20 亿元增量收入

5. 潜在并购标的（12–18 个月）
   - 对更大产业方有战略价值
   - 可比交易显示 30–40% 溢价

## 质量标准

### DCF 质量检查
- [ ] WACC 计算正确，组成部分有文档
- [ ] 永续价值合理（低于企业价值的 70%）
- [ ] 敏感性覆盖现实区间（WACC ±200–300bp，永续增长 ±100bp）
- [ ] 无杠杆 FCF 从 EBIT 正确计算
- [ ] 企业价值到股权价值桥正确
- [ ] 股本用稀释股本，不用基本股本

### 可比公司质量检查
- [ ] 选了 5–10 家可比公司
- [ ] 选择可辩护（逐个写明为什么选它）
- [ ] 含统计摘要（最大值/75 分位/中位数/25 分位/最小值）——必须
- [ ] 倍数选择合适（成熟公司 EV/EBITDA，高增长 EV/营收）
- [ ] 溢价/折价有具体理由
- [ ] 数据来源规范，日期已注明

### 整体估值质量检查
- [ ] 至少用 2 种方法（DCF + 可比为底线）
- [ ] 权重有解释且合适
- [ ] 给区间（低/基准/高），不是单点
- [ ] 情景分析（乐观/基准/悲观）
- [ ] 做了合理性检查（见下）
- [ ] 全部假设有文档与理由

## 合理性检查

**每次都要做：**

1. **历史倍数检查**
   - 隐含倍数是否在公司历史交易区间内？
   - 不在的话，解释为什么

2. **可比公司检查**
   - 相对同行的溢价/折价是否有基本面支撑？
   - 检查增长、利润率、市场位置

3. **隐含增长检查**
   - 当前价格隐含了什么增长？
   - 按公司轨迹是否合理？

4. **市值合理性**
   - 总市值与公司规模、同行相比是否说得通？
   - 相对行业会不会太大/太小？

5. **永续价值检查**
   - 永续价值是否低于企业价值的 60–70%？
   - 高于 70%，说明预测期可能不够长

6. **WACC 合理性**
   - 一般公司 WACC 是否在 7–12%？
   - 高增长/科技：9–13%
   - 成熟稳定：6–9%

7. **隐含回报检查**
   - 从现价到目标价的 12 个月 IRR 是多少？
   - 与评级是否一致？

## 成功判据

成功的估值分析应：
1. 至少用 2 种方法（DCF + 可比为底线）
2. 含完整 DCF 敏感性分析（双向表）
3. 可比公司含统计摘要（最大值/75 分位/中位数/25 分位/最小值）
4. 给估值区间（低/基准/高），不是单点
5. 全部关键假设有文档与清晰理由
6. 做了合理性检查
7. 得到可辩护的目标价
8. 只印一个评级：买入、持有或回避，与动作动词并列
9. 识别 3–5 个关键催化
10. 识别 3–5 个关键风险
11. 可审计、透明
