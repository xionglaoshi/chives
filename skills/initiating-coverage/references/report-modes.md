# 覆盖模式

`initiating-coverage` 的延后参考。第 0 步、进入第 1 步前加载；第 5 步对某节篇幅或内容有疑问时再加载。

一份首次覆盖只服务一个读者、一种决策。模式固定报告必须写什么、砍什么、论证用什么语气。选一个、写下来，五个步骤全程不变。用户没说时，从请求推断，并在交付说明里写明这是推断。

| 模式 | 读者与决策 | 多写 | 少写 |
|---|---|---|---|
| 公开发布型 | 第一次看到这家公司的广泛客户 | 完整的公司描述、行业入门、完整披露与方法说明 | 投机的差异化观点、仓位层面的具体判断 |
| 买方可疑深挖 | 判断要不要继续投入研究的分析师 | 分歧、证伪条件、与市场不同的认知、反证 | 公司历史、模板化行业描述、管理层履历 |
| 长期复利型 | 持有数年的投资者 | 资本回报的持续性、再投资空间、资本配置记录、治理 | 单季近况、交易结构 |
| 交易导向型 | 持有期较短的组合 | 带日期的催化路径、筹码位置、已定价了什么、表达方式与退出 | 长期市场空间、十年预测 |
| 杠杆资本结构型 | 站在大额债务或租赁之后的股东 | 完整的融资增长闸门、到期结构、契约空间、融资后回报 | 忽略资本结构的倍数 |
| 行业首发型 | 一次认识整个行业的读者 | 行业结构、利润池在哪、公司间排序逻辑 | 排序不需要的单公司深度 |
| 模型优先型 | 先看数字与驱动因子的读者 | 驱动结构、假设辩护、情景机制、敏感性 | 叙述性章节、竞争故事 |
| 更新型 | 已经熟悉这家公司的读者 | 上次之后变了什么，对预测与目标价的影响 | 已确认且未变的一切 |

## 模式改变什么

- **必备章节。** 买方可疑深挖花四页写公司历史，就是把篇幅花给了错误的读者；公开发布型跳过行业入门，读者就看不懂论点。
- **字数花在哪。** 10,000 字下限靠模式认定为核心的那几节达到，见 `assets/quality-checklist.md`。
- **语气。** 公开发布型中性、完整；买方可疑深挖直接、对自己的论点保持敌意；交易导向型把日期与价位写具体。
- **封面。** 模式与证据置信度、可承保状态并排出现在封面，读者一眼知道手里是什么文件。

## 初步覆盖与观察名单

任何模式都可以不发完整首次覆盖，而发**初步覆盖**或**观察名单**。这不是缩水版：当证据支持分析、但不支持承保时，它就是正确输出；要主动选择，而不是写不完才降级。

- **初步覆盖**：分析是真的，但一个承重输入拿不到，最常见的是资本结构、前瞻预测，或估值需要的分部披露。点名缺的输入、它卡住的结论，不出版目标价。
- **观察名单**：分析完整，结论是“还不是时候”。写明触发条件、价位或有日期的事件、以及届时怎么做。

两者都在封面标注，并以编号列表写出承保前必须补的具体证据；都不含编造的目标价，也都不靠语气放软来升级。
