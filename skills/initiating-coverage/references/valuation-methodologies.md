# 股票研究估值方法

`initiating-coverage` 的延后参考。第 3 步选方法、给资本密集型或依赖外部融资的生意估值、搭目标价桥时加载。DCF、可比公司与可比交易的机制见下文各节。

## 选方法

方法选择是论证，不是默认项；每种方法都带一条保留事项，输出出现在哪里，保留事项就跟到哪里。使用该方法的小节要写，任何重复该数字的摘要也要写。

| 方法 | 适用条件 | 随输出同行的保留事项 |
|---|---|---|
| DCF | 现金流可预测、资本结构稳定 | 永续价值占总价值的比例、折现率构建、敏感性区间 |
| 可比公司 | 五家以上真正可比、口径能对齐的同行 | 同行集合质量与年化口径：每家公司的 LTM/NTM 各由哪四个季度构成，按 `research-conventions/references/market-data-rules.md` |
| 分部估值 | 各分部单独披露且单独有价值 | 分部披露质量、总部费用分摊、分部间漏损 |
| 可比交易 | 该资产类别有活跃交易市场、交易较近 | 交易年份、控制权溢价、每个倍数里隐含的协同 |
| 账面价值/资产法 | 资产有盯市价格且价格有意义 | 盯市可靠性、各类资产减值充分性，逐类说明 |
| 事件驱动 | 价值取决于有日期的二元结果 | 概率与时间假设，须与收益分开列示 |
| 收入倍数 | 见可比公司下的降级规则 | 当重大债务、租赁或摊薄落在比较之外时，它只是初步市场参照，不是估值支撑 |

## 现金流折现（DCF）

### 概览

DCF 按未来预测现金流的现值给公司估值。它被认为理论上最扎实，因为基于基本面价值创造。

### DCF 分步流程

#### 1. 历史财务分析
- 取 3–5 年历史财务
- 算历史 FCF = EBIT ×（1 − 税率）+ 折旧摊销 − 资本开支 − 营运资本增加
- 分析历史增速与利润率
- 识别趋势与周期性

#### 2. 建收入预测（5–10 年）
**路径：**
- **自上而下**：市场空间（TAM）→ 市场份额 → 收入
- **自下而上**：销量 × 单价
- **混合**：多个驱动结合

**关键考虑：**
- 管理层指引与历史增速
- 行业增速与市场趋势
- 竞争动态与份额演变
- 产品管线与新市场机会
- 宏观因素

#### 3. 预测经营费用
- **营业成本**：占收入比（分析历史毛利率）
- **销售/管理费用**：半固定，按占收入比建模并体现规模效应
- **研发费用**：科技/医药关键，按占收入比建模
- **折旧摊销**：基于资本开支假设

**算 EBIT** = 营业收入 − 营业成本 − 期间费用

#### 4. 算无杠杆自由现金流
```
EBIT
×（1 − 税率）
= NOPAT（税后经营利润）
+ 折旧摊销
− 资本开支
− 净营运资本增加
= 无杠杆自由现金流（UFCF）
```

**资本开支假设：**
- 维持性资本开支：维持当前经营所需（通常占收入 2–4%）
- 增长性资本开支：扩张所需
- 参考行业基准与公司指引

**净营运资本：**
- NWC =（应收账款 + 存货）− 应付账款
- 按占收入比或周转天数（DSO、DIO、DPO）建模
- NWC 增加是现金占用

#### 5. 确定永续价值

**方法 A：永续增长**
```
永续价值 = FCF(最后一年) × (1 + g) / (WACC − g)
```
- g = 永续增长率（通常 1.5–3%，不超过名义 GDP 增速）
- 适用于已进入稳定成熟增长的公司

**方法 B：退出倍数**
```
永续价值 = EBITDA(最后一年) × 退出倍数
```
- 退出倍数基于当前可比公司交易倍数
- 周期性行业更适用

#### 6. 计算加权平均资本成本（WACC）

```
WACC =（E/V × 股权成本）+（D/V × 债务成本 ×（1 − 税率））
```

**股权成本（CAPM）：**
```
股权成本 = 无风险利率 + Beta × 股权风险溢价
```
- 无风险利率：10 年期中国国债到期收益率
- Beta：个股收益率对市场指数回归（或用可比公司 Beta）
- 股权风险溢价：用 `web_fetch` 取公开 ERP 序列，旁边写抓取日期；序列没有观测日期时，写明这一点

**债务成本：**
```
债务成本 = 无风险利率 + 信用利差
```
- 用公司当前借款利率或债券隐含收益率
- 无存续债券时按主体评级调整

**资本结构：**
- E/V = 股权市值 / 总价值
- D/V = 债务市值 / 总价值
- 用目标资本结构，不用当前结构（两者差异大时）

#### 7. 折现到现值

```
PV = Σ [FCFt / (1 + WACC)^t] + [永续价值 / (1 + WACC)^n]
```

#### 8. 算企业价值与股权价值

```
企业价值 = 预测期 FCF 现值 + 永续价值现值
− 净负债（有息负债 − 货币资金）
+ 非经营性资产
− 少数股东权益
− 永续债/优先股
= 股权价值

每股价值 = 股权价值 / 稀释股本
```

### DCF 敏感性分析

关键变量必须做敏感性：

1. **双向敏感性表**：WACC vs 永续增长率
2. **收入增长情景**：基准/乐观/悲观
3. **利润率假设**：经营杠杆情景
4. **永续倍数敏感性**：用退出倍数法时

**示例敏感性表：**
```
           永续增长率
WACC      2.0%    2.5%    3.0%
6.0%      17.2    18.1    19.2
7.0%      15.3    16.1    16.9
8.0%      13.8    14.4    15.1
```

### DCF 常见陷阱

1. **增长重复计算**：不要只预测高增长而不配相应投入（资本开支、营运资本）
2. **永续增长不现实**：不应超过长期 GDP 增速
3. **忽略周期性**：周期行业要正常化盈利
4. **现金流定义错误**：用无杠杆 FCF，不用净利润
5. **假设不一致**：折现率与现金流匹配（无杠杆 FCF → WACC）

## 可比公司分析

### 概览

可比公司按公开市场对相似公司的定价来估值。它反映当前市场情绪与相对估值。

### 可比公司分步流程

#### 1. 选择可比公司

**选择标准：**
- 同行业/同板块（首要）
- 相似商业模式与收入来源
- 规模可比（市值、收入）
- 增长特征与利润率相似
- 终端市场与地域相似

**典型池子：**
- 从 8–15 家开始
- 剔除特殊情况公司
- 最终保留 5–10 家

#### 2. 收集财务信息

**需要的数据：**
- 当前股价与总股本
- 最新年度财务报告
- NTM 预测：未来四个季度一致预期均值之和，按 `research-conventions/references/market-data-rules.md`
- 历史增速

**算市场指标：**
- 总市值 = 股价 × 总股本
- 企业价值 = 总市值 + 有息负债 + 少数股东权益 + 优先股 − 货币资金
- 净负债 = 有息负债 − 货币资金

#### 3. 计算估值倍数

**企业价值倍数：**
- **EV/营业收入**：适合早期/高增长公司
- **EV/EBITDA**：最常用；适合资本密集型
- **EV/EBIT**：折旧摊销差异大时有用

**股权价值倍数：**
- **P/E**：最常用
- **P/B**：适合金融机构
- **P/S**：未盈利公司用

**分别计算：**
- LTM（最近十二个月）——历史
- NTM（未来十二个月）——前瞻（优先）

#### 4. 分析与选择倍数

**建可比公司表：**

| 公司 | 总市值 | EV/营收 | EV/EBITDA | EV/EBIT | P/E（NTM） | 营收增速 | EBITDA 利润率 |
|---|---|---|---|---|---|---|---|
| 对手 A | 100 亿 | 3.5 | 12.0 | 18.0 | 22.0 | 15% | 28% |
| 对手 B | 80 亿 | 3.0 | 10.5 | 16.0 | 19.0 | 12% | 27% |
| …… | …… | …… | …… | …… | …… | …… | …… |
| 中位数 | - | **3.2** | **11.0** | **17.0** | **20.5** | 13% | 27.5% |

**调整：**
- 剔除异常值（通常 >2 个标准差）
- 优先用中位数，不用均值（受异常值影响小）
- 部分可比更可比时可加权
- 按增长、利润率、风险差异调整

#### 5. 把倍数套到目标公司

**示例计算：**
```
目标公司 NTM EBITDA = 50 亿元
选定 EV/EBITDA 倍数 = 11.0
隐含企业价值 = 50 × 11.0 = 550 亿元

− 净负债 = 20 亿元
股权价值 = 530 亿元

稀释股本 = 50 亿股
隐含每股价值 = 10.60 元
```

#### 6. 选择合适倍数

**按公司类型：**
- **EV/营业收入**：高增长、未盈利（科技、生物医药早期）
- **EV/EBITDA**：最常用；资本密集型（制造、公用事业）
- **P/E**：盈利、资本结构稳定的公司（消费、零售）
- **行业专属**：银行用 P/B，石油用 EV/产量，传媒用 EV/用户

### 收入倍数降级规则

股权价值/收入倍数只给收入定价，忽略收入到股东之间的所有东西。当重大债务、资本化租赁、潜在摊薄或客户预付款支撑的扩张落在比较之外时，收入倍数只是**初步市场参照**：在标题、表格和任何重复它的摘要里这样标注，不放进足球场，也不让目标价建立在它上面。

当比较转到含租赁的企业价值、按完全稀释股本、同行同口径计算时，它才成为估值支撑。

### P/E 目标的 EPS 口径

P/E 目标是倍数乘以利润，所以利润数字需要和倍数一样的辩护。

- 经常性损益扭曲时，用扣非/经营性 EPS，并展示从报表 EPS 到它的桥。
- 仍用报表 EPS 时，说明为什么它适合这家公司。
- 用调整后数字时，引用调节表，逐项说明哪些接受、哪些拒绝、哪些未证实。股份支付是雇人的经常性成本；剔除它是需要声明的决定，不能从公司演示材料里默认继承。
- 同一张表的同行倍数用同一口径，否则表里要写明哪家用了哪种口径。

### 溢价/折价分析

按以下因素给溢价或折价：
- **增长溢价**：增长更高 → 倍数更高
- **盈利能力**：利润率更高 → 倍数更高
- **规模**：大公司通常有流动性溢价
- **市场位置**：龙头 → 溢价
- **地域**：成熟 vs 新兴市场

## 可比交易分析

### 概览

可比交易按并购中为相似公司支付的价格来估值。它反映控制权溢价与战略价值。

### 分步流程

#### 1. 找相关交易

**选择标准：**
- 同行业或相近行业
- 规模相近（目标的 0.5–2 倍）
- 业务特征相似
- 交易较近（优先最近 3–5 年）
- 已公告且完成（避开撤回交易）

**典型池子：**
- 至少 5–10 笔
- 偏重近期交易

#### 2. 收集交易细节

**需要的信息：**
- 交易日期（公告与完成）
- 收购价格与支付结构（现金、股份、混合）
- 目标公司交易时点的财务
- 战略理由与协同
- 支付的控制权溢价

**来源：**
- 公司公告（重大资产重组报告书、收购报告书、权益变动报告）
- 交易双方公告与投资者材料
- 交易所披露与财经媒体，用 `web_fetch` 打开原文
- A 股交易样本少或披露不全时，写明“样本不足，不作结论”，不硬凑

#### 3. 计算交易倍数

**与可比公司同样的倍数，但基于交易价值：**

```
交易价值 = 股权收购价 + 承接债务 − 取得现金

EV/营业收入（LTM）= 交易价值 / 目标 LTM 营业收入
EV/EBITDA（LTM）= 交易价值 / 目标 LTM EBITDA
EV/EBIT（LTM）= 交易价值 / 目标 LTM EBIT
```

**计算控制权溢价：**
```
控制权溢价 =（要约价 − 未受影响价）/ 未受影响价
```
- 未受影响价 = 公告前 1–2 个交易日的股价
- 常见区间：20–40%

#### 4. 分析可比交易

**建可比交易表：**

| 日期 | 标的 | 买方 | 交易金额 | EV/营收 | EV/EBITDA | 溢价 | 理由 |
|---|---|---|---|---|---|---|---|
| 2025Q1 | 公司 X | 买方 A | 50 亿 | 4.0 | 14.0 | 35% | 行业整合 |
| 2024Q3 | 公司 Y | 买方 B | 35 亿 | 3.5 | 12.5 | 28% | 战略协同 |
| 中位数 | - | - | - | **3.8** | **13.0** | **31%** | - |

#### 5. 套到目标公司

**重要考虑：**
- 可比交易倍数通常高于二级市场可比（含控制权溢价）
- 按交易理由差异调整
- 考虑交易时市场条件与当前差异
- 近期交易给更高权重

**示例计算：**
```
目标公司 LTM EBITDA = 45 亿元
选定 EV/EBITDA 倍数 = 13.0（可比交易）
对应可比公司倍数 = 11.0

隐含 EV（可比交易）= 45 × 13.0 = 585 亿元
隐含 EV（可比公司）= 45 × 11.0 = 495 亿元

隐含控制权溢价 = 585 / 495 − 1 = 18%
```

### 交易倍数调整

**考虑调整：**
- **市场条件**：牛市 vs 熊市（并购活跃度）
- **交易结构**：产业方 vs 财务投资人
- **协同**：高协同交易给更高溢价
- **竞争动态**：单一买方 vs 多方竞购
- **时间价值**：较老交易相关性低

## 融资增长闸门

当股权故事依赖公司尚未拥有的资本时触发：资本密集度、债务到期、租赁义务、潜在摊薄，或客户预付款支撑的扩张。别人出钱支持的增长，与经营现金流支持的增长是两种资产，差异落在股东身上。

以下五项全部具备之前，报告不得给出正面的“拥有”结论：

1. **备考完全稀释资本结构桥。** 当前股本，加期权、限制性股票、可转债、认股权证与已公告发行，得到目标价所除的稀释股本。
2. **含租赁的企业价值桥。** 市值，加有息负债，加资本化经营租赁，加优先股与少数股东权益，减货币资金；每个组成部分追到公告页码。
3. **利息与再融资负担。** 当前利率下的利息保障倍数、逐年到期结构、按当前成本再融资对利润与契约空间的影响。
4. **维持性 vs 增长性资本开支。** 分开：只有增长那一半买来论点假设的增长，只有维持那一半在下行时不可避免。
5. **融资后回报。** 增量资本的回报扣除其成本，并对融资成本、利用率、摊薄做敏感性。

五项缺一，输出就是初步覆盖或观察名单，并点名缺的那项，按 `references/report-modes.md`。忽略资本结构的倍数不能替代闸门；它正是闸门要抓的失败。

## 估值对账

### 建估值桥

把三种方法放在一个框架里：

**示例估值汇总：**

| 方法 | 企业价值 | 股权价值 | 每股价值 | 权重 | 加权值 |
|---|---|---|---|---|---|
| DCF | 520 亿 | 420 亿 | 8.40 元 | 50% | 4.20 |
| 可比公司 | 550 亿 | 450 亿 | 9.00 元 | 30% | 2.70 |
| 可比交易 | 585 亿 | 485 亿 | 9.70 元 | 20% | 1.94 |
| **加权平均** | - | - | **8.84 元** | - | **8.84** |

### 给方法加权

**常见权重：**
- **DCF**：40–60%（基本面价值，但依赖预测准确性）
- **可比公司**：25–40%（反映当前市场情绪）
- **可比交易**：15–25%（除非并购很可能，否则相关性低）

**按以下调整权重：**
- **预测信心**：信心越高 → DCF 权重越高
- **市场条件**：牛/熊市影响可比可靠性
- **并购可能性**：公司待售或行业整合时更高
- **公司成熟度**：成熟公司 → 可比权重更高；成长公司 → DCF 权重更高

### 估值区间

永远给区间，不给单点：

**做法：**
- **基准**：最可能情景
- **乐观**：乐观假设（收入增长、利润率）
- **悲观**：保守假设

**示例：**
```
悲观：7.6 – 8.0 元
基准：8.4 – 9.2 元
乐观：9.6 – 10.4 元

评级：买入（增持）。目标价 8.4–9.2 元，中枢 8.8 元。
```

### 目标价桥

目标价要带从现价到它的完整路径。八项齐全，否则目标价不成立：

1. 现价与 as-of 日期，以及市值背后的完全稀释股本。
2. 目标价是区间，区间内有一个点，不是裸点。
3. 从现价起的隐含回报，以及获得回报的期限。
4. 产出它的方法，以及为什么该方法适合这家公司。
5. 目标价最敏感的三到四个假设。
6. 目标价隐含的倍数，与公司自身历史、同行集合分别对照。
7. 敏感性区间：乐观与悲观输入下目标价变成多少。
8. 可得的一致预期目标价，并解释差异，而不是只提一句。

用远期利润乘以退出倍数的多年期情形，不折现就不是回报：给出带折现率的现值，或给出对明确门槛回报的年化回报，按 `research-conventions/references/judgment.md`。

### 合理性检查

**交叉检查估值：**
1. **历史倍数**：当前估值是否与历史一致？
2. **同行比较**：相对同行的溢价/折价是否合理？
3. **隐含增长**：市场在定价什么增长？
4. **隐含回报**：从现价到目标价的 IRR
5. **市值分析**：总市值是否说得通？

---

## 结论

三种估值方法一起用，构成判断合理价值的稳健框架：

- **DCF** 给出基于基本面的内在价值
- **可比公司** 反映当前市场估值
- **可比交易** 指示并购价值与控制权溢价

关键是理解每种方法背后的假设，并给出考虑了多情景、多方法的、有理由的估值区间。
