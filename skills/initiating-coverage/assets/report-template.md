# A 股首次覆盖报告模板

本模板给出完整首次覆盖报告的结构。它是指南，不是填空表：每一节都要用分析填满，模板只保证不遗漏。

**注意：**报告一律写成 Markdown（`reports/<主题>/<公司>_首次覆盖_<日期>.md`），不使用 DOCX/PPT。图表先用 matplotlib 生成 PNG（300 DPI，`charts/<主题>/`），再在 Markdown 中以相对路径嵌入。

**关键要求：**
1. **先出图，后成文**：成文前用 Python（matplotlib）生成 25–35 张图表文件
2. **图表必须真实**：嵌入的是 PNG 文件，不是文字描述，也不是外部截图
3. **数字来自模型**：正文与表格的每个数字追到 `scripts/<主题>/model.py` 的输出 CSV
4. **中文报告**：标题、表头、图题、来源行、单位全部中文；金额统一亿元/万元，并写明单位

**关键排版指引：**
- **高密度**：每一节都要有信息，文字、图、表穿插
- **不留孤节**：不出现只有一个小标题或一张图的一节
- **25–35 张真实图**：先生成文件，再在正文对应位置嵌入

## 第 1 页：首次覆盖封面（最重要的一页）

**关键**：第 1 页不是传统执行摘要，而是机构格式的**首次覆盖**封面。

**结构要点：**
- 页首写“首次覆盖”，绝不写“公司更新”，也不写“执行摘要”
- 左上角是评级框
- 显眼位置放股价表现图（图 1）
- 3–4 条详细要点，用 ■ 开头
- 每条要点有**加粗小标题**，后接 3–5 句解释
- 底部是财务与估值指标表
- 所有图有图号（图 1、图 2……）和来源行

## 图表编号与格式标准

**关键**：所有图、表都遵循机构报告的编号规范。

### 图号格式

**每张图/表必须有：**
1. **连续编号**：图 1、图 2、图 3……全文连续
2. **描述性标题**：“图 X - [公司] [具体指标] [图型/分析]”
3. **来源行**（始终在底部）：“来源：公司定期报告、[数据工具]、我们的预测。”

**示例：**
- 图 1 - [公司] 股价表现
- 图 2 - [公司] 历史与预测分产品收入结构
- 图 3 - [公司] 分地区收入
- 图 4 - [产品名] 收入与单价
- 图 5 - [公司] 毛利率变化
- 图 6 - DCF 敏感性分析（元/股）
- 图 7 - 估值足球场

### 图题格式

```
图 X - [描述性标题]
[图/表内容]
来源：公司定期报告、[数据工具]、我们的预测。
```

多来源表格：
```
图 X - [描述性标题]
[表内容]
来源：公司公告、`company_financials`/`company_valuation`、我们的预测。
```

### 位置规则

- 图按正文出现顺序编号
- 第一张图通常是第 1 页的股价图或营收增长轨迹
- 图题紧贴图上方
- 来源行放在图下方，字号小一号、斜体
- Markdown 中图与表都要有编号，并在正文里用“（图 X）”“（表 X）”引用

## 使用本模板的注意事项

1. **第 1 页最关键：**首次覆盖封面必须包含全部关键信息——速览事实、财务快照、3 张图、估值摘要、论点与风险。这是最重要的一页。

2. **高密度：**机构研究信息密度极高。每节都要文字、图、表穿插，版面覆盖率 60–80%，减少空白。

3. **不留孤节：**不出现只有一个小标题、或只有一张图/表的一节。始终组合元素。例如不要把“财务快照”单独放一节，要和上下文整合。

4. **25–35 张图：**全文充分用图，重点保证：
   - **分产品/分部收入**（堆叠面积）
   - **分地区收入**（堆叠柱）
   - **财务表现趋势**（多张图）
   - 图嵌在正文里，不集中放置

5. **Markdown 规范：**标题层级不跳级；表格有表头与来源行；图片用相对路径；数字与单位统一。

6. **穿插内容：**文字段落之间嵌图。每节应有 2–4 个不同元素（表、图、文字块）。

7. **格式一致：**标题、正文、表格、图表风格统一。选定一套配色并坚持。

8. **引用：**每个数据点都有来源与日期。

9. **校对：**反复校对准确性，尤其是财务数据与计算。

10. **封面最后写：**它出现在第 1 页，但要等全部分析完成后再写。

11. **平衡：**正面与负面都要客观呈现，反方证据不能省略。

12. **具体优于空泛：**用具体数据与例子，不写通用判断。
