# A 股财报前瞻（earnings-preview）

整篇只围绕一个对象：**bar（市场已经定价的预期水平）**。一致预期只是 bar 的一个输入，不是 bar 本身。前瞻要回答：bar 在哪、什么能超/低、电话会听什么、每种结果下股价可能怎么反应。

财报发布后转 `earnings-analysis`。

证据标签、来源分层、新鲜度与就绪姿态遵循 `research-conventions`。

## 边界

- 只做研究，不下单、不给仓位；交易方案交 `trade-pitch`。
- **A 股个股没有上市期权**，不写“期权隐含波动”；可用历史财报日涨跌、两融余额、资金流、龙虎榜替代，并写明这是替代口径。
- 一致预期是卖方汇总，不是事实；写机构数与抓取日期。
- 预告区间是原文，不能当成精确值；正式报告前只能按区间准备。
- **缺输入不缩短报告**：某节取不到就保留标题，写“缺什么、什么能补”，不静默删节。

## 第 1 步：冻结时点与期间映射

- 记录一个 `as_of`：价格、一致预期、两融、资金流都取同一时点；没有日期的输入是缺口。
- 用 `company_earnings(kind="schedule", code)` 确认预约披露日与实际披露日；`kind="forecast"/"express"` 确认是否已有预告/快报。
- 期间映射一次写死：本季、上季、去年同期、前年同期，四个标签在所有表/图中一致。
- 财报日期以公司公告/交易所为准，不用“一般 4 月底”推断。

**完成判据**：四个期间标签、`as_of`、披露日（含是否改期）齐全。

## 第 2 步：搭 bar

五个来源分开列，不混合：

| 来源 | 是什么 | 从哪取 |
|---|---|---|
| 公司指引/预告 | 管理层给的区间或预告类型（预增/预减/扭亏/首亏） | `company_earnings(kind="forecast"/"express")`、公告原文 |
| 卖方一致预期 | 均值与机构数，带抓取日期 | `company_consensus(code)` 的 `eps_forecast`/`net_profit_forecast`；两套口径差 >5% 时都列 |
| 我们自己的估计 | 按驱动量搭的模型 | 本 skill 或 `initiating-coverage` 的模型 |
| 上期实际 | 公司上一报告期披露的 run-rate | `company_financials` |
| 市场传闻/调研 | 有来源才写，否则写“未提供” | 公开新闻/调研纪要（标 `street estimate`/`rumour`） |

最后用一句话写 bar 在哪：**股票在交易哪个数**（营收、归母、扣非、毛利率、订单/装机），以及其余来源离它多远。五种来源冲突时，标 `judgement` 并说明选了哪个。

**完成判据**：五行都有值或缺席理由；bar 句有数值、来源、日期、口径。

## 第 3 步：先看 EPS 质量

A 股财报的“超预期”常来自非经营项，提前能查：

| 项目 | 为什么会失真 | 财报前风险 | 财报后看什么 |
|---|---|---|---|
| 政府补助 | 计入其他收益/营业外 | 补助公告、往年占比 | 扣非与补助金额 |
| 投资收益/公允价值变动 | 参股/理财/交易性金融资产 | 市场走势、被投企业 | 是否经常性 |
| 税率 | 高新/西部/减免到期 | 税收优惠公告 | 实际税率 |
| 股本 | 定增/可转债转股/回购 | 股本变动公告 | 稀释后 EPS |
| 减值/资产处置 | 一次性 | 商誉/存货/应收 | 是否反复 |
| 汇兑 | 出口占比高 | 汇率区间 | 财务费用 |
| 收入确认 | 项目制/验收 | 合同负债、应收 | 现金流匹配 |

再检查：一致预期与公司口径是否一致（归母 vs 扣非、全年 vs 单季）；不一致时写清 bar 到底压在哪。

**完成判据**：至少筛查六项；每项有财报前风险；写明一致预期与公司口径是否一致。

## 第 4 步：把指引/预告桥到隐含 bar

预告是一个区间，不是预期。用公司自己的历史记录桥：

- 过去 8 个季度，实际值相对预告中值/上次指引的偏差方向与幅度。
- 偏差是否稳定、在扩大还是收敛；管理层/政策是否变过。
- 样本限制：几期、是否跨行业周期、预告是否强制。

**完成判据**：隐含 bar 写成数值或区间，附桥的算式与样本限制。

## 第 5 步：选决定本季的指标

财务：营收（分产品/地区）、归母、扣非、毛利率、经营现金流、费用率、下一季指引（若有）。

经营（按行业选 2–4 个）：白酒（批价、库存、合同负债）、新能源（销量/装机、单位盈利）、光伏（价格、开工率、库存）、半导体（稼动率、库存周转）、医药（集采放量、创新药收入）、银行（净息差、不良）、券商（成交/两融/投行）、军工（合同负债、交付）、地产（销售、去化）。

排序按“哪个最可能移动股价”，不按利润表顺序。公司不披露的指标写“数据请求”，不静默删除。

**完成判据**：指标有序；每个有比较基准；未披露项列为数据请求。

## 第 6 步：读同业与产业链

| 公司 | 关系 | 已披露什么 | 对本案意味着什么 | 传导链 | 置信度 |
|---|---|---|---|---|---|

覆盖：已披露的同业、上下游（客户/供应商）、行业龙头、相关宏观数据（价格/出口/PMI）。没有传导链的读数写“无明确传导”，不当信号。

**完成判据**：每行有传导链与置信度；说明哪些已被一致预期反映。

## 第 7 步：情景与反应

三档，围绕 bar 而不是去年同期：

| 情景 | 营收 | 归母/扣非 | 关键驱动 | 管理层信号 | 证伪条件 | 可能反应 |
|---|---|---|---|---|---|---|
| 乐观 | | | | | | |
| 基准 | | | | | | |
| 悲观 | | | | | | |

反应列用历史财报日数据校准：`market_bars` 取过去 8 个财报公告日次日/当日的涨跌幅（注意公告时段：盘后/盘前），列“结果 vs bar / 次日涨跌 / 驱动 / 是否延续”。没有历史样本就写“样本不足”。

再说清“已经定价了什么”，以及两个不对称：什么让差财报可买、什么让好财报该卖。

**完成判据**：每档有驱动与证伪；反应列有历史依据；写明已定价与两个不对称。

## 第 8 步：业绩说明会/电话会问题

3–4 个必问，排序，每个四部分：

1. 为什么重要（一句话，挂到 bar 或支柱）。
2. 什么回答验证观点。
3. 什么回答推翻观点。
4. 要听的具体措辞/数字（包括回避信号）。

其余放“备选问题库”（≤8 个）。财报前发生的事件矛盾，转成问题，不单独写新闻。

**完成判据**：必问 3–4 个且排序；每个四部分齐全；开放事件都转成问题或明确关闭。

## 第 9 步：装配与交付

Markdown，路径遵守 T149。章节：

1. 公司、报告期、披露日、`as_of`、姿态。
2. bar 表与 bar 句。
3. 指标排序与重要性标记。
4. EPS 质量与指引桥。
5. 同业/产业链读数。
6. 情景、历史反应、已定价。
7. 必问问题与备选库。
8. 交易 setup：近期涨跌、两融（T+1）、资金流、北向季度持股（不是每日）。
9. 缺失证据。
10. 一句话结论（不给仓位）。

**缺失证据块**：每项写“缺什么、哪个工具/文档能补、阻塞哪个结论”。

**结论**：没有足够 bar 证据时，只给“setup + 反应框架”，不写“必涨/必跌”。

**完成判据**：十节齐全；每个时间敏感数字在 `as_of` 内或标“aging”；缺口块存在。

## 常见错误

- **把预告当精确值**：预告是区间，正式报告可能落在区间外。
- **用去年同期当 bar**：市场交易的是预期，不是同比。
- **忽略股本稀释**：定增/转股后的 EPS 不可比。
- **把两融当实时**：T+1，盘后取到的是上一交易日。
- **把北向当每日**：只有季度持股；成交额是买卖合计。
- **A 股写期权隐含波动**：没有个股期权，改用历史反应与资金面。
