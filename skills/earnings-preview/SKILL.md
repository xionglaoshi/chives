# 披露日前先记下预期

在报告开头写股票代码、要预测的财季、预约披露日和本次取数截止时刻。之后发布的快报、修订或正式报告另记一版。读者日后要能用这张表判断，当时究竟预期了什么。

| 项目 | 截止时已知 | 披露后看哪一行 |
| --- | --- | --- |
| 盈利 | 公司预告的归母区间、扣非区间及最近修订；独立列出机构预测的日期、样本数和统计口径 | 归母、扣非和一次性项目各自的差额 |
| 主业 | 选两项能解释利润变化的经营量，写明销量、单价、毛利率、减值或费用中的哪项在起作用 | 相同期间的分部披露和附注 |
| 现金 | 销售收现、应收变化或预收款能否支持盈利 | 现金流量表与期后事项 |

例如公司只预告了全年归母利润，用该区间两端减去前三季累计归母，得到第四季度的隐含范围。两端统一单位；并表范围或重述导致两期不可比时停止这一步。EPS 另外核对加权股数、增发和摊薄，扣非净利、经营现金流及税率能帮助判断这次变化能否延续。不要用市盈率或股价涨幅倒推一个假定的市场一致预期。

用授权的公告、财务及研报查询工具，先打开公司自己的预告及修订，再找带日期的可比公司披露或上下游量价数据。没有机构一致预期时，标明「市场预期缺数」，仅列公司指引和独立假设。为偏低、基准、偏高三个情景各写一组可观测条件，说明哪个条件会使判断失效。股价反应还取决于此前预期和市场环境，单列讨论。

交付一份可在披露日填回实数的 Markdown 核对表。末尾给管理层两三个具体问题，例如「在手订单增长了多少，其中有多少已经收款」；列出公告原件、证据页和下次复核日期。
