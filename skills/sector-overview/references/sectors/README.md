# 行业视角模板（sector-overview 参考）

某个行业没有现成文件时，按本模板现场建；新增行业文件也按这七节写，顺序固定。

行业视角是**背景**，不是交付物：它只决定跟踪哪些指标、先看哪把估值尺子、检查哪些失败模式。报告本身仍由 `sector-overview` 决定。

| 小节 | 写什么 |
|---|---|
| 生意原型 | 这个行业的公司靠什么赚钱，一行一个原型，附“分错会犯什么错” |
| 核心 KPI | 行业真正被衡量的经营/财务指标；两家定义不同时写清定义 |
| 模型结构 | 预测从什么驱动开始、按什么顺序搭，让模型跟经济逻辑走，而不是先拍收入增速 |
| 估值尺子（按顺序） | 先用的尺子、它是哪些变量的函数；再写哪个通用尺子在这里会给出“自信但错误”的答案 |
| 红旗 | 报表数字可能不是看上去那样的可观察模式，每条写“下一步查什么” |
| 来源层级 | 这个行业的数字实际来自哪里；哪些是公司自述而非报表数 |
| 行业铁律 | 在这个行业成立的做法，每条配“不这么做会犯的错” |

没有现成文件时，先从同行业两家公司的收入确认与分部附注读出商业模式，写下分类，再进入分析；交付时说明“视角是现场建立的”。

新文件完成标准：七节都有内容；每把估值尺子写明它是哪些变量的函数；铁律至少三条，来自上面的陷阱与红旗。

以上为研究框架，不构成投资建议。
