## 指数行情

接口：`GET /api/v5/market/index-tickers`
用途：取指数价格。指数由多家交易所现货价格加权计算，用作衍生品定价基准。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | N | 指数 ID，如 `BTC-USD`（与 `quoteCcy` 二选一） |
| quoteCcy | str | N | 计价货币，如 `USD`，返回该计价下全部指数 |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instId | str | 指数 ID |
| idxPx | str | 最新指数价格 |
| high24h / low24h | str | 24 小时最高 / 最低 |
| open24h | str | 24 小时开盘价 |
| sodUtc0 / sodUtc8 | str | UTC 0 点 / UTC+8 0 点开盘价 |
| ts | str | 时间戳（毫秒） |

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/index-tickers?instId=BTC-USD")
```

响应示例（2026-11-02T08:36:45Z）：

```json
{"code":"0","data":[{"instId":"BTC-USD","idxPx":"78082.3","high24h":"78756.4","low24h":"77528.4","open24h":"78038","sodUtc0":"78238.8","sodUtc8":"77874.2","ts":"1793608605089"}],"msg":""}
```

用法：指数价格与永续最新价、标记价三者并列，是看基差与溢价的最小数据集。`quoteCcy=USD` 会返回大量指数，`web_fetch` 场景下优先按 `instId` 取单个。

文档：<https://www.okx.com/docs-v5/en/#public-data-rest-api-get-index-tickers>
