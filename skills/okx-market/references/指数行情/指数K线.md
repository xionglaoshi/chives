## 指数 K 线

接口：`GET /api/v5/market/index-candles`
用途：取指数价格的 K 线，用于基准走势分析。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 指数 ID，如 `BTC-USD` |
| bar | str | N | 默认 `1m`；可选 `1m/3m/5m/15m/30m/1H/2H/4H/6H/12H/1D/1W/1M` |
| after | str | N | 请求此时间戳之前的数据（毫秒） |
| before | str | N | 请求此时间戳之后的数据（毫秒） |
| limit | str | N | 返回条数，默认 100，最大 **100** |

### 返回字段（二维数组，按索引）

| 索引 | 说明 |
|---|---|
| 0 | 开盘时间（毫秒时间戳） |
| 1 | 开盘价 |
| 2 | 最高价 |
| 3 | 最低价 |
| 4 | 收盘价 |
| 5 | K 线状态：`0`=未完结，`1`=已完结 |

指数 K 线**没有成交量列**，不要套用现货 K 线的 9 列结构。返回顺序同样是**最新在前**。

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/index-candles?instId=BTC-USD&bar=1D&limit=2")
```

响应示例（2026-11-02T08:36Z）：

```json
{"code":"0","data":[
 ["1793548800000","77874.2","78756.4","77528.4","78082.3","0"],
 ["1793462400000","77463.5","78135.7","77308.4","77874.2","1"]
],"msg":""}
```

上限与现货 K 线不同：指数 K 线单次最多 100 条，现货/合约 K 线最多 300 条。翻页都用 `after`（向更早）。

文档：<https://www.okx.com/docs-v5/en/#public-data-rest-api-get-index-candlesticks>
