## 批量产品行情

接口：`GET /api/v5/market/tickers`
用途：一次取某类产品（现货/永续/交割/期权）下全部产品的最新行情。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instType | str | Y | `SPOT` / `SWAP` / `FUTURES` / `OPTION` |
| instFamily | str | N | 合约家族过滤（如 `BTC-USDT`），仅对衍生品有效 |

### 返回字段

`data` 为数组，每个元素的字段与 `/market/ticker` 相同（`instId`、`last`、`open24h`、`high24h`、`low24h`、`vol24h`、`volCcy24h`、`ts` 等）。

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/tickers?instType=SPOT")
```

**注意**：`SPOT` 与 `SWAP` 的全量响应很大（数百到上千个产品），会占用大量上下文。研究单一产品时用 `/market/ticker`；确实需要全量时，优先在本地用脚本拉取并只保留需要的列。

响应结构示例（单元素节选，字段同 `/market/ticker`）：

```json
{"code":"0","data":[{"instType":"SPOT","instId":"BTC-USDT","last":"78186.7",
 "open24h":"78141","high24h":"78866.5","low24h":"77600.5",
 "vol24h":"4301.84328439","volCcy24h":"336154440.232936149",
 "ts":"1793608603564"}],"msg":""}
```

排序前先确认 `volCcy24h` 的计价单位；现货与合约的 `volCcy24h` 口径可能不同，不要混排。

### 核对说明

全量 `SPOT` 响应体很大，本页字段口径按 `/market/ticker` 与官方文档核对。若要断言某字段存在，先用 `instId` 过滤或抽样一次再写。

文档：<https://www.okx.com/docs-v5/en/#order-book-trading-market-data-get-tickers>
