## 交易产品列表

接口：`GET /api/v5/public/instruments`
用途：取可交易产品的元数据：交易对、精度、最小下单量、合约面值、上市时间、状态。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instType | str | Y | `SPOT` / `SWAP` / `FUTURES` / `OPTION` |
| instId | str | N | 产品 ID，过滤单个产品 |
| instFamily | str | N | 合约家族，如 `BTC-USDT`（衍生品） |

### 返回字段（节选，2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instType / instId | str | 产品类型 / 产品 ID |
| baseCcy / quoteCcy | str | 基础货币 / 计价货币（现货） |
| settleCcy | str | 结算货币（衍生品） |
| tickSz | str | 最小价格变动 |
| lotSz | str | 最小下单数量步长 |
| minSz | str | 最小下单量 |
| ctVal / ctValCcy / ctMult | str | 合约面值 / 面值币种 / 乘数（衍生品） |
| lever | str | 最大杠杆（衍生品） |
| listTime | str | 上市时间（毫秒） |
| expTime | str | 到期时间（交割/期权，毫秒） |
| state | str | `live` / `suspend` / `preopen` 等 |
| maxLmtSz / maxMktSz | str | 单笔限价/市价最大数量 |

实测 `SPOT/BTC-USDT` 还返回大量风控与交易参数（`maxPxLmtPct`、`maxLmtAmt`、`posLmtAmt`、`ruleType` 等）；这里只列研究常用的字段，不要假定字段全集固定不变。

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/public/instruments?instType=SPOT&instId=BTC-USDT")
```

响应示例（节选）：

```json
{"code":"0","data":[{"instId":"BTC-USDT","instType":"SPOT","baseCcy":"BTC",
 "quoteCcy":"USDT","tickSz":"0.1","lotSz":"0.00000001","minSz":"0.00001",
 "lever":"10","listTime":"1611907686000","state":"live",
 "maxLmtSz":"9999999999","maxMktSz":"1000000"}],"msg":""}
```

用途提示：算合约名义价值要用 `ctVal × ctMult × 张数`（以当前返回为准），不要用现货数量口径套衍生品。产品状态为 `suspend` 或 `preopen` 时，行情字段可能为空。

文档：<https://www.okx.com/docs-v5/en/#public-data-rest-api-get-instruments>
