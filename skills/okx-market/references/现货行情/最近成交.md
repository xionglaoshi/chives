## 最近成交

接口：`GET /api/v5/market/trades`
用途：取产品最近的逐笔成交。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 产品 ID，如 `BTC-USDT` |
| limit | str | N | 返回条数，默认 100，最大 500 |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instId | str | 产品 ID |
| tradeId | str | 成交 ID |
| px | str | 成交价格 |
| sz | str | 成交数量 |
| side | str | 吃单方向：`buy` / `sell` |
| source | str | 成交来源标记（实测返回，如 `"0"`） |
| ts | str | 成交时间（毫秒） |

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/trades?instId=BTC-USDT&limit=2")
```

响应示例（2026-11-02T08:36:41Z）：

```json
{"code":"0","data":[
 {"instId":"BTC-USDT","tradeId":"1077355395","px":"78186.7","sz":"0.00003","side":"buy","ts":"1793608601076","source":"0"},
 {"instId":"BTC-USDT","tradeId":"1077355394","px":"78186.6","sz":"0.000135","side":"sell","ts":"1793608598221","source":"0"}
],"msg":""}
```

`side` 是**吃单方**方向，不是挂单方；用它统计主动买/卖时要在报告中写明这一口径。`limit=500` 为上限，超过可能被截断，不要假定返回条数等于请求条数。

文档：<https://www.okx.com/docs-v5/en/#order-book-trading-market-data-get-trades>
