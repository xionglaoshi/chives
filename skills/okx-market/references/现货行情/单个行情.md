## 单个产品行情

接口：`GET /api/v5/market/ticker`
用途：取单个交易产品的最新行情快照（最新价、买卖一、24 小时高低与成交量）。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 产品 ID，如 `BTC-USDT`、`BTC-USDT-SWAP` |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instType | str | `SPOT` / `SWAP` / `FUTURES` / `OPTION` |
| instId | str | 产品 ID |
| last | str | 最新成交价 |
| lastSz | str | 最新成交量 |
| askPx / askSz | str | 卖一价 / 卖一量 |
| bidPx / bidSz | str | 买一价 / 买一量 |
| open24h / high24h / low24h | str | 24 小时开盘 / 最高 / 最低 |
| vol24h | str | 24 小时成交量（币） |
| volCcy24h | str | 24 小时成交额（计价货币） |
| sodUtc0 / sodUtc8 | str | UTC 0 点 / UTC+8 0 点开盘价 |
| ts | str | 数据时间戳（毫秒） |

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/ticker?instId=BTC-USDT")
```

响应示例（节选，2026-11-02T08:36:43Z）：

```json
{"code":"0","data":[{"instType":"SPOT","instId":"BTC-USDT","last":"78186.7",
 "lastSz":"0.00003","askPx":"78186.7","askSz":"0.35594756",
 "bidPx":"78186.6","bidSz":"0.74813789","open24h":"78141",
 "high24h":"78866.5","low24h":"77600.5","vol24h":"4301.84328439",
 "volCcy24h":"336154440.232936149","ts":"1793608603564",
 "sodUtc0":"78342.6","sodUtc8":"77982.6"}],"msg":""}
```

计算涨跌幅：`last / open24h − 1`。所有数值都是字符串，先转数值。引用时写 `as_of`。
