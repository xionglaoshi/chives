## 深度数据（Order book）

接口：`GET /api/v5/market/books`
用途：取买卖盘口深度。
限频：40 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 产品 ID，如 `BTC-USDT` |
| sz | str | N | 深度档位数，默认 1，最大 **400** |

实测 `sz=401` 返回 `{"code":"51000","msg":"Parameter sz error."}`，说明上限为 400。

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| asks | list | 卖盘，每档 `[价格, 数量, 已废弃字段, 订单数]` |
| bids | list | 买盘，每档 `[价格, 数量, 已废弃字段, 订单数]` |
| ts | str | 时间戳（毫秒） |
| seqId | int | 序列号（实测返回） |

第三列在官方文档中标注为已废弃，计算时只用第 0、1、3 列。

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/books?instId=BTC-USDT&sz=2")
```

响应示例（2026-11-02T08:36:44Z）：

```json
{"code":"0","msg":"","data":[{
 "asks":[["78186.7","0.02092544","0","1"],["78187.5","0.17852692","0","1"]],
 "bids":[["78186.6","0.74813789","0","8"],["78186.2","0.32","0","1"]],
 "ts":"1793608604053","seqId":83163463816}]}
```

研究用法：算买卖价差用 `asks[0][0] − bids[0][0]`，再除以中间价；算盘口深度要把数量换算成同一计价单位。`sz` 越大响应越大，`web_fetch` 场景下建议先取小档位。

文档：<https://www.okx.com/docs-v5/en/#order-book-trading-market-data-get-order-book>
