## K 线数据（OHLCV）

接口：`GET /api/v5/market/candles`
用途：取现货/合约的 K 线。单次最多 **300** 条；更早数据用 `after` 翻页。
限频：40 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 产品 ID，如 `BTC-USDT` |
| bar | str | N | 默认 `1m`；可选 `1m/3m/5m/15m/30m/1H/2H/4H/6H/12H/1D/1W/1M` |
| after | str | N | 请求此时间戳**之前**的数据（毫秒），用于向更早翻页 |
| before | str | N | 请求此时间戳**之后**的数据（毫秒） |
| limit | str | N | 返回条数，默认 100，最大 300 |

### 返回字段（二维数组，按索引）

| 索引 | 说明 |
|---|---|
| 0 | 开盘时间（毫秒时间戳） |
| 1 | 开盘价 |
| 2 | 最高价 |
| 3 | 最低价 |
| 4 | 收盘价 |
| 5 | 成交量（币） |
| 6 | 成交额（计价货币） |
| 7 | 成交额（报价货币） |
| 8 | K 线状态：`0`=未完结，`1`=已完结 |

**顺序**：接口返回**最新一根在前**（时间倒序）。做时间序列计算前要按索引 0 升序排序。

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/market/candles?instId=BTC-USDT&bar=1D&limit=2")
```

响应示例（2026-11-02T08:36Z，注意第一行比第二行新）：

```json
{"code":"0","data":[
 ["1793548800000","77982.6","78866.5","77600.5","78186.7","2632.29316531","205853911.749780258","205853911.749780258","0"],
 ["1793462400000","77558.3","78251.1","77400","77982.5","3270.06099936","254729792.066704016","254729792.066704016","1"]
],"msg":""}
```

核对要点：

- `limit=300` 正常；"可翻页取得的历史总量"与单次 `limit` 上限不是一回事，单次上限按 300 条处理。
- 第 9 列 `confirm` 为 `0` 时是未完结 K 线，不能当收盘价使用。
- `bar` 大小写敏感：`1H` 与 `1h` 不是同一个值。
