## 资金费率

接口：`GET /api/v5/public/funding-rate`
用途：取永续合约的当前资金费率、上下次结算时间、利率基准与溢价。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 永续合约 ID，如 `BTC-USDT-SWAP` |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instId / instType | str | 合约 ID / 类型 |
| fundingRate | str | 当前资金费率（小数，`0.0001` = 0.01%） |
| fundingTime | str | **下次**结算时间（毫秒） |
| prevFundingTime | str | **上次**结算时间（毫秒） |
| nextFundingTime | str | 下下次结算时间（毫秒） |
| settFundingRate | str | 上次已结算费率 |
| settState | str | `settled` / `processing` |
| interestRate | str | 利率基准（实测 `0.0001`，即 0.01%） |
| premium | str | 溢价（实测返回） |
| minFundingRate / maxFundingRate | str | 费率上下限 |
| method / formulaType / impactValue | str | 计算方式与影响名义价值（实测返回） |
| ts | str | 数据时间戳（毫秒） |

### 结算间隔必须从字段推导

```
interval_ms = int(fundingTime) − int(prevFundingTime)
```

本次实测 `1793635200000 − 1793606400000 = 28,800,000 ms = 8 小时`，且 `nextFundingTime − fundingTime` 同为 8 小时，可交叉核对。**不同合约可能不同**，不要写死 3 次/日。

年化（简单年化）：

```
annualized = rate × (365 × 24 × 3600 × 1000 / interval_ms)
```

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/public/funding-rate?instId=BTC-USDT-SWAP")
```

响应示例（2026-11-02T08:36:10Z，节选）：

```json

 "fundingRate":"0.0000851812713453","fundingTime":"1793635200000",
 "prevFundingTime":"1793606400000","nextFundingTime":"1793664000000",
 "settFundingRate":"0.0000859268179859","settState":"settled",
```
