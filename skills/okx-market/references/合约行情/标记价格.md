## 标记价格

接口：`GET /api/v5/public/mark-price`
用途：取合约标记价格。标记价格用于未实现盈亏与强平计算，通常比最新成交价稳定。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instType | str | Y | `SWAP` / `FUTURES` / `OPTION` |
| instId | str | N | 产品 ID，过滤单个合约 |
| instFamily | str | N | 合约家族（衍生品） |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instType / instId | str | 产品类型 / 产品 ID |
| markPx | str | 标记价格 |
| ts | str | 时间戳（毫秒） |

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/public/mark-price?instType=SWAP&instId=BTC-USDT-SWAP")
```

响应示例（2026-11-02T08:36:46Z）：

```json
{"code":"0","data":[{"instId":"BTC-USDT-SWAP","instType":"SWAP","markPx":"78152.2","ts":"1793608606174"}],"msg":""}
```

用法：比较"最新成交价 − 标记价格"可以看短时基差/溢价；强平距离用标记价格算，不要用最新成交价。不传 `instId` 会返回该类型下全部合约，响应很大。

文档：<https://www.okx.com/docs-v5/en/#public-data-rest-api-get-mark-price>
