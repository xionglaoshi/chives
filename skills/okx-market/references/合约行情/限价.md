## 合约限价

接口：`GET /api/v5/public/price-limit`
用途：取合约当前允许的最高买入价与最低卖出价（超出范围的订单会被拒绝）。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 合约 ID，如 `BTC-USDT-SWAP` |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instType / instId | str | 产品类型 / 产品 ID |
| buyLmt | str | 买入限价（最高可买价） |
| sellLmt | str | 卖出限价（最低可卖价） |
| enabled | bool | 限价是否启用（实测返回） |
| ts | str | 时间戳（毫秒） |

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/public/price-limit?instId=BTC-USDT-SWAP")
```

响应示例（2026-11-02T08:36:46Z）：

```json
{"code":"0","data":[{"buyLmt":"78543","enabled":true,"instId":"BTC-USDT-SWAP","instType":"SWAP","sellLmt":"77761","ts":"1793608606181"}],"msg":""}
```

研究用法：限价区间可以衡量交易所允许的价格波动边界，但它是风控参数，不是支撑/阻力位。`enabled=false` 时该字段不具约束力。本接口只读，不涉及任何下单操作。

文档：<https://www.okx.com/docs-v5/en/#public-data-rest-api-get-limit-price>
