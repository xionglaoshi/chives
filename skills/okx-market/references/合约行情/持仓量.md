## 持仓量（Open Interest）

接口：`GET /api/v5/public/open-interest`
用途：取合约未平仓量。
限频：20 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instType | str | Y | `SWAP` / `FUTURES` / `OPTION` |
| instId | str | N | 产品 ID，过滤单个合约 |
| instFamily | str | N | 合约家族（衍生品） |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instType / instId | str | 产品类型 / 产品 ID |
| oi | str | 持仓量（合约张数） |
| oiCcy | str | 持仓量（币） |
| oiUsd | str | 持仓量（USD 计价，实测返回） |
| ts | str | 时间戳（毫秒） |

接口还返回 `oiUsd`；做跨品种比较用 `oiUsd`，做本币数量分析用 `oiCcy`，两者变化率不同，报告里必须写明用的是哪一个。

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/public/open-interest?instType=SWAP&instId=BTC-USDT-SWAP")
```

响应示例（2026-11-02T08:36:46Z）：

```json
{"code":"0","data":[{"instId":"BTC-USDT-SWAP","instType":"SWAP",
 "oi":"3342676.56000001922","oiCcy":"33426.7656000001922",
 "oiUsd":"2612365242.49465502079518","ts":"1793608606176"}],"msg":""}
```

`oi` 是张数，换算名义价值需要合约面值（见 `public/instruments` 的 `ctVal × ctMult`）。不传 `instId` 时返回全量，响应较大。

文档：<https://www.okx.com/docs-v5/en/#public-data-rest-api-get-open-interest>
