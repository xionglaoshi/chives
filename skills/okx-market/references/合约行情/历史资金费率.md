## 历史资金费率

接口：`GET /api/v5/public/funding-rate-history`
用途：取永续合约已结算的历史资金费率。
限频：10 次/2s。

### 输入参数

| 名称 | 类型 | 必选 | 说明 |
|---|---|---|---|
| instId | str | Y | 永续合约 ID，如 `BTC-USDT-SWAP` |
| after | str | N | 请求此时间戳**之前**的数据（毫秒） |
| before | str | N | 请求此时间戳**之后**的数据（毫秒） |
| limit | str | N | 返回条数，默认 100 |

### 返回字段（2026-11-02T08:36Z 实测核对）

| 名称 | 类型 | 说明 |
|---|---|---|
| instId / instType | str | 合约 ID / 类型 |
| fundingRate | str | 该期资金费率（小数） |
| realizedRate | str | 实际收取费率 |
| fundingTime | str | 结算时间（毫秒） |
| method | str | 计算方式（实测返回，如 `current_period`） |
| formulaType | str | 公式类型（实测返回，如 `withRate`） |

### 用 web_fetch 直接取

```
web_fetch(url="https://www.okx.com/api/v5/public/funding-rate-history?instId=BTC-USDT-SWAP&limit=3")
```

响应示例（2026-11-02T08:36:10Z）：

```json
{"code":"0","data":[
 {"instId":"BTC-USDT-SWAP","instType":"SWAP","fundingRate":"0.0000859268179859","fundingTime":"1793606400000","method":"current_period","formulaType":"withRate","realizedRate":"0.0000859268179859"},
 {"instId":"BTC-USDT-SWAP","instType":"SWAP","fundingRate":"0.0001","fundingTime":"1793577600000","method":"current_period","formulaType":"withRate","realizedRate":"0.0001"},
 {"instId":"BTC-USDT-SWAP","instType":"SWAP","fundingRate":"0.0000954849645099","fundingTime":"1793548800000","method":"current_period","formulaType":"withRate","realizedRate":"0.0000954849645099"}
],"msg":""}
```

返回同样是**最新在前**。用相邻两条 `fundingTime` 之差可以核对结算间隔（本例两条相差 28,800,000 ms = 8 小时）；若某段历史切换过间隔，差分会变化，计算年化时应逐期用各自的间隔，或按段落分别年化。

引用历史费率时同时给出 `limit`、抓取时间与合约 ID。
