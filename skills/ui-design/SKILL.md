# 让读者看懂这次判断

从交付物要回答的问题决定版式。比较几家公司的回款，用同一口径的小表；看股价在公告前后如何变化，用时间轴；比较多种估值假设，让读者同时看到分母、倍数和结果。只有一个现价时，写出数值、单位和时间就够了。

| 场景 | 页面上先看到什么 | 细节放在哪里 |
| --- | --- | --- |
| 工作台或 Bot 侧栏 | 当前对象、实际状态和下一步可执行动作 | 证据、运行记录和高级设置按需展开 |
| 盘口、估值或财务图 | 指标、期间、单位、截止时点 | 图注给数据源、复权或调整口径 |
| Markdown、HTML 或 PDF 报告 | 研究问题、结论与最重要的反证 | 原公告、页码和计算表紧跟对应判断 |

**行情有自己的语法。** A 股涨跌沿用工作台当前的配色偏好，涨跌两边同时显示正负号或文字。触发、失效、数据陈旧和休市用不同的词。区间用带宽或上下界展示，预测段和历史段在图例中区分。跨币种、跨期间或合并范围不同的值先换算再比较。鼠标悬停才出现的数字，应当也能在表格、图注或键盘焦点读到。

**先排字，再装饰。** 标题说清指标与比较对象，中文字体有本地回退，数字列用等宽数字并按小数点或右侧对齐。正文一套字号层级，图上减少重复标签。报告页优先把横向空间给图和数据，窄屏让卡片顺排、长表可横向查看。浅色和深色主题分别确认对比度，避免让装饰色与涨跌含义相撞。

**交付前按读者的动作走一遍。** 手机宽度能否读到单位？灰度打印能否分清预测和实际？图表在无动画、无鼠标和离线导出时是否依然完整？数字没有证据时显示缺口，把空值与零区分开。图不改变读者判断时，删掉图，保留支撑判断的那一行数据。
