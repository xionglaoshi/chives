# 用一项估值结果倒查模型

先确认文件版本、估值日、模型类型和用户关心的输出。在副本中检查；原工作簿保留原样。列出输入页、预测页、校验页和输出页，包括隐藏表、命名范围、外部链接、宏及依赖的重算程序。分别读取单元格公式与缓存值。若环境无法重算，记录限制，不能把缓存值当成本次计算的证据。

**沿依赖走一遍。** 从一个目标价、债务余额或 IRR 开始，逆向查到输入格，再查公告页或交易条款。每步记录“表名!单元格、模型值、源值、单位、差额”。检查复制公式时滑动的引用、实际期与预测期交界、公式中混入的常数、循环引用、空值被当零、百分数与小数混用。对关键输入在另一个临时副本做一次可解释的扰动，核实际响应方向与幅度。

**逐项平账。** 三表模型核资产恒等式、现金桥、债务滚动和留存收益。DCF 核现金流与折现率的币种、名义口径、起算点、终值、净债务和稀释股数。交易模型核资金来源与用途、手续费、购买价与融资额。可比模型按分母日期和股本重算一家同行。平账阈值跟随表的显示精度；量级错误与尾差分开。

**给能动手修的人一张清单。** 每项写原格位置、触发步骤、期望值、现值、受影响输出、严重度、修改负责环节。硬错误、源数矛盾、假设分歧、缺少证据分开。报告首页说明哪些输出已经重算、哪些仍不能用于决策，附最先该修的一项。审阅与修订分开交付。
