# A股可转债分析

## 概述

A股可转债是"债底 + 股票期权 + 条款博弈"的混合品种。本 skill 覆盖三维估值、
条款分析、双低/轮动筛选，以及必须知道的交易规则与数据缺口。

**先记住三条**：
1. 可转债价格不是债底，也不是转股价值的简单相加；期权价值和条款预期都在价格里。
2. 强赎、下修、回售都是**合同条款**，每只债不同，必须逐只读募集说明书和公告。
3. 信用风险真实存在；低价不等于安全。

## 交易规则（沪深，2022-08-01 起；以交易所最新细则为准）

| 项目 | 规则 |
|------|------|
| 交易机制 | T+0，当日买入可当日卖出 |
| 交易单位 | 1 手 = 10 张 = 1,000 元面值；沪市最小申报 1 手，深市最小 10 张；不足 1 手/10 张应一次性卖出 |
| 上市首日涨跌幅 | 相对发行价 -43.3% 至 +57.3% |
| 次日起涨跌幅 | 相对前收盘 ±20% |
| 盘中临时停牌 | 设有临时停牌机制，阈值/时长按交易所细则；不要假设可以随时成交 |
| 转股 | 转股申报后，股份通常 T+1 到账；可卖出时间以登记结算和券商为准 |
| 利息税 | 个人投资者利息收入按适用税率代扣（常见 20%，以券商/税务为准）；税后现金流要单独假设 |

回测影响：T+0 意味着日内策略可行；±20% 和临停意味着涨跌停/停牌无法成交要
单独建模；转股 T+1 意味着"转股套利"不是当日无风险闭环。

## 可转债基础概念

### 核心要素

| 要素 | 说明 | 示例（仅示意） |
|------|------|----------------|
| 面值 | 100 元/张 | - |
| 票面利率 | 常见递增，0.2%–2.0% 区间，逐只不同 | 第 1 年 0.4% … 第 6 年 2.0% |
| 转股价 | 转换成股票的价格 | 15.00 元 |
| 到期期限 | 常见 5–6 年 | 2024–2030 |
| 到期赎回价 | 面值 + 最后一年利息 + 补偿，逐只不同 | 110–115 元（含最后一年利息） |
| 回售条款 | 常见：最后 2 个计息年度，连续 30 个交易日收盘价低于转股价 70%；**改变募集资金用途**也可能触发 | 以募集说明书为准 |
| 强赎条款 | 常见：转股期内连续 30 个交易日中至少 15 个交易日收盘价 ≥ 转股价 130%；**未转股余额 < 3,000 万元**也可能触发 | 以募集说明书为准 |
| 下修条款 | 常见：连续 30 个交易日中至少 15 个交易日收盘价低于转股价 85% | 以募集说明书为准 |

### 关键指标

```
转股价值 = 100 / 转股价 × 正股价格
         = 100 / 15.00 × 18.00 = 120.00 元

转股溢价率 = (转债价格 - 转股价值) / 转股价值 × 100%
           = (125 - 120) / 120 × 100% = 4.17%

纯债价值 = Σ(票息 / (1+r)^t) + 到期赎回价 / (1+r)^n
         （详见下方现金流函数；不要重复计算最后一年票息）

纯债溢价率 = (转债价格 - 纯债价值) / 纯债价值 × 100%
```

## 三维估值体系

### 1. 纯债价值（债底）

用**显式现金流**，避免"票息单位"和"最后一年重复计算"两个常见错误：

```python
from typing import Sequence

def make_cashflows(coupon_rates: Sequence[float], redemption_price: float) -> list[tuple[float, float]]:
    """coupon_rates: 剩余各年票息率，小数表示（0.008 = 0.8%）。
    redemption_price: 到期赎回价，必须包含最后一年票息；若报价不含最后一年票息，
    传入 redemption_price + 100 * coupon_rates[-1]。
    返回 [(年数, 每 100 元面值现金流)]。
    """
    flows = [(float(t), 100.0 * r) for t, r in enumerate(coupon_rates[:-1], 1)]
    flows.append((float(len(coupon_rates)), redemption_price))
    return flows


def bond_floor(cashflows: list[tuple[float, float]], yield_rate: float) -> float:
    """yield_rate: 同评级/同剩余期限信用债收益率（小数），不是票面利率。"""
    return sum(cf / (1 + yield_rate) ** t for t, cf in cashflows)
```

- 首个付息期不足一年时，把第一段的 `t` 改成实际年数（如 0.42 年），后续各期
  依次加 0.42（1.42、2.42…），不要默认整年。
- 折现率用**同评级、同期限**的信用债收益率；用 3% 的统一假设会把不同信用风险
  的债底算成一样。
- 税后口径：对利息现金流按适用税率下调，再折现；在输出中注明"税前/税后"。
- 纯债价值越高，债底保护越强；但债底不是保证，违约时回收率可能远低于债底。

### 2. 转股价值（股性）

```
转股价值 = 100 / 转股价 × 正股当前价

影响因子:
- 正股价格（正相关）
- 转股价（负相关）
- 下修转股价 → 转股价值上升
- 送股/转增/增发导致转股价调整 → 用调整后的转股价
```

### 3. 期权价值

```
期权价值 = 转债价格 - max(纯债价值, 转股价值)
```

期权价值高，可能反映市场对正股上涨、下修或条款博弈的预期；期权价值低/负，
可能便宜，也可能是流动性差、信用风险或条款不利。**不能仅凭期权价值下单。**

### 三维判断矩阵（穷举版）

行：转股价值；列：纯债溢价率 = 转债价格/纯债价值 - 1。每个格子给"类型 + 要研究的问题"，
不是买卖指令。

| 转股价值 \ 纯债溢价率 | < 10%（接近债底） | 10%–30% | > 30%（远离债底） |
|---|---|---|---|
| < 80 | 偏债，债底保护较强；研究信用风险、回售/下修可能 | 偏债转平衡；研究下修动机与回售保护 | 价格主要靠期权/条款预期；研究是否过度定价 |
| 80–100 | 平衡偏债；研究债底与转股价值的收敛路径 | 平衡；研究正股弹性、下修概率、信用利差 | 平衡偏股；研究溢价是否由稀缺性/流动性支撑 |
| 100–120 | 平衡偏股；研究强赎倒计时与转股节奏 | 偏股；研究正股趋势与溢价压缩风险 | 偏股高溢价；研究强赎/正股波动下的下行风险 |
| > 120 | 深度价内；研究强赎条款与转股后的卖压 | 深度价内高溢价；研究正股波动与流动性 | 深度价内、远离债底；债底保护很弱，研究强赎与正股回撤 |

"偏债/平衡/偏股"是描述，不是"最佳区间"；每个格子的结论都要有数据和条款依据。

## 条款博弈分析

### 下修博弈

**触发条件**：以募集说明书为准，常见为连续 30 个交易日中至少 15 个交易日正股
收盘价低于当期转股价的 85%。

```
下修概率评估（定性，不是概率数字）:
1. 触发条件是否满足/接近满足
2. 大股东是否持有大量转债、是否有下修动力
3. 公司是否临近回售、是否有避免回售的动机
4. 公司现金是否充裕、是否有还债压力
5. 下修是否大幅稀释股权、是否触及控制权/国资审批约束
6. 下修是否有净资产/股价下限等条款约束
```

下修后：转股价值上升，但转债价格的反应取决于预期是否已被定价、下修幅度、
正股稀释和后续强赎风险。**不要假设固定的 5–15% 涨幅**；要做事件研究并给出
样本期、样本量和置信度。

### 强赎博弈

**触发条件**：以募集说明书为准，常见为转股期内连续 30 个交易日中至少 15 个
交易日正股收盘价 ≥ 转股价的 130%；未转股余额 < 3,000 万元也可能触发。

```
强赎应对:
1. 公告强赎 → 在赎回登记日前转股或卖出；逾期未转股按赎回价赎回
2. 赎回价通常略高于面值（含最后一期利息），可能远低于转股价值
3. 不转股/不卖出 = 按赎回价被赎回，可能产生较大损失
4. 公司公告"不提前赎回" → 在公告的期限内不触发；到期后重新计算
```

不要从"转股进度 >90%"推断公司不会赎回；是否赎回看公告和条款。

### 回售博弈

**触发条件**：以募集说明书为准，常见为最后 2 个计息年度，正股连续 30 个交易日
收盘价低于转股价的 70%；**改变募集资金用途**也可能触发回售。

```
回售 = 投资者有权按面值+利息（或条款约定价）卖回给公司
公司应对: 下修转股价 / 拉升股价 / 接受回售
投资者研究: 回售收益率、公司偿付能力、下修可能性、回售期剩余时间
```

回售保护不是无风险的：公司可能下修规避回售，也可能出现偿付困难。

## 双低与轮动筛选

### 双低值

```
双低值 = 转债价格 + 转股溢价率 × 100
       = 价格 + (价格/转股价值 - 1) × 100
```

双低值越低，表示"价格低 + 溢价率低"的组合排序越靠前；它只是一个排序指标，
不是收益保证。

### 筛选参数（全部可配置，不是统一安全线）

| 参数 | 作用 | 注意 |
|------|------|------|
| 双低值上限 | 控制价格+溢价 | 130/150 只是常见起点，需按市场横截面分位校准 |
| 价格上限 | 控制债底距离 | 不要用固定"<115 安全"；用价格/纯债价值 |
| 转股溢价率上限 | 控制股性 | 与正股波动、剩余期限一起看 |
| 剩余期限下限 | 避免到期压力 | 太短要看到期赎回/回售 |
| 信用评级下限 | 控制信用风险 | 评级是筛选参数，不是安全保证；低评级要额外分析 |
| 成交额下限 | 控制流动性 | 小盘转债日成交额可能很低，大资金进出困难 |

筛选结果要给出：数据日期、universe、参数、每只债的转股价值/纯债价值/溢价率/
评级/剩余期限，以及缺失字段。

### 轮动流程（研究框架）

```
1. 全市场筛选（剔除已退市/已公告强赎/停牌/数据缺失）
2. 计算价格、转股溢价率、纯债溢价率、双低值
3. 加入信用、条款、正股动量等维度（权重可配置）
4. 排序，形成观察名单（不是买入名单）
5. 按月/按周复核；记录调仓假设、成本和无法成交的情形
```

回测必须报告：样本期、universe、调仓频率、交易成本、T+0 假设、强赎/下修/回售
处理、停牌/涨跌停无法成交的处理、以及样本外结果。**不要引用"年化 10–15%、
最大回撤 -8% ~ -15%、Sharpe 1.0–1.5"这类无样本、无成本、无来源的数字。**

## 数据获取与缺口

- 正股价格：`market_bars(code, interval="1d")`（`volume_shares` 是股、`amount_yuan` 是元）。
- 转债价格、转股溢价率、转股价值、转股价：优先用 `convertible_bonds(kind="list", underlying=..., limit=...)`
  取条款与列表字段，或 `convertible_bonds(kind="quote", codes=[...])` 取 1–20 只行情。
  字段为 `bond_price_yuan`、`conversion_price_yuan`、`underlying_price_yuan`、
  `conversion_value_yuan`、`premium_pct`；转股价值与溢价率由代码计算，**正股价不是逐笔实时价**，
  引用时必须同时写出 `quote_time` 或 `as_of`。强赎、下修、回售条款仍须读公告原文，
  不能只看工具字段。纯债价值、评级、剩余期限仍无结构化源。
  **工具取不到时**，才用 `web_fetch` 抓交易所/集思录/公司公告作为备选，记录
  URL 和抓取时间；取不到就写"取不到"，不要用旧价格。
- 条款：募集说明书、发行公告、下修/强赎/回售公告（`company_announcements(code, start, end, category, limit)`
  检索，需要原文用 `company_announcements(url=...)`；否则 cninfo/交易所 `web_fetch`，记录 URL 与抓取时间）。
- 若会话配置了 tushare 接口，可用 `cb_basic`（票面利率、发行/剩余规模、评级、
  转股价、到期日）、`cb_daily`（收盘价、成交量、转股价值、溢价率）、
  `cb_call`（强赎/回售公告）做交叉核对；字段名以接口文档为准。
- 所有结论性数字带 `as_of`；价格用交易日期，条款用公告日期。

## 注意事项

1. **信用风险是最大雷**：A股已出现可转债违约/偿付困难案例；低评级、小盘、
   弱资质转债要单独做信用分析，不能只看债底。
2. **强赎倒计时要盯紧**：公告强赎后不转股/不卖出会按赎回价被赎回，可能巨亏；
   每天查公告。
3. **流动性风险**：小盘转债日成交额可能很低，大资金进出困难；报价与成交价
   可能偏离。
4. **条款差异**：每只转债的下修比例、强赎天数、回售条件都不同，必须逐只核查
   募集说明书。
5. **到期不转股**：到期按赎回价拿回面值+利息，高价买入会亏。
6. **转股 T+1**：转股所得股份通常次一交易日到账，不能假设当日卖出。
7. **数据缺口**：没有转债行情源时，不要用正股价格"推算"转债价格；写清楚
   取不到，并给出需要补充的数据。
