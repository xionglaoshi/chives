# 仓位与风险边界（risk-boundary）

用户问“仓位多少合适 / 止损放哪 / 回撤到多少该停”时用本 skill。产出是**建议**，不是设置：本 skill **不写任何配置、不代替用户采纳**，只给值、算式、依据与失效条件，由用户自己决定是否采用。

## 边界

- 只做研究，不下单、不改持仓、不写设置。
- 只在用户明确问到仓位/风险时使用；用户只是问某只股票、行情或复盘时，不主动塞一堆阈值。
- 一次只处理用户问到的项或一组相关项，不一次性给全部 11 项。
- 持仓与画像数据是私有的：不在回复里复述成本、数量、账号；只引用必要比例。
- **所有阈值建议都标“未经回测”**：它们是基于当前持仓与历史波动的估计，不是策略验证结果。

## 第 1 步：读现状

1. `profile_get()`：风险偏好、持有周期、硬约束、可承受亏损。画像与本次对话冲突时，以本次对话为准。
2. `portfolio_get()` / `portfolio_valuation()`：持仓结构、总资产、现金、单票权重。只在用户主动问持仓/风险时读。
3. `portfolio_risk(window_days=250, benchmark="000300.SH")`：年化波动率、Beta、最大回撤、`top1_weight_ratio`、`top5_weight_ratio`、`hhi`、`effective_n`；被排除的持仓逐条说明。
4. 最近复盘/记忆（若有）：环境判断、纪律状态；没有就写“无”。

**口径**：`portfolio_risk` 的比例字段是小数，写结论前换算成百分数并注明；它用前复权日收盘价，不含融资负债与分红现金流；停牌按前值填充。

**完成判据**：每个数字有 `as_of` 与来源；取不到的项写“取不到”并说明试过哪个工具。

## 第 2 步：定风险预算

先回答三个问题；用户没给就按默认并披露：

| 问题 | 默认 |
|---|---|
| 总资产与可投资金 | 用 `portfolio_valuation` 的 `total_assets_cny`；没有就写“需要你提供” |
| 单笔最大可承受亏损（占总资产） | 1%（假设），并写明是假设 |
| 组合最大可承受回撤 | 10–15%（假设），并写明是假设 |

**单笔风险预算** = 总资产 × 单笔风险比例。这个数是后面所有仓位的上限来源，不先定它，任何“买几成”都不可复核。

**完成判据**：总资产、单笔预算、组合回撤预算三项都有值或明确写“需要用户提供”。

## 第 3 步：仓位上限

### 单票上限

两种算法取较小值：

1. **风险预算法**：`单票上限金额 = 单笔亏损预算 ÷ 止损距离%`；再除以总资产得上限比例。
2. **集中度法**：参考 `top1_weight_ratio`、该股波动率与流动性；单票不超过总资产的 20–25%（默认区间，可按画像调整）。

若用户已长期重仓某票：先指出集中度事实（`top1_weight_ratio`、`effective_n`），再给“逐步降到 X%”的路径，不要求一次性砍到位。

### 题材/行业上限

用持仓的行业分布（`portfolio_get` 的行业字段或 `company_profile` 逐只归类）；上限至少覆盖当前最大题材权重，否则建议一采纳就立刻“超限”。默认同一行业/题材 ≤ 35%，并写明这是经验值。

### 总仓位上限（三档环境）

参考当前仓位比例、组合波动、最大回撤与画像：

| 环境 | 建议 | 依据 |
|---|---|---|
| 强势 | 不超过“回撤预算反推值” | 组合波动低、回撤未触发、市场宽度好 |
| 中性 | 强势档 × 0.7–0.8 | 默认 |
| 弱势 | 明显低于中性档 | 波动上升、回撤接近预算、市场宽度差 |

反推公式：`总仓位 ≤ 组合回撤预算 ÷ 组合最大回撤`（用 `portfolio_risk.max_drawdown_ratio`，并注明这是历史回撤，不是未来最大回撤）。

**完成判据**：单票、题材、总仓位三档都有值；每个值有算式或经验值标注；没有“通用百分比”冒充用户数据。

## 第 4 步：止损与回撤线

- **单笔止损**：价格止损用 ATR 或近期波幅，不用固定 5%/10% 拍脑袋；同时写逻辑止损（哪条证据被推翻）。
- **当日回撤暂停线**：参考组合历史单日波动与用户容忍度；建议 2–4%（经验区间），标“未经回测”，只是提醒线。
- **累计浮亏暂停线**：参考 `max_drawdown_ratio` 与回撤预算；建议不超过组合回撤预算的 80%，留出缓冲。
- **连亏笔数**：系统没有券商逐笔盈亏，靠用户手动记录；先问“你一般连亏几笔会失控”，没有答案就跳过。
- **指数盘中跌幅应急线**：参考核心指数近期日波动；只写建议值，不承诺抓住所有急跌。
- **跌停家数应急线**：参考近期跌停家数与极端日样本；样本不足就写“样本不足，先给保守值”。

**完成判据**：每项有值、依据、失效条件；全部标“未经回测”。

## 第 5 步：输出

```markdown
# 仓位与风险边界建议（<日期>）
- 数据：portfolio_risk <as_of>；画像 <as_of>；持仓 <as_of>
- 结论：建议 N 项，跳过 M 项（原因）

| 项目 | 当前值 | 建议值 | 算式/依据 | 失效条件 |
|---|---|---|---|---|
```

逐项说明：

1. 一句话结论：建议了哪几项、哪些因缺依据跳过。
2. 表格：项目、当前值、建议值、依据（数据 + 日期 + **未经回测**）。
3. 关键假设与失效条件；当前值与建议值的差距；采纳后会不会立刻触发“超限/暂停”。
4. 采用方式：如果界面有对应设置项，由用户自行填入；本 skill 不写设置、不代替采纳。
5. 不复述持仓明细，只引用必要比例。

**完成判据**：结论先行；每项有依据与失效条件；明确写“建议、未写入、未经回测”。

## 常见错误

- **用通用百分比**：20% 单票上限不是对所有人都合适，必须从风险预算与集中度推。
- **把历史最大回撤当未来最大回撤**：它是下界参考，不是保证。
- **只给仓位不给止损**：没有止损距离，仓位无法复核。
- **忽略流动性**：小盘股建仓/退出金额超过日均成交额，仓位再“合规”也执行不了。
- **声称已设置**：本 skill 不写任何配置，也不说“已生效”。

以上为研究框架，不构成投资建议。
