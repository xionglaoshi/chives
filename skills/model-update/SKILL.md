# 新信息究竟让估值变了多少

确认要更新的原文件、输入事件、披露时间、估值日及交付格式。保留原稿，创建可追溯的版本副本。遇到含宏、外部链接、加密、复杂透视表或当前引擎不能无损保存的文件，先交付待录入表与核对位置。没有模型时先列所需文件与可以独立核对的数据。

**准备录入单。** 一行一个输入，写业务含义、报表期间、单位、原值、新值、来源页、工作表和单元格。区分已披露实际数、管理层指引和分析假设。遇到追溯重述，保留旧版与新版口径。累计数先差分，拆股或增发后重新核股数。找不到对应格的项目留待核，不向未知位置批量写入。

**让模型自己传导。** 将已确认数据录入输入格，锁住已披露期间。模型公式覆盖了的格子不粘贴结果。需要延长预测期时审查绝对引用、跨表范围、图表、隐藏列、格式与验证条件。把旧估值与新估值按实际业绩偏差、经营假设变化、净现金或债务、折现与估值倍数、股数变化分解。保留单位和关键中间值，桥合计应与两端差额相符。

**交付两版之间的差异。** 用兼容引擎重算后重新打开文件，核现金桥、资产平衡、历史数据一致性和代表性公式。若只有静态检查能力，在交付记录注明哪些输出待重算。给出工作簿副本、修改单、更新前后关键数字，以及下次披露时最先要验证的一项假设。
