# 如果按同行定价，这家公司值多少

先写清估值日、股份类别、币种和要比较的业务。一家设备厂同时经营工程总包和售后服务时，先看收入与利润分别来自哪一块。用行业成分找候选，再按客户、合同交付、资本投入和周期挑出核心同行。保留一份剔除清单；有可比业务但利润结构差异大的企业只作参照。记录样本选择时间，避免先看倍数再挑名单。

**建立同口径底表。** 对每家企业列主营、股价日、总股本、总市值、财务披露日、期间、收入、归母利润、净资产和特殊项目。用获授权的 `company_profile`、`company_financials`、`company_valuation` 取数，关键分母回到公告检核。滚动十二个月可用上年全年加本年累计减上年同期；预测值另列年度、机构与日期。次新股、重大并表及一次性处置造成的数据断点单列。

**选倍数并实际算一遍。** 稳定盈利比较 PE，亏损公司把 PE 标成无意义；金融企业可按 PB 对照 ROE；PS 需要并列毛利率和盈利路径。EV 为总市值加有息债与少数股东权益，再减可用现金。计算 EV/EBITDA 时债务、现金、合并范围和期间必须对齐。写明异常倍数与缺数的处置，以及每个指标的有效样本数。核心样本不足三家，只能展示最可比对象与限制；其余按样本量报告中位数、可解释的四分位和范围。

**从倍数回到每股。** 权益倍数乘目标公司的对应分母，再除同口径股数；企业价值倍数先转回股权价值。给出低、中、高三档，分别标明参照公司和业务差异。交付同行表、区间、目标当前所在位置，以及一个会让区间失效的条件。
