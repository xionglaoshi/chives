# A 股可比公司分析（comps-analysis）

可比公司表是“谁属于这个集合、每个数字是否在说同一件事、数据有多旧”三件事的总和，算术只是最后一步。本 skill 按这三个问题的顺序建表，**不先拉数再找故事**。

证据标签、来源分层、新鲜度、就绪姿态（posture）与口径规则：遵循 `research-conventions`，在第一张表出现前先读。期间标记、LTM/NTM 与共同基准日规则以它为准。

## 边界

- 只做研究，不下单、不给仓位数字、不写买入名单；隐含估值区间是相对估值结果，不是目标价。
- 每个估值倍数带**数据日期**（价格抓取日、财报报告期）与口径（PE TTM / PE 静态 / PB）；没有日期的倍数不进表。
- 一致预期与评级是**卖方预测汇总，不是事实**；A 股没有 NTM 四季度的现成一致预期时，不把年度预测冒充 NTM。
- 两源不一致时两者都列、不取平均；取不到的单元格写“取不到”或“不可比”，不留空、不用 0 代替。

## 第 1 步：把问题写清楚

先确认四件事，答案会改变表的结构而不只是封面：

1. **交付形式**：Markdown 表 / xlsx / 两者。
2. **读者**：投委会、内部备忘、快速参考。
3. **要回答的问题**：相对估值、成长性、经营效率、竞争位置。
4. **使用场景**：投资决策、行业比较、并购、业绩复盘。

相对估值问题需要倍数与分位；效率问题需要利润率与周转，可以不要倍数。用户给的口径与模板优先于本文默认值。

**完成判据**：用一句话写出这张表要回答的问题，指标列表由这句话推出。

## 第 2 步：建立同行集合（A 股）

### 取行业与成分

- 主体所属行业与概念：`company_profile(code="600519.SH")` 返回所属行业路径（三级）与概念板块；行业/概念行情用 `market_sectors(kind="industry"/"concept", sort, limit)`，每行含 `code`、`name`、`change_pct`、`amount_yuan`、`member_count`、`leader`（代码与名称）。板块分类口径不同时工具会带 `basis`。
- 行业排名与强度：`market_sectors(kind="industry", sort="change", limit=30)`；涨跌幅与成交额是板块口径，不是个股。
- 板块详情与成分：`market_sectors(code="BK0433", limit=100)`；`code` 取自排行结果（`BK0433`、`new_*`、`gn_*`），详情里的 `members` 是成分；取不到就写“成分取不到”，不要用记忆补名单。
- 指数成分：`company_profile(index="沪深300", limit=500)`，用于大盘/宽基对照；行业指数成分仍以板块成分为主。

### 筛选规则（先写规则，再列名字）

| 保留 | 剔除，并写理由 |
|---|---|
| 主业与主体可比，收入/利润驱动相同 | `ST`/`*ST`、退市风险警示（名称含 ST 或用公告类别“特别处理和退市”核对） |
| 同一报告期有可读财报 | 上市不足一年、无同比基数的次新股 |
| 有连续成交、非停牌 | 当前停牌或长期停牌（`news(kind="suspensions", date)`） |
| 规模与商业模式相近 | 主业不可比：纯业务对多元集团、贸易对制造、并表口径差异过大 |
| 至少 3 家、最多 10 家 | 亏损且 PE 为负的公司：可留在表内，但不进 PE 统计 |

层级：`core`（主业、规模、驱动都可比，进头部统计）、`read-through`（部分可比，只作背景）、`excluded`（读者会预期出现但被剔除，附理由）。头部统计只取 `core`。

**完成判据**：每个名字有层级与纳入/剔除理由；`core` 少于 3 家时，输出自动降为 `screen-grade`，只给最可比的一家的区间。

## 第 3 步：先定口径，再取数

在建表前把下面五项写在表头或表注：

1. **报告期**：统一到 `YYYY-03-31`/`06-30`/`09-30`/`12-31`；LTM 用“最近四个已披露单季”，不是“最近一个年报”。
2. **利润口径**：归母净利润还是扣非归母净利润；PE 用哪个口径要与 `company_valuation(scope="stock")` 的 `pe_ttm` 对齐并说明。归母与扣非不得混在一列。
3. **价格与市值**：价格抓取日、是否停牌、是否涨跌停；市值单位统一为亿元或元。
4. **单位**：金额 CNY；三表金额是元，展示时可换亿元，但表头必须写“亿元”。
5. **复权**：画股价走势时写清前复权/不复权；倍数只用最新市值与 TTM 财务，不复权不影响倍数，但影响区间收益。

### A 股特有的口径问题

- **亏损公司 PE 无意义**：PE TTM 为负或为 `null` 的公司，PE 列写“不适用（亏损）”，并从 PE 中位数/四分位中剔除，记录剔除家数。
- **次新股溢价**：上市不足一年、无四个单季可比数据的公司不纳入倍数统计；留在表内时标“次新，估值溢价不可比”。
- **壳价值**：小市值、低营收、主业萎缩的公司，PB/PS 可能反映壳价值而不是经营；此类公司单列“壳价值可疑”，不进入隐含估值。
- **板块涨跌幅限制只作定性说明**：主板 10%、创业板/科创板 20%、ST 5%、北交所 30% 会影响事件后价格反应与“涨跌停无法成交”，**不用来调整倍数**，也不据此判断高估/低估。
- **停牌与涨跌停**：价格不可交易时，市值仍可算，但“可实现价格”不是市价；表注写明。

**完成判据**：表头含报告期、利润口径、价格日、单位、复权；每个剔除项有理由。

## 第 4 步：取数

| 数据 | 工具 | 注意 |
|---|---|---|
| 三表与指标 | `company_financials(code, statement="income"/"balance"/"cashflow"/"indicators", periods=8)` | `periods` 默认 8、最多 40；金额 `_yuan`、比率 `_pct`、每股 `_yuan` |
| 估值与市值 | `company_valuation(scope="stock", code, years=1)` 的 `current.pe_ttm`、`current.pb_mrq`、`current.total_mv_yuan`、`current.float_mv_yuan` | `years` 只用于历史窗口；建表取 `current`；分位样本不足会返回 `null` + `percentile.reasons` |
| 行业估值对照 | `company_valuation(scope="industry", date=None, limit=40)` | 只有静态 PE（加权/中位数/算术平均），与个股 TTM 不同口径 |
| 指数估值 | `company_valuation(scope="index", index="沪深300")` | 10 年窗口，分位为本地计算 |
| 一致预期 | `company_consensus(code)` 的 `eps_forecast` | 按年预测，不是 NTM 四季度；写覆盖机构数与日期，声明“卖方预测汇总，不是事实” |
| 价格/快照 | `market_quote(codes=[...])`、`market_bars(code, start, end, interval="1d")` | `volume_shares` 是股、`amount_yuan` 是元；K 线一次一只 |
| 停牌 | `news(kind="suspensions", date)` | 停牌日不取“最新价”作为可实现价格 |

**单位口径**：估值市值字段以 `_yuan` 结尾，是元；财务指标金额是元、比率是百分数；`company_holders(kind="lockup")` 的解禁数量为 `_shares`、市值 `_yuan`、比例为 `_pct`。写表前统一。

**完成判据**：每个基本面单元格有报告期；每个价格类单元格有抓取日；没有把年度一致预期当 NTM。

## 第 5 步：算经营指标与 LTM

用三表原始数在 Python 里算，不抄工具汇总字段。至少：

- 营业收入、归母净利润、扣非归母净利润（单季与 LTM）。
- 毛利率 =（营业收入 − 营业成本）/ 营业收入；净利率 = 归母净利润/营业收入；扣非净利率同法。
- ROE（加权，`roe_pct`）与资产负债率（`debt_ratio_pct`）；两者都是百分数，不再乘 100。
- 营收同比（`revenue_yoy_pct`）与归母净利润同比（`net_profit_yoy_pct`），注明是累计同比还是单季同比。

LTM 的算法必须写出来：

```
2026Q3 LTM 营收 = 2025 年报营收 − 2025 前三季度营收 + 2026 前三季度营收
```

若公司披露的是单季报表，则四个单季直接相加；两种口径不能混用。字段名以工具返回为准，不按中文名猜。

**完成判据**：每个比率能回到分子、分母与报告期；LTM 的加减法在表注可见。

## 第 6 步：估值倍数与 EV

- **PE TTM**：优先用 `company_valuation(scope="stock", code).current.pe_ttm`，与自算“市值 / LTM 归母净利润”交叉核对；差异超过 2% 时写差异原因（口径、少数股东、追溯调整）。
- **PB**：`current.pb_mrq` 与“市值 / 归母净资产”交叉核对。
- **市值**：`current.total_mv_yuan` 是总市值；`current.float_mv_yuan` 是流通市值。两者不能混用。
- **EV/EBITDA**：A 股没有现成的 EV 字段。用资产负债表取有息负债、货币资金与少数股东权益，按 `EV = 总市值 + 有息负债 + 少数股东权益 − 货币资金` 计算；字段缺失时标“不可比”，**不估算、不用行业均值代替**。
- **PS**：营收为负或接近零的公司不计算。

**完成判据**：每个倍数有公式、口径、日期；与工具值不一致的地方有解释。

## 第 7 步：统计量与剔除规则

统计量由代码计算，不用“凭感觉取中位数”：

```
样本 = core 层、倍数有效（非负、非空）的公司
输出 = 样本数 n、25 分位、中位数、75 分位、最小值、最大值
剔除 = PE ≤ 0 或 null；单侧超过 1.5×IQR 的极端值（记录剔除对象与理由）
```

- `n < 3`：不给四分位，只给“最可比的一家的倍数 + 区间”，并在文首标 `screen-grade`。
- `n ≥ 3`：中位数为主，四分位为区间；均值只在分布对称时作补充，并说明为什么。
- 统计量只用于可比指标（PE、PB、PS、增速、利润率），**不用于规模指标**（营收、市值、净利润的绝对额）。

**完成判据**：每个统计量有 n 与剔除记录；没有静默丢样本。

## 第 8 步：隐含估值区间

把选定统计量应用到主体的同一口径指标上：

```
隐含市值（PE 法） = 主体 LTM 归母净利润 × 选定 PE
隐含市值（PB 法） = 主体归母净资产 × 选定 PB
每股区间 = 隐含市值 ÷ 总股本
```

- 至少给“25 分位 / 中位数 / 75 分位”三档，不给单点“目标价”。
- 主体亏损时 PE 法不适用，改用 PB 或 PS，并写明“亏损公司 PE 无意义”。
- 区间要写适用条件：盈利可持续、净资产真实、行业分类未变；写失效条件：下一期亏损、重大减值、重组导致主业变化。
- 不写主观概率，不把区间中值说成“合理价”。

**完成判据**：区间可复算；每个假设与失效条件都写在表下。

## 第 9 步：输出

**文首 posture**：`decision-grade` / `review-ready` / `screen-grade` / `not-ready` / `blocked` 之一，说明哪个输入拖低了它。

**表结构**（列数控制在 10–12 列）：

| 公司 | 代码 | 层级 | 报告期 | 营收(亿元) | 归母(亿元) | 毛利率 | ROE | PE TTM | PB | 市值(亿元) | 数据日期 |
|---|---|---|---|---|---|---|---|---|---|---|---|

表下固定四块：

1. **口径**：报告期、利润口径、价格日、单位、复权。
2. **剔除**：每个被剔除公司的名字与理由；亏损、次新、壳价值可疑分别计数。
3. **统计**：n、25 分位、中位数、75 分位、剔除的极端值。
4. **局限**：哪些公司不可比、哪些字段取不到、板块涨跌幅限制对价格反应的影响（定性）。

**交接块**（给下游模型/备忘录）：

```
数据日期：价格 [日期]，财报 [报告期]
同行集合：core 名单；read-through 名单；excluded 及理由
统计量：所用档位（中位数/四分位/单一最可比）与数值
口径：归母或扣非；LTM 算法；单位
隐含区间：PE 法 / PB 法，及主体所用指标
限制：亏损、次新、壳价值、停牌、字段缺失
```

## 质量门槛

1. **数据日期**：每个倍数与财务数字都有日期；价格与财报日期不同时分别写。
2. **来源分层**：公告原文/三表 > 估值工具 > 行业估值表 > 卖方预测 > 媒体。冲突时并列，不平均；工具与原文冲突以原文为准。
3. **反证**：至少写一条能推翻“相对低估/高估”结论的反证（例如：主体盈利下修、同行样本变化、行业分类调整、一次性收益推高分母）。
4. **卖方预测声明**：凡用 `eps_forecast` 或评级，写“卖方预测汇总，不是事实”，给覆盖机构数与日期。
5. **口径一致**：同一列只有一个利润口径、一个报告期、一个单位；跨列比较前先换算。

## 不做的事

- 不把不同板块的涨跌幅限制当成估值调整因子。
- 不把亏损公司的负 PE 放进中位数，也不把“负 PE 取绝对值”当便宜。
- 不用 ST 股、次新股、停牌股做头部统计。
- 不在没有 EV 字段时编造 EV/EBITDA。
- 不写“目标价”“买入”“仓位”；需要评级时按人设规则另写，并带假设与失效条件。
