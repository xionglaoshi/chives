# A 股事件日历（catalyst-calendar）

只有日期的清单不是事件日历；事件日历是**决策压力排序**。一个事件值得进表，是因为它能改变盈利预期、叙事、估值、筹码、下行风险或流动性。**近不等于重要**：十一周后的高影响政策读数，排在周四的例行披露之前；例行披露放“卫生区”，不占主表。

证据标签、来源分层、新鲜度与就绪姿态遵循 `research-conventions`。解禁、分红、定增、并购、集采、关税等各类事件要填什么，见 `references/event-lenses.md`。

## 边界

- 只做研究，不下单；本 bot 有 `watch_plan_create` 时可以顺手建盯盘，规则见 `watch-briefing`。
- 日期必须带**日期类型**与**置信度**；“下半年”“月底前”不能写成某一天。
- 公司公告/交易所/监管原文优先于媒体与聚合器；两源冲突时都保留，取较低置信度。
- 政策日期读原文（`web_fetch` 公开页面），写发文号与生效日；取不到写“未取到原文”。

## 第 1 步：定范围

四件事，用户没说就按默认并披露：

- **标的范围**：代码清单、持仓/自选、行业板块、指数成分。
- **时间窗**：默认滚动 90 天；用户说“本周/本月”就按周/月。
- **是否含宏观与政策**：默认含“与标的直接相关的”政策与数据，不铺全市场日历。
- **输出对象**：自己看（可含持仓与观点）还是对外（只含公开日期与来源）。

**完成判据**：范围落到具名清单或板块代码；时间窗有起止日期；宏观/政策取舍写明；输出对象写明。

## 第 2 步：取事件并分类

### 数据来源

| 事件 | 工具/来源 | 口径 |
|---|---|---|
| 预约披露日 | `company_earnings(kind="schedule", code, period)` | 首次预约、历次变更、当前预约、实际披露日；改期要保留旧日期 |
| 业绩预告/快报 | `company_earnings(kind="forecast"/"express", code, period)` | 预告区间是原文；正式报告前只能按区间准备 |
| 定期报告/临时公告 | `company_announcements(code, start, end, category, limit)` | 类别：年报/半年报/一季报/三季报/业绩预告/权益分派/股东大会/增发/股权激励/解禁/可转债/风险提示等 |
| 解禁 | `company_holders(code, kind="lockup")` | 个股未来 90 天：`free_date`、`free_shares`、`free_ratio_pct`、市值；全市场用不带 code 的 `lockup` |
| 分红/送转 | `company_announcements(category="权益分派")` + 公告原文 | 预案/股东大会通过/实施三段分开；除权除息日以实施公告为准 |
| 定增/配股/可转债 | `company_announcements(category="增发"/"配股"/"可转债")`、`convertible_bonds(kind="list", underlying=code)` | 预案、受理、过会、注册、发行分开；可转债看下修/强赎/回售条款公告 |
| 股东大会 | `company_announcements(category="股东大会")` | 通知日、股权登记日、会议日、议案 |
| 龙虎榜/大宗 | `market_trading_activity(kind="dragon_tiger"/"block_trades")` | **已发生**的事件，用于复盘，不作为未来催化 |
| 宏观数据/政策会议 | 统计局、央行、发改委、财政部、交易所官网（`web_fetch`）；`news(kind="calendar", date)` | 只取与标的行业相关的；写发布机构、日期、市场预期（有则写） |
| 指数调整 | 中证指数公司/交易所公告（`web_fetch`） | 生效日与调入调出名单；不预测名单 |
| 新闻线索 | `news(kind="stock"/"flash", code)` | 只作线索，日期回公告核对 |

### 事件分组

- **业绩与披露**：预约披露、预告/快报、年报/季报、业绩说明会、投资者接待日。
- **公司行为**：分红（预案/通过/实施）、定增/配股、可转债（发行/下修/强赎/回售）、股权激励（授予/解锁）、回购、重大合同、诉讼、重组。
- **筹码**：解禁、大股东/董监高减持计划、质押、员工持股到期、指数调整带来的被动资金。
- **政策与监管**：行业政策、集采/招标、出口管制/关税、环保/安全督查、交易所问询与回复。
- **宏观**：与行业相关的价格（煤价/锂价/猪价）、利率（LPR/MLF）、PMI、进出口、社融；只列有传导链的。

### 日期类型与置信度

| 日期类型 | 呈现 |
|---|---|
| `hard` | 单一日期；有会议时段就写时段 |
| `window` | 起止区间；导出/日历也写区间 |
| `undated` | 无日期但影响大；进“待定”表，写什么能把它定下来 |

| 置信度 | 依据 |
|---|---|
| `confirmed` | 公告/交易所/监管原文写明 |
| `guided` | 公司说“预计/拟”，未给确切日 |
| `expected` | 可靠聚合器有，发行人未确认 |
| `inferred` | 按报告节奏/法定时限/合同推算 |
| `rumoured` | 媒体或市场传闻，无原文 |
| `undated` | 关键但无法定日期 |

**日期不是越硬越好**：把“下半年”渲染成某一天，是编造。改期要保留旧日期与变更来源。

**完成判据**：每个事件有分组、日期类型、置信度、来源与抓取日；无日期的关键事件在“待定”表。

## 第 3 步：打重要性分与行动性分

两个 1–5 分，按判断合并，不乘：

- **重要性**：能改变盈利预测、叙事、估值、下行风险、仓位、流动性或后续事件概率。5 = 改变逻辑；1 = 不影响跟踪。
- **行动性**：有多少准备时间、能否表达、是否具备决策输入。5 = 有准备时间且有可执行方案；1 = 事后才知道。

优先级 `P1/P2/P3`，各写一句理由。

**升级项**（任一触发就上调，并写明是哪条）：

1. 一周内且准备未完成。
2. 日期置信度低但重要性高。
3. 与另一个关键事件撞在同一周。
4. 预期波动大或标的流动性差。
5. 市场站位单边（拥挤、估值极端、一致预期集中）。
6. 不对称性未被一致预期反映。
7. 可能触发后续事件（如解禁后减持）。
8. 缺数据导致无法做风险决策。

**聚集**：同一天/同一周有两个以上相关标的事件，标“聚集”；聚集本身是一条催化。

**完成判据**：每行两个分数、优先级与理由、触发的升级项、聚集标记。

## 第 4 步：建表

主表字段：

| 日期 | 类型/置信度 | 标的 | 事件 | 分组 | 重要性 | 行动性 | 优先级 | 准备项 | 负责人 | 截止 | 支持什么决定 |
|---|---|---|---|---|---|---|---|---|---|---|---|

细节列（可放附表）：来源、抓取日、日期原文发布日、最近核对时间、事件后的确认/证伪阈值、与持仓/观点的关系。

- “卫生区”：例行、无决策含义的日期放表下，列出但不排序。
- “待定”表：无日期但重要的事件，写“什么能定日期”（公告、批文、会议议程）。
- 每个 `P1`/`P2` 行必须写“支持什么决定”，写不出就降级。

**完成判据**：主表每行有日期类型/置信度、优先级、决定；`P1`/`P2` 有准备项与截止日。

## 第 5 步：准备项与事件后动作

每个 `P1`/`P2` 一个准备项：产出物、负责人、截止日、支持的决定。没有截止日的准备项是愿望。

每个 `P1` 写事件块：

- **当前争论**：市场在争什么。
- **会看的 2–3 个数**：营收/毛利/订单/装机/价格/解禁比例。
- **预期框架**：公司指引/预告区间、一致预期（卖方汇总，带日期与机构数）、历史同期、我们的估计。
- **确认/证伪阈值**：哪个数字以上/以下改变判断。
- **事件后动作**：if 确认 → 做什么；if 证伪 → 做什么；写事件前，不临场编。

**完成判据**：`P1` 事件块齐全；阈值可观察；事件后动作两侧都写。

## 第 6 步：刷新不毁历史

刷新只追加：

- 日期变了：保留旧行，新增一行，写旧日期与变更来源。
- 来源不再支持：标 `stale` + 最后确认日，不删除。
- 置信度提升（`expected` → `confirmed`）：更新并写确认原文。
- 事件落地：标完成，记录实际结果 vs 预期，保留。

输出变更日志：新增/变更/标记各几行，逐条列。

**完成判据**：变更日志齐全；没有覆盖旧行。

## 第 7 步：输出与自检

默认 Markdown；需要排序/筛选时另存 CSV（`data/` 下），**不使用 Excel 工作簿**。路径遵守 T149。

```markdown
# <标的/板块> 事件日历（<起> 至 <止>）
- 数据时间：<抓取日>；就绪姿态：<...>
## 本周
## 未来 30 天（P1/P2）
## 31–90 天（P1/P2）
## 卫生区
## 待定（无日期）
## 变更日志
## 来源与缺口
```

自检：

- [ ] 每个日期有类型与置信度；`window` 写区间。
- [ ] 每个 `P1`/`P2` 有准备项、截止日、支持的决定。
- [ ] 每个 `P1` 有事件块与两侧动作。
- [ ] 宏观/政策只列与标的有关且有传导链的。
- [ ] 解禁有股数、占比、市值；分红分清预案/通过/实施。
- [ ] 龙虎榜/大宗标“已发生”，不当未来催化。
- [ ] 缺口写明试过的工具与返回，不用推测补日期。
- [ ] 对外版本不含持仓、成本、目标价、交易意图。
