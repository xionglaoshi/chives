# 盈利预测与一致预期

## 概述

围绕企业盈利预测和市场一致预期的偏差构建研究信号。核心逻辑：股价短期可能受
预期差驱动，但"预期差"不等于可交易收益；必须同时考虑数据可得性、交易成本、
T+1、涨跌停和信息扩散。

两条主线：
1. 自主预测 vs 一致预期，寻找偏差；
2. 跟踪分析师预期修正的方向和幅度。

**数据日期规则**：实际值用报告期；一致预期用快照日；价格用交易日。任何一条
没有日期的数字，都视为缺失。

## 核心概念

### 1. 自上而下预测法（Top-Down）

**预测链条：**

```
GDP/行业增加值增速 → 行业收入增速 → 公司收入增速 → 利润率假设 → EPS
```

**示例（假设数字，仅演示结构，不是对任何真实公司的预测）：**

| 层级 | 假设 | 依据/需要验证的数据 |
|------|------|---------------------|
| 宏观 | GDP +5.0% | 国家统计局支出法 GDP、最终消费/资本形成数据；引用时标年份和日期 |
| 行业 | 行业收入 +8% | 行业协会/统计局产量、价格、渗透率；不要用"消费占 GDP 65%"这类无来源数字 |
| 公司 | 收入 +12% | 量×价、产能、渠道、份额；与公司公告/调研一致 |
| 盈利 | 净利率 20% | 毛利率、费用率、税率；与历史/同业比较 |
| EPS | = 归母净利润/稀释股本 | 注明是否扣非、是否并表 |

消费占 GDP 的比重会随年份和统计口径变化。引用时从国家统计局支出法 GDP 数据
取当年值，并写"截至[年份]"，不要用一个固定的 65%。

**适用场景：** 行业 beta 判断、大盘盈利周期定位、宏观策略配合。

### 2. 自下而上预测法（Bottom-Up）

**收入拆解：**

```python
# 方法1：量价拆解
revenue = volume * price
# 例：煤炭/电力公司 = 销量 × 单价 + 其他业务收入

# 方法2：客户/产品拆解
revenue = sum(segment_revenue for segment in business_lines)

# 方法3：门店/用户拆解
revenue = stores * tables_per_store * turnover * ticket * operating_days
# 或 users * ARPU
# 餐饮门店必须包含"每店桌数/座位数 × 翻台率"，否则量纲不完整。
```

**利润率假设关键点：**
- 毛利率：原材料成本、产品结构、产能利用率、价格传导。
- 费用率：规模效应、研发投入、销售网络、股权激励。
- 税率：高新技术企业 15% vs 一般 25%；税收优惠是否有到期日；用实际税率
  而非法定税率做预测。

### 3. 标准化未预期盈利（SUE）

**公式：**

```python
surprise_t = actual_eps_t - consensus_eps_t

# 用该股票过去 8 个季度的"实际-预期"偏差的标准差做标准化
sue_t = surprise_t / std(surprise_{t-8 .. t-1})

# 约束：
# 1) 至少 8 个季度的历史偏差；不足则写"SUE 不可计算"。
# 2) std 接近 0 时（例如预期从不偏离），SUE 会爆炸；用
#    max(std, 0.01 * abs(mean_eps)) 兜底；若仍接近 0，标记 SUE 不可计算，
#    或改用"偏差/股价"的缩放口径，并写明口径。
# 3) 一致预期取中位数还是均值要写清楚；两者不可混用。
```

**信号阈值（待校准的默认参数，不是已验证的实证结论）：**

| SUE | 含义 | 研究含义 |
|-----|------|----------|
| > +1.5 | 明显高于预期 | 正向预期差，需查一次性项目/低基数 |
| +1.0 ~ +1.5 | 温和高于预期 | 弱正向，需看修正方向与估值 |
| -1.0 ~ +1.0 | 接近预期 | 无明确信号 |
| -1.5 ~ -1.0 | 温和低于预期 | 弱负向，需看是否一次性 |
| < -1.5 | 明显低于预期 | 负向预期差，需查原因与后续指引 |

阈值只是起点。用历史样本做校准，报告样本期、universe、持有期、成本和样本外
结果；没有校准就写"默认参数，未验证"。

### 4. 盈余公告后漂移（PEAD）

**现象：** 业绩公告后，超预期方向的股价漂移在部分市场/样本中被观察到，但
A股的结果混合，且受业绩预告、涨跌停、T+1、小盘流动性和信息扩散影响。不要
把它当成稳定规律，也不要用"30–60 个交易日"这种无来源的固定窗口。

**研究实现（参数化）：**

```python
# 事件日：业绩公告日（或业绩预告日，二者分开研究）
# 1. 计算 SUE 或"实际 vs 预告中值"的偏差
# 2. 事件窗口：CAR[-1,+1]、[0,+20]、[0,+40]、[0,+60] 分别报告
# 3. 基准：沪深300/中证500/行业指数，按市值/行业中性化
# 4. 交易假设：T+1、涨跌停无法成交、停牌、交易成本、滑点
# 5. 输出：样本期、样本量、IC/分组收益、样本外结果、失败情形
```

**A股注意事项：**
- 做空受限；研究信号时区分"多头组合"和"多空组合"的可行性。
- 业绩预告（1月底前，按交易所规则）通常早于正式报告；预告和正式报告是
  两个不同事件，不要混在一起。
- 年报集中在 4 月，信息拥挤；季报/中报的窗口不同。
- 涨跌停/停牌会导致"信号日无法成交"，回测要用可成交价。

### 5. 分析师预期修正动量

**三个指标（默认参数，需校准）：**

```python
# 1. 预期修正比率（ERM）
ERM = (上调家数 - 下调家数) / 总覆盖家数
# 默认：> +0.3 正面，< -0.3 负面；覆盖家数 <3 时不计算

# 2. 预期变化幅度
eps_change_pct = (new_consensus - old_consensus_30d_ago) / abs(old_consensus_30d_ago)
# 默认：> +5% 显著上调；分母接近 0 时改用绝对变化/股价

# 3. 预期离散度
dispersion = std(all_analyst_EPS) / abs(mean(all_analyst_EPS))
# 默认：> 0.3 分歧大，< 0.1 共识强；分母接近 0 时不计算
```

**研究信号（不是交易指令）：**
- 正向：ERM > +0.3 且 eps_change_pct > +5% 且 dispersion < 0.25
- 负向：ERM < -0.3 且 eps_change_pct < -5%
- 信号有效期：不要写死 60–90 天；按样本校准，报告衰减曲线。

## 分析框架

### 盈利分析四步法

1. **构建预测**：选择 Top-Down 或 Bottom-Up，输出 EPS 预测值和关键假设。
2. **获取一致预期**：Wind/Choice/东方财富/同花顺等；记录快照日、覆盖家数、
   均值/中位数。没有一致预期就写"取不到"，不要用实际值倒推"预期"。
3. **计算偏差**：SUE 或百分比偏差；同时看营收、毛利率、扣非净利，避免只看 EPS。
4. **形成研究结论**：信号方向、证据、不确定性、需要跟踪的下一期数据；不输出
   买卖评级。

### 财报日历（A股，按交易所规则；以最新公告为准）

| 时间 | 事件 | 研究用途 |
|------|------|----------|
| 1 月 31 日前 | 年报业绩预告（达到交易所规定的披露情形时） | 提前捕捉方向；预告精度低于正式报告 |
| 年报披露前 | 业绩快报（按交易所规则/公司自愿） | 比年报早，但仍是初步数据 |
| 4 月 30 日前 | 年报、一季报 | 确认实际值，研究 PEAD |
| 8 月 31 日前 | 半年报 | 中期验证 |
| 10 月 31 日前 | 三季报 | 全年进度与预期修正 |

- 年报"未在 4 月 30 日前披露"本身是风险信号，但要先看是否停牌/延期公告。
- 业绩预告的强制情形（如净利润为负、扭亏、同比变动超 50% 等）按交易所规则
  执行，不同板块可能不同；引用时给出规则名称和日期。
- 港股/美股：财年不同，按公司公告的 fiscal year 和交易所截止日处理，不要套用
  A股日历。

### 预期差研究组合（参数示例，不是实盘指令）

```python
config = {
    "universe": "沪深300/中证500，剔除ST、停牌、上市不足60日",
    "signal": "SUE > +1.5 或 ERM > +0.3",
    "max_positions": 20,
    "position_weight": "equal_weight",
    "holding_period": 40,          # 交易日，需做20/40/60敏感性
    "rebalance": "earnings_calendar",
    "cost_bps": 15,                # 单边，含佣金/印花税/滑点，按实际填
    "cannot_trade": "涨停/跌停/停牌顺延或剔除，按规则处理",
}
```

回测报告必须包含：样本期、universe、信号定义、持有期、成本、T+1、涨跌停/
停牌处理、样本外结果。没有这些，不能写"策略有效"。

### 分析师动量
- ERM：[+X.X]（过去 30 日 [N] 家上调/[M] 家下调，覆盖 [K] 家）
- 预期变化幅度：[+X%]

- [一次性收益、会计政策变更、商誉减值、低基数、覆盖不足、数据过期等]

## 注意事项

- 一致预期数据需要 Wind/Choice 等终端；免费源可能不及时，必须写快照日。
- SUE 需要至少 8 个季度的历史偏差；不足时不要硬算。
- 业绩预告和业绩快报比正式财报早，但精度较低；把三者分开研究。
- A股财报季信息拥挤（4 月/8 月），PEAD 信号可能互相干扰；按行业/市值中性化。
- 一次性损益（资产处置/政府补贴/投资收益）会扭曲 EPS；用扣非 EPS 并单独说明。
- 预期修正动量有自我实现/羊群效应；拐点识别比趋势跟踪更需要证据。
- 小市值股票分析师覆盖少（<3 家），一致预期统计意义弱；不要伪造覆盖家数。
