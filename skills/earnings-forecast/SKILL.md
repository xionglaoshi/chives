# 把今年的利润拆成能检查的假设

锁定公司、财年、披露截止日及预测指标。把已公布的累计值、管理层预告、各机构预测、自算结果分四栏。前三季度已披露时，单列四季度还需赚多少钱才会达到全年目标。累计报表先差分为单季，再和上年同季对照；模型里保留原始累计数以便复算。

**收入到利润。** 按主要业务写收入驱动。设备厂从期初在手订单、新签、取消、交付和验收推导收入；零售可用门店、客流和客单价。标明哪一个环节只有估计。用价格、材料成本和产能利用率推导毛利，再扣费用、税费和少数股东损益。一次性补偿、减值与公允价值变动另列。用同期间的加权股数算每股收益。

**检验市场预期。** 记录机构、发布日期、预测年度和口径，相同机构同一年度保留最新可见版本。列有效机构数、中位数、分布和最近上调或下调情况。解释“少一家机构加入统计”和“同一家下调预测”的区别。计算业绩超预期幅度前检查可比性及基数，预测接近零或由亏转盈时报告差额。

**交付可证伪的区间。** 基准、上行、下行各改变一组有证据的驱动，给出营收、毛利、归母利润、每股收益和对区间影响最大的变量。附一张核对表，写清哪份月度数据、订单公告或季报会先检验哪条假设。公告落地后保留原预测日期，记录误差来自数量、价格、成本还是确认时点。
