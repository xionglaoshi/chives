# A 股表达与风险预算（trade-pitch 参考）

本文件只写 A 股的交易机制与仓位算术；观点本身写在 `SKILL.md`。

## 1. 交易约束

| 约束 | A 股现状 | 对方案的影响 |
|---|---|---|
| 交收 | T+1，当日买入次日才能卖 | 当日冲高不能当日止盈；止损要留隔夜缺口 |
| 涨跌幅 | 主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST ±5%；新股上市前 5 个交易日不设涨跌幅 | 跌停时可能卖不出，止损价不等于成交价 |
| 最小单位 | 买入 100 股整手（科创板 200 股起、可 1 股递增，按现行规则核对） | 小资金无法精确按金额建仓 |
| 交易费用 | 佣金（含规费）、卖出印花税；具体费率以券商为准 | 高频/小额方案先算费用占预期收益的比例 |
| 做空 | 个股融券券源有限、成本高，普通账户不宜作为常规表达 | 看空写成“回避/减仓/不参与”，不写融券卖出 |
| 停牌/ST | 停牌期间无法交易；ST 与退市风险另有 5% 限制与投资者适当性 | 事件驱动方案先查停复牌与风险警示 |

## 2. 两种亏损上限

- **情景内上限**：悲观情景走完时最多亏多少。用于回答“这个位置能不能扛”。
- **绝对上限**：任何状态下最多亏多少。用于回答“隔夜跳空/跌停卖不出时还剩下多少”。

两者给出不同的仓位。用户没有说明时，**两个都算、都列**，不要替用户选一个。

## 3. 仓位算术

```text
每股风险 = 买入价 − 止损价
最大股数 = floor(单笔亏损预算 / 每股风险 / 100) × 100
占用资金 = 最大股数 × 买入价
```

再检查三条约束，取最小值：

1. 单票占总资产上限（来自 `risk-boundary` 或用户画像）。
2. 流动性：建仓/退出金额不超过该股近 20 日日均成交额的 10%（默认，可调）。
3. 跌停/停牌情形：若跌停价低于止损价，按跌停价重算每股风险，再算一次仓位。

**示例（仅为算术示例，不是建议）**：总资产 50 万元，单笔亏损预算 1% = 5,000 元；买入价 20.00 元，止损价 18.50 元，每股风险 1.50 元；最大股数 = floor(5000 / 1.50 / 100) × 100 = 3,300 股，占用 66,000 元（占总资产 13.2%）。若该股跌停价 18.00 元，按 2.00 元风险重算为 2,500 股。

## 4. 介入与退出的写法

- **介入**：条件句优先于限价单。“回踩 19.20–19.50 元且日成交额不低于近 20 日均值的 80%”比“19.35 元买入”更可执行。
- **止损**：价格止损（跌破支撑/固定百分比）与逻辑止损（证伪条件）分开写；价格止损用 ATR 或近期波幅定，不拍整数。
- **止盈**：分批，写清每批的触发价与剩余仓位的止损上移规则。
- **时间止损**：到某日期催化未出现即退出，避免“无限期等”。
- **缺口风险**：若重大公告在盘后发布，次日可能一字板；方案要写“无法成交时放弃，不追”。

## 5. 不可执行的写法

- “跌到 18 元止损”但该股连续跌停：要写“跌停无法卖出时，按次日集合竞价处理”。
- “买入 3 成仓”：没有总资产与风险预算，这个数字不可复核。
- “做空该股”：A 股个股没有便捷做空工具。
- “目标价 30 元，必到”：没有期限、没有驱动量、没有证伪条件。

以上为研究框架，不构成投资建议。
