# A 股交易观点（trade-pitch）

研究的终点是把分析变成**可执行的观点**：方向、与市场不同的地方、支撑它的证据、情景树、介入与退出条件、错了在哪一步认错、之后跟踪什么。本文只写“怎么把观点说清楚”，不写“买多少股”；仓位只以“占单笔亏损预算的比例”表达。

证据标签、来源分层、新鲜度与就绪姿态遵循 `research-conventions`。观点所依赖的深度分析应已有落盘文件；没有就先按 `stock-analysis`（快速版）或 `initiating-coverage`（完整版）补齐，缺哪块写哪块。A 股交易机制、两种亏损上限与仓位算术见 `references/expression.md`。

## 边界

- **只做研究，不下单、不连接券商、不承诺收益**。A 股个股没有便捷的做空工具，**不写“做空”“融券卖出”方案**；看空表达为“回避/减仓/不参与”，并写清触发条件。
- 每个价位带数据时间（`quote_time` 或 K 线日期）与复权方式；每个预测带假设。
- 一致预期是卖方汇总，不是事实；引用时写机构数与抓取日期。
- 不给“必涨/稳赚/目标一定到”；目标价是区间与条件，不是承诺。

## 第 1 步：定输入与姿态

先确认四件事；用户没说就按默认并在开头披露：

| 项目 | 来源 | 未说明时的默认 |
|---|---|---|
| 方向 | 用户或已有分析 | 已有分析倾向的方向，标为假设 |
| 期限 | 用户 mandate；没有则看催化 | 1–3 个季度 |
| 依赖的分析 | 指定文件或本会话已有结论 | 无；先补 `stock-analysis` 快速版，或标 `screen-grade` |
| 风险预算 | 用户口述/画像 | 假设单笔最大亏损为总资产的 1%，并写明是假设 |

姿态按 `research-conventions` 的表取一个：`decision-grade` / `review-ready` / `screen-grade` / `not-ready` / `blocked`。观点至少要有**当前价、估值锚、一个可验证的催化或数据点**；缺一项就降级并写明缺什么。

**完成判据**：方向、期限、依赖分析及其数据时间、风险预算四项都有值或已披露的默认值。

## 第 2 步：变体认知（variant view）

四栏，缺一栏就只是复述别人的观点：

1. **市场相信什么**：当前价格隐含了什么——需要多高的增速、多少利润率、什么预期。用 `company_valuation(scope="stock")` 的分位、`company_consensus` 的 EPS 预测与评级分布来量化，不用“市场情绪”四个字。
2. **我们相信什么**：同一个驱动量，我们的数字与依据（来自第 1 步的分析）。
3. **差距为什么存在**：披露滞后、口径误读、业务分类错误、被动卖盘、期限错配、事件未被定价。**说不出机制，多半是我们自己算错**。
4. **什么把它拉平**：有日期的业绩披露、政策落地、订单/价格数据、解禁与股东行为；标注“已确定/可能/传闻”。

**完成判据**：四栏都写；市场信念用数字表达并注明来源；差距有机制；拉平因素有日期或时间窗。

## 第 3 步：证据写成可证伪的句子

2–5 条主张，每条六列：

| 主张 | 今天的证据 | 证据标签 | 若成立意味着 | 检验指标 | 证伪条件 | 多久知道 |
|---|---|---|---|---|---|---|

要求：

- 每条主张都能被一个数据点杀死；“长期看好”“管理层优秀”不是主张。
- 证据标签用 `fact` / `company claim` / `street estimate` / `model-derived` / `judgement` / `assumption`；`needs-source` 不得出现在交付稿。
- 删掉任何一条会改变结论，说明这组主张是承重的。

**完成判据**：2–5 条，每条七列齐全，无 `needs-source`，且至少一条是反面证据（可能证伪当前观点）。

## 第 4 步：情景树

三档，每档从驱动量出发，不是给基准目标价打折：

| 情景 | 驱动量与水平 | 推到价格的算式 | 相对现价空间 | 概率 | 依据/来源 |
|---|---|---|---|---|---|
| 乐观 | | | | | |
| 基准 | | | | | |
| 悲观 | | | | | |

- 每档移动一个具名驱动量（收入增速、毛利率、估值倍数、政策力度），把算式写到价格，读者能自己改驱动量。
- 概率要么互斥且加总为 1，要么标“ illustrative skew”并不给加权值。
- **悲观情景要写生存性**：现金流、负债、到期债务、大股东质押/减持是否会在悲观情景下恶化；不能只写“跌到某某价”。
- A 股约束进情景：涨跌停、T+1、停牌、ST 与退市风险、解禁抛压。

**完成判据**：三档都有驱动量、算式、空间、概率与依据；悲观档写清“什么先坏、坏到什么程度”。

## 第 5 步：表达（介入、退出、仓位）

| 字段 | 写法 |
|---|---|
| 工具 | A 股普通股/ETF；不写期权、融券、场外结构 |
| 介入 | 条件句：“回踩 X 元且缩量”“突破 Y 元且成交额 ≥ Z”；附参考价与数据时间，分 1–2 批 |
| 目标 | 来自第 4 步基准/乐观情景的区间，不是一个点；写对应期限 |
| 止损 | 价格规则：跌破某支撑或买入价下方 N%（N 用该股 ATR 或近期波动定），写依据 |
| 重写条件 | 主张级：哪条证据被推翻就重新研究（对应第 3 步证伪条件） |
| 时间止损 | 到某个日期催化仍未出现，视同证伪 |
| 仓位 | “按止损距离计算，这笔最多占用单笔亏损预算的 X%”，不写“买 3 成仓” |
| 约束 | 哪一条限制了仓位：流动性、涨跌停、集中度、风险预算 |

仓位算法：`最大股数 ≈ 单笔亏损预算 ÷ (买入价 − 止损价)`，再按 100 股整手取整；同时检查单票占总资产上限（本 bot 有 `risk-boundary` 则按其口径，没有就用用户给的上限）。无法给出止损价时，不给仓位。

**完成判据**：介入、目标、止损、重写条件、时间止损、仓位六项齐全；仓位有算式；没有把“看空”写成做空。

## 第 6 步：跟踪与交付

| 触发 | 指标 | 阈值 | 来源工具 | 日期/窗口 | 触发后动作 |
|---|---|---|---|---|---|

- 第 3 步每条主张至少被一行触发覆盖；没有触发的证伪条件只是愿望。
- “什么会让我改变观点”单独一小段：2–3 条可观察事实，各带日期。
- 可以建盯盘（`watch_plan_create`），规则见 `watch-briefing`；说明只唤醒分析、不下单。
- 交付顺序：**结论先行**——第一段给方向、介入区间、目标区间、止损、姿态与数据时间；再写变体认知、情景、证据表、跟踪。落盘用 Markdown，路径遵守 T149 约定（`reports/<主题>/<YYYYMMDD>_交易观点.md`）。

**完成判据**：第一屏能独立读懂观点；每条主张有触发；交付文件路径与数据时间齐全。

## 常见错误

- **把“便宜”当理由**：估值分位低只是必要条件，还要写清什么会让它修复。
- **目标价没有算式**：只给数字不给驱动量，等于编。
- **止损与逻辑脱节**：价格止损和基本面证伪要分别写，不能互相替代。
- **忽略 T+1 与涨跌停**：介入/退出条件要能在真实交易规则下执行。
- **看空写成做空**：A 股个股缺乏便捷做空工具，表达为回避/减仓。
