# 财报三表解读

## 概述

从三张报表（利润表、资产负债表、现金流量表）的勾稽关系出发，分析盈利质量，
识别需要进一步调查的会计信号，用杜邦分析分解盈利驱动因子。红旗是**调查线索**，
不是造假结论；任何结论都必须落到报表期次、科目名和数值。

## 三表核心框架

### 利润表（赚了多少）

```
营业收入
 - 营业成本
 - 税金及附加
 - 销售费用 - 管理费用 - 研发费用 - 财务费用
 + 其他收益
 + 投资收益 + 公允价值变动收益
 - 信用减值损失 - 资产减值损失
 + 资产处置收益
 = 营业利润
 + 营业外收入 - 营业外支出
 = 利润总额
 - 所得税费用
 = 净利润
 - 少数股东损益
 = 归属于母公司股东的净利润
```

**关键比率**：

| 比率 | 公式 | 观察方式 |
|------|------|----------|
| 毛利率 | 毛利/营收 | 与自身历史、同业比较；连续下滑要问原因 |
| 净利率 | 净利/营收 | 行业差异大；看趋势与驱动，不用固定"优秀线" |
| 期间费用率 | (销售+管理+研发+财务费用)/营收 | 看结构变化；财务费用受杠杆与利率影响 |
| 扣非/归母 | 扣非净利/归母净利 | 低于 80% 说明非经常性损益占比高，需逐项看 |

### 资产负债表（有什么家底）

```
资产 = 负债 + 所有者权益

资产端重点:
- 货币资金: 是否受限？与有息负债、利息收入是否匹配？
- 应收账款: 增速是否超过营收？账龄与坏账准备是否变化？
- 存货: 是否积压？跌价准备是否充分？
- 商誉: 并购溢价，减值测试假设是否激进？
- 在建工程: 是否长期不转固？利息资本化是否异常？
- 其他应收款/预付款: 是否流向关联方？

负债端重点:
- 有息负债: 短期借款+长期借款+应付债券+一年内到期非流动负债
- 应付账款: 对上游议价权
- 预收/合同负债: 对下游议价权
- 或有负债/担保: 表外风险
```

**关键比率**：

| 比率 | 公式 | 观察方式 |
|------|------|----------|
| 资产负债率 | 负债/资产 | 与同业和自身历史比较；金融企业不适用 |
| 流动比率 | 流动资产/流动负债 | 行业差异大；看趋势与现金质量 |
| 速动比率 | (流动资产-存货)/流动负债 | 存货占比高的行业要结合存货周转 |
| 有息负债率 | 有息负债/总资产 | 与利息保障倍数一起看 |

### 现金流量表（真正拿到多少现金）

```
经营活动现金流(CFO): 做生意赚的现金
投资活动现金流(CFI): 买卖资产花的现金
筹资活动现金流(CFF): 借钱/还钱/分红

长期关系: 净利润 ≈ CFO（不是每一期都相等）
```

**现金流质量矩阵**（方向组合，不是精确预测）：

| CFO | CFI | CFF | 常见状态 |
|-----|-----|-----|----------|
| + | - | - | 经营赚钱、投资、还债/分红 |
| + | - | + | 扩张：经营赚钱、投资、融资 |
| + | + | - | 收缩/回收投资、还债 |
| - | - | + | 经营失血、仍投资、靠融资 |
| - | + | + | 卖资产+融资维持 |
| - | + | - | 卖资产还债 |

## 三表勾稽关系

### 核心勾稽

```
1. 利润表 → 资产负债表
   净利润 → 未分配利润增加（扣除分红后）
   应收增加 ≈ 收入 - 实际收款（还受票据、预收、并表范围影响）
   存货增加 ≈ 采购 - 已售成本（还受跌价准备、并表范围影响）

2. 利润表 → 现金流量表
   净利润 + 折旧摊销 ± 营运资本变动 ± 非现金项目 ≈ 经营现金流
   差异大 → 盈利质量存疑，但要先排除并表、汇率、一次性项目

3. 资产负债表 → 现金流量表
   现金及现金等价物净增加额 = CFO + CFI + CFF + 汇率变动影响
   期末现金及现金等价物 = 期初 + 上述净增加额
```

**注意**：现金流量表勾稽的是"现金及现金等价物"，不是资产负债表的"货币资金"。
货币资金包含受限资金（保证金、冻结存款、募集资金专户等），两者不应直接相等。

### 勾稽验证公式

```python
# 盈利质量（应计）
accrual_ratio = (net_income - cfo) / ((total_assets_t + total_assets_t1) / 2)
# 经验观察：>10% 说明应计占比偏高，需要看应收/存货/一次性收益；
# 这是启发式，不是造假证据。

# 收入质量
receivable_growth = accounts_receivable.pct_change(fill_method=None)
revenue_growth = revenue.pct_change(fill_method=None)
# 应收增速持续高于营收增速 → 收入质量可能恶化

# 现金勾稽（单位：元）
cash_change = cash_and_equivalents_end - cash_and_equivalents_begin
cf_total = cfo + cfi + cff + fx_effect_on_cash
# 容差建议：abs(cash_change - cf_total) > max(10_000, 0.001 * cash_and_equivalents_end)
# 超过容差 → 先查科目口径、并表范围、受限资金，再判断数据问题
```

## 盈利质量分析

### 应计 vs 现金流

```
较高质量:
- CFO / 净利润 > 1.0（长期平均，单期可能受营运资本波动）
- 应收账款增速低于营收增速
- 经营现金流持续为正

需要调查:
- CFO / 净利润在 0.5–1.0，且连续多期偏低
- 应收/营收比例持续上升
- 利润依赖一次性收益（投资收益、资产处置、政府补助）

弱:
- CFO / 净利润 < 0.5
- CFO 连续为负而净利润为正
- 应收、存货、其他应收款同时异常上升
```

### 盈利质量评分卡（启发式，未经验证）

| 指标 | 3 分 | 2 分 | 1 分 | 权重 |
|------|------|------|------|------|
| CFO/净利润 | >1.0 | 0.5–1.0 | <0.5 | 25% |
| 应收增速 vs 营收 | 应收更慢 | 同步 | 应收更快 | 20% |
| 扣非/归母 | >90% | 70–90% | <70% | 20% |
| 经营现金流趋势 | 连续改善 | 波动 | 恶化 | 20% |
| 存货周转 | 加快 | 稳定 | 放慢 | 15% |

评分只是把多个观察压缩成一个排序工具，权重没有统计验证。评分低时写
"需要进一步核查哪些科目"，不要写"盈利质量差，建议回避"。

## 财务造假红旗清单

以下每一项都是**筛查线索**，需要证据才能升级为判断；健康公司也可能同时出现
两三项。不要用红旗数量推算"造假概率"。

| # | 红旗 | 要查的证据 |
|---|------|-----------|
| 1 | 存贷双高 | 货币资金与有息负债同时处于同业高位；利息收入/利息支出是否匹配；受限资金比例 |
| 2 | 应收暴增 | 应收增速持续高于营收；账龄、坏账准备、前五大客户、期后回款 |
| 3 | 存货异常 | 存货/营收突然上升；跌价准备、库龄、期后销售 |
| 4 | 经营现金流背离 | CFO 连续为负而净利润为正；营运资本项目与收入是否匹配 |
| 5 | 关联交易占比高 | 关联方名称、定价、资金流向；与同业比较 |
| 6 | 频繁更换审计师 | 3 年内更换次数、更换原因、前任是否保留意见 |
| 7 | 在建工程不转固 | 在建工程/固定资产、转固时点、利息资本化、产能是否投产 |
| 8 | 预付/其他应收异常 | 对象是否关联方、账龄、期后结转 |
| 9 | 少数股东损益异常 | 少数股东损益与少数股东权益是否匹配；是否存在表外安排 |
| 10 | 审计意见 | 保留/否定/无法表示意见；关键审计事项 |
| 11 | 研发资本化率过高 | 资本化政策、同行业对比、摊销年限 |
| 12 | 商誉占比高 | 商誉/净资产、标的业绩承诺完成情况、减值测试假设 |

处理方式：每条红旗写"触发/未触发/无法判断 + 证据 + 需要补充的数据"。无法判断
就写"无法判断"，不要用"低/中/高概率"。

## 杜邦分析

### 三级分解

```
ROE = 净利率 × 总资产周转率 × 权益乘数

ROE = (净利润/营收) × (营收/总资产) × (总资产/净资产)
      盈利能力        运营效率        杠杆水平
```

### 五级分解

```
ROE = 税务负担 × 利息负担 × 营业利润率 × 资产周转率 × 权益乘数
    = (净利/税前利润) × (税前利润/EBIT) × (EBIT/营收) × (营收/总资产) × (总资产/净资产)
```

### 杜邦分析模板

```markdown
### 杜邦分析: [公司名]  (报告期: [YYYYA/YYYYQN])

| 指标 | [上期] | [本期] | 变化 | 驱动判断 |
|------|--------|--------|------|---------|
| ROE | ... | ... | ... | ... |
| 净利率 | ... | ... | ... | ... |
| 资产周转率 | ... | ... | ... | ... |
| 权益乘数 | ... | ... | ... | ... |

结论: [哪一项驱动了变化；哪些是会计口径/并表范围变化；数据缺口]
```

不要用固定的"行业典型 ROE"表给公司下结论；ROE 受会计口径、杠杆、周期和并表
范围影响，必须与同口径同业和自身历史比较。

## 数据获取与口径

- 首选 `company_financials`（资产负债表/利润表/现金流量表/关键指标）。
  记录：报告期、报表类型（合并/母公司）、币种、字段后缀（`_yuan`/`_pct`）。
- 港股/美股没有对应网关时，用 `web_fetch` 抓公司 filing 或交易所公告，记录
  会计准则（CAS/IFRS/US GAAP）和币种。
- 缺失科目写"缺失"，不要当 0；口径不一致（如并表范围变化、会计政策变更）要

- 每个结论性数字带 `as_of`/报告期；价格与市值另带交易日期。

## 注意事项

1. **会计准则差异**：A股用中国企业会计准则，港股/美股用 IFRS/US GAAP；比较时
   先调整口径。
2. **季度数据看同比**：季节性因素大，环比波动不代表趋势。
3. **银行/保险特殊**：三表结构与一般企业不同，不适用传统勾稽与杜邦分析。
4. **重资产 vs 轻资产**：资产周转率跨行业不可比，同行业内比较才有意义。
5. **并表范围变化**：新收购/处置子公司会导致同比不可比，需看可比口径。
6. **审计意见优先**：非标准意见比任何比率都重要，先读审计报告。
7. **与 valuation-model 的分工**：本 skill 判断"数字是否可信、质量如何"；
   valuation-model 判断"这些数字值多少钱"。目标价与评级放到估值步骤里给，财务分析本身聚焦数字质量。
