# 公司赚的钱最后去了哪里

先读报告封面和审计意见，记录合并主体、报告期、货币单位、披露日期和追溯调整。使用获授权的 `company_financials` 或财务取证工具，再核对公告页码。财务报表是累计数就按同期累计比较；拆单季时用同一年度相邻累计数相减。年末资产、平均资产和当期利润分别保留。

**沿一笔销售穿过三张表。** 收入确认在哪个交付环节？尚未收款的部分落在应收账款、票据或合同资产的哪一项？经营现金流量表的销售收现包含哪些税费与预收？列出两期归母与扣非利润、毛利、经营现金流、应收和合同负债。把净利润与经营净现金流之间主要差额落到折旧、减值、存货和应收应付的变动。并表或币种变化时解释差额。

**做三项勾稽。** 核资产与负债加权益，核期初现金加净流量及汇率影响与期末现金，再核利润、分红及其他权益变动与期末权益。资产负债表的货币资金可能包含受限资金，不能直接等同现金等价物。ROE 分解用相同合并口径的利润率、资产周转率和权益乘数，注明平均余额算法。银行、保险企业按其报表结构看资产质量和资本约束。

**异常要有证据。** 收入涨而回款慢时查账龄、集中度、减值政策和期后收款。库存增加时查在手订单、发货、验收、跌价准备和取消记录。用 `special_financials` 或公告原页定位置，标清金额、分母、日期与已到账部分。红旗只提示待核事项。交付一张口径表、一条最能解释利润与现金差异的证据链，以及下一期该追的指标。
