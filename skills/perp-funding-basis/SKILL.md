# 两个报价之间的差额能不能兑现

确定平台、标的、报价币、正向或反向合约、乘数、标记价与指数口径。取同时间的现货、合约买卖价、已结算费率、下次预计费率和实际结算间隔。公开 API 的响应码、采集时间及历史覆盖按原样记录。已挂载的行情技能含相应接口和字段。若用公开网页取证，只读报价、市场规则及官方规格。

**先统一符号。** 以持有多头或空头的一方记账，正费率下的实际收付方向按该交易场所规则核实。逐个结算时点用名义本金乘当期费率，区分已结算、下一期预估和延展假设。用一年的小时数除以该合约真实结算间隔才可作简单年化；间隔变化时用实际时间加总。把当前值放回自己的历史分布，标注分位与覆盖区间。

**再对齐价格。** 同币种基差为合约价减现货价，除现货价得相对基差。定期合约按距到期天数估计年化，永续没有固定到期日。分别测算建仓与退出价差、双边手续费、借币利息、滑点、资金费翻转和补保证金。跨平台比较使用共同结算窗口，列抵押品、划转延迟和强平规则；名义中性仍可能被其中一条腿先行平仓。

把持仓量与价格、费率一起读。持仓量上升和正费率只说明未平仓规模与资金成本变化，方向需要额外成交证据。交付每个名义单位的现金流明细、能覆盖成本的最低费率，以及样本未覆盖的风险。此流程仅用于研究。
