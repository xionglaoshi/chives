# 这笔股息由谁付、能付多久

读者买的是哪种股份，在哪天按什么价格衡量股息？从公告逐笔登记所属年度、每十股现金额、币种、股权登记日、除息日和付款日。董事会预案、股东大会通过、已实施分三栏；中期、特别和年终分红分别登记。同一方案多次公告用实施公告更新原行。送股、转增股本单列，不能当成收到的现金。

**按持股单位算。** 每十股现金除以十得每股股息。过去十二个月实际现金股息除指定日未复权价格，得到历史股息率。预案通过后可能收到的金额另算前瞻股息率；跨币种写汇率日期。税前与税后分别列，只有在投资者身份、持股时间和适用规则核实后才估税后现金。除权价格跳变不能算成额外收益。

**找钱。** 展示至少三个可比年度的现金分红总额、归母利润、经营净现金流、资本开支及净负债，单独列示特别股息。利润为负时派息率失去比较意义；说明是用过去留存、卖资产还是新增融资支付，并回到公告验证。银行和保险公司应查资本约束与可分配利润，经营现金流不能照搬工业口径。

**给股息率做压力测试。** 用正常经营、利润下行、资本开支上升三种假设，对照历史每股股息和管理层可核实的分红承诺。价格大跌抬高的收益率、一次性处置抬高的利润都要单列。交付实际收到的钱、下一笔付款的条件、派息削减的最早可见信号和公告出处。
