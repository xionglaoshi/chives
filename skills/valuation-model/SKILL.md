# 个股合理估值

收到沪深北个股的估值问题、筛选条件涉及合理价、或用户点击「立刻测算」，先调用 `estimate_equity_value(code, as_of)`。默认当前日期，关注任务使用请求指定的北京时间日期。所有渠道使用同一工具及版本。

先报告工具的币种、数据截至日和价格区间。优先展示已校准的 `dynamic`。若仅有 `static`，标注「静态参考，动态待校准」，说明定价分母、同行样本和关键假设。两项皆空时，报告 `reasons` 指出的缺口。按需用 `research_snapshot` 查 `input_snapshot` 的公开依据。个人偏好影响安全边际与解读，市场估值本身对所有用户相同。

关注任务把原样返回的 `valuation_id` 交给 `save_watchlist_estimate`，价格与 20 日方向均由服务读回。亏损公司的可比 PS 用已披露营收和同行利润率定价，需说明利润改善假设。出现盈利法和营收法区间不重合时披露分歧。按 `outlook.label`、`outlook.score`、`outlook.method` 解释后市；报告 `outlook_backtest` 的命中数、总数及基准，新股特别说明实际回放次数。这个判断预测未来 20 个交易日的收盘中位数，本版正式方向主要是个股历史基准倾向。组合信号只作研究对照；历史频数和分档没有校准为未来概率。

## 解释差异与自定义情景

记下估值日、股价、币种、可稀释股数、净债务、报表截止日和实际可见的报告。标明每个输入来自披露、用户还是研究假设。先说明价值由什么驱动。成熟制造业可预测经营现金流，银行可用 PB 与可持续 ROE、股利折现或剩余收益，多业务集团可分部估值。亏损、周期谷底或资产重组中的公司先问分母何时能恢复正常。

**把现金流折回来。** 工业企业 FCFF 可从税后经营利润加折旧摊销、减资本开支和营运资本净增加得到。将逐年的 FCFF 按同币种 WACC 折现，终值使用最后一年常态现金流。永续增长法要求 WACC 大于增长率。企业价值扣有息债务和少数权益、加非经营资产后才是可归属普通股的价值。使用股东现金流或股息时改用股权成本。使用 `discounted_cashflow` 或 `valuation_scenarios` 复核用户另行指定的情景，注明假设和终值占比。这些补充结果单独展示，关注列表以测算器回执为准。

**用另一把尺复核。** 盈利稳定时核 EPS×PE，资产驱动企业核 PB 与回报率，EV/EBITDA 比较先统一租赁和债务口径。历史估值分位注明窗口与当时可见的分母。分部估值分别注明业务、方法和股权比例，然后扣除总部及净债务，避免重复计价。

**交付区间与分歧。** 列基准、上行和下行三档，走一遍折现率与长期增速的二维敏感性；使用退出倍数时改动退出倍数。说明当前价格需要怎样的收入增长、利润率或资本投入。如果同行法与现金流法差得很大，指出哪一个假设能够解释差额以及用什么数据检验。
