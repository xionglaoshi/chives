# 市价要求这门生意做到什么

记下估值日、股价、币种、可稀释股数、净债务、报表截止日和实际可见的报告。标明每个输入来自披露、用户还是研究假设。先说明价值由什么驱动。成熟制造业可预测经营现金流，银行可用 PB 与可持续 ROE、股利折现或剩余收益，多业务集团可分部估值。亏损、周期谷底或资产重组中的公司先问分母何时能恢复正常。

**把现金流折回来。** 工业企业 FCFF 可从税后经营利润加折旧摊销、减资本开支和营运资本净增加得到。将逐年的 FCFF 按同币种 WACC 折现，终值使用最后一年常态现金流。永续增长法要求 WACC 大于增长率。企业价值扣有息债务和少数权益、加非经营资产后才是可归属普通股的价值。使用股东现金流或股息时改用股权成本。用获授权的 `discounted_cashflow` 或 `valuation_scenarios` 复算，列出终值占比。

**用另一把尺复核。** 盈利稳定时核 EPS×PE，资产驱动企业核 PB 与回报率，EV/EBITDA 比较先统一租赁和债务口径。历史估值分位注明窗口与当时可见的分母。分部估值分别注明业务、方法和股权比例，然后扣除总部及净债务，避免重复计价。

**交付区间与分歧。** 列基准、上行和下行三档，走一遍折现率与长期增速的二维敏感性；使用退出倍数时改动退出倍数。说明当前价格需要怎样的收入增长、利润率或资本投入。如果同行法与现金流法差得很大，指出哪一个假设能够解释差额以及用什么数据检验。
