# Bot 模型与 dsh 内核

Chives 本体和所有 Bot 使用 DeepSeek Harness（dsh）。在[Bot市场](http://127.0.0.1:8888/#/bots)打开 Bot 档案，可以跟随全局默认模型、指定一条已经保存的模型连接，或在当前供应商下填写模型 ID。指定连接的 Bot 使用该连接的接口地址、协议、模型和凭据。切换全局默认连接后，已绑定其他连接的 Bot 继续使用自己的连接。每次新任务按 Bot 权限加载相应技能和工具。

Bot市场的名册由系统部署维护。新增 Bot 时，维护者在 `bots/<id>/bot.yaml` 部署定义及其引用文件，再重启 Chives 服务读取名册。用户可在Bot市场聘用或解聘已部署的 Bot。总调度为常驻成员。

## 版本和更新

在[本机设置](http://127.0.0.1:8888/#/settings?tab=kernels)的「Agent 设置 → 内核设置」查看当前版本。「检查更新」读取 npm 上 `@deepseek-ai/dsh` 的 latest 标签，可能包含候选版本。只有点击「升级到指定版本」才会安装。Chives 验证 CLI 版本并在临时目录完成 ACP 初始化，再原子写入版本号。安装或握手失败时继续使用原版本。忙碌的 Bot 结束本轮后再重启执行进程。

## 为每位 Bot 选择资产

在档案展开「技能、工具与 Bot 指令」。「使用全部技能」包含以后放入 `skills/<技能名>/SKILL.md` 的方法；也可以关闭此项，只勾选该 Bot 需要的方法；工具控制读取方法、生成报告、读写记忆和查询资料；MCP 控制可以接触哪些业务服务。选择的数据库同时受「查询本地数据库」开关控制。取消一个选项后保存，新任务使用新配置；运行中任务须先结束。带审批的交易或修改操作按 dsh 审批流程执行。

- Bot 指令存入 `data/bots/<id>/profile/AGENTS.md`。首次按该 Bot 的职责创建。系统把它与公共规范、Bot 人设、默认任务提示词一起交给选定的内核。默认任务提示词的出厂文本在 `bots/<id>/task-prompt.md`，个人修改保存在同一 Bot 的 `profile/resources.json`。
- 私有记忆沿用 `data/bots/<id>/memory/` 和工作台的记忆服务。选择「保存 Bot 记忆」后写入的内容仍受任务身份、证据及委派权限约束。工作区、个人交付物和内核会话也按 Bot 分开。恢复个人配置时应一并恢复该 Bot 的数据目录与主数据库。
- 资料库可以选本 Bot 资料库、已存在的市场监控库和策略结果库。管理员可将不含其他 Bot 私聊或密钥的独立 SQLite 文件放在 `data/library/`，以字母、数字、下划线或连字符命名，后缀为 `.sqlite`，重新打开档案后按 Bot 授权。只读工具能列出表、抽样读取指定表，单次最多 50 行。空表表示未录入数据。
- 当前 Bot 使用一条默认任务提示词，另可在既有定时任务中配置各任务的具体提示词。每位 Bot 可以绑定不同供应商的已保存连接。

## 安装和恢复

在 Mac 准备 Node、npm、pnpm、uv，运行[安装脚本](../scripts/install-chives.sh)。默认版本见 `config/dsh-version`，用户选定的版本保存在 `data/harness/dsh/version`。恢复工作台时同时恢复版本文件、Chives 主数据库、Bot 工作区及本机凭据，再运行 `scripts/run-dsh.sh --version` 核对。模型连接及凭据需要按备份方式分别恢复。迁移旧版本时，原有 Bot ID、模型 ID、历史会话和记忆继续沿用。

调试科研任务时，固定数据快照、工具权限和题目，只更换模型来比较结果。可先让两位 Bot 各从获准数据库读回一个随机数，再用同一份公告核对关键数字与页码。见[设置中心](设置中心.md)和[投研工具](投研工具.md)。
