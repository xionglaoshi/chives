# Chives 工作台

默认主题跟随系统，浅色界面以白色和中性灰为主。工作台的字标是「老韭菜 · Chives」，涨跌颜色、字号和主题在[设置中心](设置中心.md)调整。

左侧列出 Bot。用户进入一个 Bot 后，通过会话、研究报告、工具调用记录和 Bot 档案查看工作结果。图表标明观测时间和单位，风险和运行状态使用文字或图形辅助辨识。详见[Bot 配置](专家内核与配置.md)。

盯盘面板中，指数、市场宽度和告警摘要置于顶部，待处理信号优先显示。窄屏按阅读顺序排列。实际面板实现见[盯盘组件](../packages/watch-panel/README.md)。研究报告图表的制作要求见[排版技能](../skills/ui-design/SKILL.md)。
