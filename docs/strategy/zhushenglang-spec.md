# 首板观察池与主升浪阶段池：规则规格 v1

> 状态：**v1 冻结**（2026-11-17，用户确认按 `docs/zhushenglang-plan.md` 第 2 节建议口径）。来源：用户提供的《首板观察池与主升浪阶段回测规则》说明与规则总表。
> 本规格是规则引擎的唯一依据。引擎实现与本文不一致时以本文为准；要改规则先改本文并升版本号。
> 用途：构造历史筛选与复核样本。不代表形态有效或收益保证。先输出逐事件记录与 K 线标注，再评估收益；不得用未来涨幅回头筛选入池。

## 0. 记号与口径

| 记号 | 含义 |
|---|---|
| `t` | 市场交易日（沪深交易所日历）。所有"第 n 日""后续 3 日"都按**市场交易日**计数，停牌日照样占用 |
| `bar(s,t)` | 股票 s 在 t 日的日线；不存在即停牌 |
| `C_t, L_t, H_t, V_t` | **前复权**收盘价、最低价、最高价，成交量（股）。支撑、突破线、均线、涨幅、回撤全部用前复权价 |
| `R_t` | **未复权**收盘价，只用于涨停识别 |
| `MAn_t` | 截至 t 的 n 根**有效 K 线**（跳过停牌）前复权收盘均值；不足 n 根时无定义，相关条件按不满足处理 |
| `limit_up(t)` | `R_t == LU_t`，精确到分 |
| `LU_t` | `round_half_up(R_{t−1}' × (1+p), 2)`，`R_{t−1}'` 为上一有效 K 线的未复权收盘价；`p` 见下表 |
| 比较 | "高于/低于"一律严格不等；"站回/收复"要求严格高于；收盘价等于支撑价或均线**既不算跌破也不算站回** |

涨跌幅比例 `p`（按 t 日适用规则）：

| 板块 | 规则 |
|---|---|
| 沪深主板 | 10%；ST/*ST 5% |
| 创业板 | 2020-08-24 及以后 20%（含 ST）；之前 10%（ST 5%） |
| 科创板 | 20% |

**股票池**：沪深主板、创业板、科创板；排除北交所、ST/*ST（按当日名称前缀近似，报告注明）、退市整理期、在 t 日上市不足 60 个市场交易日的股票。

**一只股票同一时间只有一个"轮次"**：已在首板观察池或主升浪池中时，不产生新的首板。

## 1. 首板识别（F 日）

在 F 日同时满足：

1. `limit_up(F)`；
2. 前 10 个市场交易日 `F−10 … F−1` 内没有任何 `limit_up`（停牌日视为非涨停）；
3. 窗口 `W = {F−10 … F−1}` 内至少 6 根有效 K 线；
4. 回撤：设 `M = max(C_j, j∈W)`，其最后一次出现在 `j_M`；`m = min(C_j, j∈W, j > j_M)`；要求 `j_M < F−1` 且 `3% ≤ (M − m)/M ≤ 15%`；
5. 黄金坑：`G = min(C_j, j∈W)`，其最后一次出现在 `j_G`；要求存在 `j ∈ W, j > j_G` 使 `C_j > G`（即低点不能在首板前一日）。

记录：`F`、`C_F`、`L_F`（首板日最低价）、`G`、`M`、`m`、回撤值。

## 2. 分流（F+1 日）

- `limit_up(F+1)` → **二板**：直接进入主升浪池，入池日 `E = F+1`，基准价 `B = C_F`。不进入首板观察池的支撑与确认流程。
- 否则（含 F+1 停牌）→ 进入**首板观察池**，第 1 个观察日为 `F+1`。

## 3. 首板观察池

### 3.1 期限
`k(t)` = t 是 F 之后的第几个市场交易日（`F+1` 为 1）。未启动且未移出的股票在 `k = 45` 收盘后到期移出。

### 3.2 启动（即突破标记，两者为同一事件）
- 突破线 `Hb(t) = max(C_j, F ≤ j ≤ t−1)`，含首板日收盘，只计有效 K 线。
- 首次出现 `C_t > Hb(t)` 的日子记为 `T*`，标记价 `P* = C_{T*}`，之后不更新、不重启。
- 启动后：进入主升浪池（`E = T*`，`B = P*`）；不再受 45 日期限约束；停止支撑监控（3.3）；进入突破确认（3.4）。

### 3.3 支撑监控（仅未启动期间）
两条支撑各自独立：`S1 = G`（黄金坑低点），`S2 = L_F`（首板日最低价）。
- 状态：`正常 → 观察中 → 收复 / 最终破位`。
- `C_t < S` 且当前为"正常"：首次跌破，观察日为 `t+1, t+2, t+3`；任一观察日 `C > S` 即收复（回到正常，记"已收复过"）。
- 三个观察日都没有收复：第 3 个观察日收盘后**最终破位，移出首板观察池**。
- 已收复过后再次 `C_t < S`：`S1` 立即最终破位并移出；`S2` 重新开始 3 日观察（可反复）。

### 3.4 突破确认与优先级（T* 之后）
- 确认窗口 `T*+1, T*+2`：任一天 `limit_up` → **优先级一**（在该日确定）；否则两天都 `C > P*` → **优先级二**（在 `T*+2` 确定）。
- 都不满足（含只有一天高于 `P*`、窗口内停牌）：再看 `T*+3 … T*+5`，任一天 `C > P*` → **普通观察级**（保留原 `P*`，不再重新确认）；否则 `T*+5` 收盘后**移出首板观察池排序**。
- 这一移出只影响首板观察池；股票是否留在主升浪池只由第 5 节决定。
- 确认窗口内（尚未确定）显示为"确认中"，按普通观察级的分数参与排序。

### 3.5 普通观察级评分（每日收盘计算，0–100 整数）

| 分项 | 权重 | 计算 |
|---|---|---|
| 支撑分 `Ss` | 30% | 两条支撑都没有最终破位 100；一条 50；两条 0。观察中不扣分 |
| 均线分 `Sm` | 15% | 收拢日：`max(|MA5−MA20|, |MA10−MA20|) / MA20 ≤ 4%`。t 日"满足"= `t−2 … t` 三个市场交易日中至少 2 日为收拢日。观察期内（`k ≥ 1`）任一日满足 → 100 并保留到本轮结束，否则 0 |
| 时效分 `St` | 45% | 未启动：`100 − (k−1) × 100/44`（k=1 为 100，k=45 为 0）；已启动：固定为 `k(T*)` 对应值 |
| 量能分 `Sv` | 10% | 启动前 0。启动日量比 `VR = V_{T*} / mean(最近 5 根 V>0 的有效 K 线，均在 T* 之前)`；`VR ≥ 1.5` 100，`1.0 ≤ VR < 1.5` 50，`< 1.0` 0；之后固定 |

- 总分 `S = 0.30·Ss + 0.15·Sm + 0.45·St + 0.10·Sv`，四舍五入为整数（0.5 进位）。
- **保底**：若 `k ∈ [20, 30]` 中任一日均线"满足"，总分不低于 60，保留到本轮结束。
- 不加分、只展示：整理期缩量、波动收窄、整理低点抬高。

### 3.6 首板观察池排序（每日收盘）
1. 优先级一：按确定日早者在前，同日按 `VR` 高者在前；
2. 优先级二：同上；
3. 普通观察级与确认中：按总分降序；同分按 `T*` 早者在前（未启动视为最晚）；再同分按 `VR` 高者在前；再同分按代码升序。

已启动股票留在首板观察池列表，直到确认失败（3.4）或被移出主升浪池（第 5 节）。

## 4. 主升浪阶段池（入池）
- 来源：二板（`E = F+1, B = C_F`）或首板观察池启动（`E = T*, B = P*`）。
- 入池前发生的 MA10 跌破不计数。

## 5. 主升浪阶段池（评分、排序与移出）

### 5.1 分数（每日收盘）
- `Hmax(t) = max(C_j, E ≤ j ≤ t)`；涨幅 `g = Hmax / B − 1`。
- 涨幅基础分：`g < 15%` 80；`15% ≤ g ≤ 25%` 100；`g > 25%`：`90 − 10 × (ceil((g − 25%) / 5%) − 1)`，最低 0。即 `(25%,30%]` 90、`(30%,35%]` 80……`(70%,75%]` 0。
- 回撤 `d = (Hmax − C_t) / Hmax`；扣分 `10 × floor(d / 3%)`。
- 分数 `= max(0, 基础分 − 扣分)`。0 分仍留池。

### 5.2 排序
分数降序；同分 `E` 晚者在前；再同分代码升序。二板不单独置顶。

### 5.3 MA10 跌破与移出
- 跌破事件：`t > E` 且 `C_t < MA10_t`，并且这是入池后的第一次，或上一次事件之后出现过 `C > MA10`（严格高于）的日子。连续多日低于 MA10 只算一次。
- 计数 `n` 入池后只增不减，不因创新高清零。
- 第 1、2 次事件：观察 `t+1 … t+3`，任一天 `C > MA10` 即修复；都未修复则第 3 个观察日收盘后移出。
- 第 3 次事件：当日收盘后立即移出。
- 停牌日占用观察日。移出只按本节规则，与分数无关。

## 6. 输出

- **事件表**：每条记录含 `code, round_id, date, event, values`。事件包括：首板、二板、入首板池、启动、优先级一/二确定、普通观察级、确认失败移出、支撑跌破/收复/最终破位（S1/S2）、到期移出、入主升浪池、MA10 跌破（第 n 次）、MA10 修复、主升浪移出。
- **每日快照**：首板观察池（状态、优先级、各分项与总分、k、`Hb`、两条支撑状态）与主升浪池（`B`、`Hmax`、`g`、`d`、基础分、扣分、分数、MA10 计数与观察状态）。
- **K 线标注**：首板日、黄金坑低点、两条支撑线、突破线与 `P*`、MA5/10/20、MA10 事件。
