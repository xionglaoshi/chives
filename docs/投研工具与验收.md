## 研究任务与工具

| 研究任务 | Chives 的实际入口 | 谁用、返回什么 |
|---|---|---|
| Qlib 因子库、复权日线 | `factor_catalog`、`factor_values`、`price_history` | 主升浪、个股分析师可查 154 个因子。目录可分页；计算可一次指定多个因子，返回实际行情日、复权、单位、公式、最短历史和缺值原因。日线先查 Chives 本地库，覆盖不足走 cn_market。 |
| 自选组合、全市场条件选股 | `screen_stocks` | 投资专家等按价格、涨跌幅、换手、量比、市净率和市盈率过滤。指定组合逐只给判断；全市场给覆盖、匹配和不确定数。动态 PE 用行情日已披露的最近完整季度累计基本 EPS 年化，与网关的滚动 PE 分列。 |
| 双均线回测 | `ma_backtest` | 返回实际成交日、股数、开盘成交价、费用、逐日净值与回撤。使用未复权日线、整百股、统一费率，跳过一字线。用于策略基准对照。 |
| 公司画像、财务、公告、机构预测、同比与多维评价 | 现有 `cn_market`、`cn_research`；新增 `equity_review`、`special_financials`、`research_snapshot` | 个股分析师可生成公共数据快照，比较同期收入和现金利润比，读回质量、成长、风险六项检查的字段与原值。商誉、应收票据、合同资产、减值等分表列报告期和披露日。 |
| 研报原文与观点 | `research_report_lookup`、`evidence_page` | 研究员逐篇尝试原件，列发表日、机构、原件可读状态、目录所载财年预测和单独的市场一致预期。可按 PDF 物理页读取文字。 |
| 公告发现、账龄、回款、专项报告 | `filing_evidence`、`cash_quality`、`research_snapshot`、`evidence_page` | 个股分析师取证，报告员沿同一 SHA 复核。保留原件、检索窗口、来源与缺页。分开合并与母公司、原值与净额、累计与单季、项目实收与审计抽查。 |
| 比率、EPS×PE、FCFF | `financial_ratio`、`valuation_scenarios`、`discounted_cashflow` | 个股分析师与投资专家可复算分子、分母、逐年现金流、终值、净债务和每股结果。PE 需要正盈利，DCF 的折现率须高于永续增长率。 |
| 基金榜单、季度明细、交集与增减 | `fund_ranking`、`fund_holdings`、`fund_study_job`、`fund_holdings_changes` | 研究员可启动后台研究，按任务状态查快照，再按股票或分页查股数差、权重差和共同持有份额。同日同参数重用已完成任务，排名及明细存证。 |
| 盯盘、自选、定时、档案 | 既有 cn_watch 的 `price_cross`、自选列表、Chives routines、profile 和 Bot 记忆 | 阈值重新武装、消息去重、关注理由、历史问题和私人研究沿现有链路。研究快照编号可与私人记录关联。 |
| 成交登记和持仓 | 私有 portfolio 的 `portfolio_record_trade`、`portfolio_trade_history`；原持仓、现金、估值和导入工具 | 投资专家先预览，用户确认后按 UUID 登记，成交与余额同文件、同锁、原子落盘；重复录入不增加股数，冲突和超卖返回错误。历史成交从相应期初持仓按时间顺序导入。 |
| 报告、证据与历史查询 | `save_report`、Bot 工作区、任务时间线、`research_snapshot` | 报告员用相同证据生成私人交付物。归档 PDF 在本机和经身份验证的公网入口可打开。 |

新增「因子与回测复核」「基金披露持仓研究」，扩充财报分析、估值、研究规范、报告、盯盘、持仓诊断六项已有技能。[因子方法](../skills/factor-research/SKILL.md) · [基金方法](../skills/fund-disclosures/SKILL.md)

## 本机验收

- 华维设计与凌志软件使用 2026-11-18 冻结的原始公告 PDF，从文本重新取数。华维的三季累计现金利润比为 3.74，问询回复第 39 页的 316 万元归属特定项目；凌志为 7.69，审计抽查没有提供可确认的实收金额。两家半年报的应收原值、减值、净额与三年以上分档和均通过勾稽。已用 dsh、Pydantic AI 真模型查证，报告员读取输入快照并生成带出处的 Markdown。
- 对皖通科技和贵州茅台用 2026-11-19 的线上公告目录盲测。两家公司均能提取三季合并现金流。皖通的账龄表未通过自动勾稽；茅台提取到可勾稽的账龄。两家公司这批材料中都未提取到可确认的期后实收金额。华维另有一份扫描件缺文字层。这些情况在交付中列为证据缺口。本机的复核结果随研究快照留存
- 154 个因子分别跑过上升、下降、平价、零成交和短历史输入。人工复核了 MA5 的方向和数值。真实 Bot 用 dsh、Claude Code、Codex、Hermes、Pydantic AI 分别查询华维 2026-11-18 的 MA5，返回 0.9115062761505325。全库数值可运行，其他因子的经济解释、预测能力与样本外收益仍需逐项研究。
- 实际用凌志软件跑出 250 根日线的回测并读取券商研报 PDF 及预测财年。全市场动态 PE 筛选一次覆盖 5,938 个代码，其中 1,864 个缺少可用输入。研究问题和决策仍需结合披露时点和缺项。
- 刷新近一年股票型基金份额前 100，保存当天排名及 100 份持仓查询结果。得到 277 个股票代码、753 条两期可比记录，016352 的返回表无披露行。排名截至 2026-11-19，并非历史时点可知的排名。增减未校正送转，各份额分别计算。冻结快照为 `bb42ae76df6c4b1c9939d1d47b633d8e`；旧快照 758 条可比记录仍可单独查询。
- 本机与登录后的公网均核对 Bot 授权，并取回与本地 SHA-256 一致的 PDF。未登录访问该原件返回 401。持仓幂等、超卖及冲突在临时账本中验证。

## 重建与复验

Chives 安装脚本会把 `packages/equity-evidence` 和其余本地包一并装进公共 Python 环境。PDF 文本抽取需 Poppler。公开原件位于 `data/equity-research/documents/`，存档清单、原值和基金快照同在 `data/equity-research/`。敏感问题、报告与个人持仓按原工作台权限保存。服务使用当前工作台端口。公网入口供偶尔查看和展示，投研数据、公告归档、私人报告和备份均落在 Mac。文件上传不属于公网使用场景。

```bash
cd /Users/xiong/.chives
bash scripts/install-chives.sh
~/.agents/venvs/chives/bin/python packages/equity-evidence/import_public_snapshot.py "/path/to/research-backup.tar.gz"
~/.agents/venvs/chives/bin/python -m pytest -q packages/equity-evidence/tests packages/portfolio-mcp/tests/test_trade_registration.py
```

历史导入器仅提取公开报告的发现信息、按哈希校验的 PDF 和基金公开数据。完整恢复以本次验收备份中的公开研究库为准。[持仓工具](../packages/portfolio-mcp/src/portfolio_mcp/server.py)
