# 问AI预设提示词规范

[配置文件](../config/ask-ai-prompts.json)保存每个按钮实际带入对话草稿的完整提示词。按页面和数据分支维护。按钮从配置读取正文，用当前页面数据替换变量，并附上与页面选项一致的快照。点击只准备草稿。

## 固定五段

每段以标题和全角冒号开头，按下列顺序排列，段间留一个空行。

| 段落 | 写法 |
| --- | --- |
| 这是什么 | 说明附件对应的页面或榜单，以及数据范围、排序、单位或报告类型。条数和可变口径取当前快照。 |
| 入榜意味着什么 | 解释数据支持的观察。非榜单也使用这个标题，说明被列出的指数、新闻、持仓或报告结论有何含义。 |
| 要读哪些文件 | 先列本次附件，再点名与问题相关且获授权的文件和会话。列出路径和需读的字段或范围。 |
| 重点回答哪些问题 | 按顺序列出具体问题，写清要比较什么、输出多少条以及需要什么依据和观察条件。 |
| 不要做什么 | 先写该模板特有的限制，再使用下方统一结尾。 |

统一结尾如下。

> 直接回答本按钮列出的问题。不要质疑或审计数据版本、采集过程、时滞或来源质量，不要自行扩大范围。依据不足时略过对应判断，继续回答其余问题。只在对话中简洁回答。

## 文件权限和数据边界

- 个人分析按需读取 `recent-memory.md`、`user-index.md`、`attributes/values.json`、当前 Bot 的相关近期会话，以及获授权的持仓工具。个人风格评估按章节补读 `profile/investor.json` 的相关问卷原答。区分真实持仓、模拟持仓和关注标的。
- 示例报告只读本次附件，称分析对象为「示例答题者」。此分支也要写完整五段。
- 隐藏金额分支仅使用持仓身份和允许的公开行情。持股数、成本、市值、仓位和金额贡献保持隐藏，禁止反推。
- 排名、涨跌、成交额和成交量各写各的含义。尤其要说明跌停不足 20 只时，按跌幅排列的榜单可能包含未跌停股票。数据无法支撑具体归因时保留未知。

## 新增与验收

1. 在配置中新增五段模板。条件分支分别检查。港股、美股这类共享口径可以共用模板并填入市场名称。
2. 可变字段使用 `{{变量名}}`，在按钮调用处用 `fillAskPrompt` 提供真实条数、顺序或市场名称。同时核对附件列名、单位及选择状态。
3. 执行 `pnpm --filter @chives/web test`。格式回归会检查整份配置的段落及统一结尾。
4. 在 PC 和手机宽度点击新增按钮，检查草稿全文、变量替换、分支和附件。验收草稿时保持在发送前。
