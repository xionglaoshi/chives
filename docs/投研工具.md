# Chives 投研工具

从[所有 Bot](http://127.0.0.1:8888/#/bots)打开已创建的 Bot 档案，展开「技能、工具与 Bot 指令」。勾选工具并保存，下次任务按这位 Bot 的权限执行。工具由 dsh 按 Bot 权限挂载的 `bot_assets` MCP 提供。现有明确保存的权限清单继续有效，Bot 新增授权可在档案中调整。[注册清单](../config/equity-tools.json) · [计算实现](../packages/equity-evidence/src/equity_evidence)

## 研究任务与工具

| 研究任务 | Chives 的实际入口 | 谁用、返回什么 |
|---|---|---|
| 量价因子查询、复权日线 | `factor_catalog`、`factor_values`、`price_history` | 主升浪、个股分析师可查 154 个因子。目录可分页；计算可一次指定多个因子，返回实际行情日、复权、单位、公式、最短历史和缺值原因。日线先查 Chives 本地库，覆盖不足走 cn_market。 |
| 自选组合、全市场条件选股 | `screen_stocks` | 投资专家等按价格、涨跌幅、换手、量比、市净率和市盈率过滤。指定组合逐只给判断；全市场给覆盖、匹配和不确定数。动态 PE 用行情日已披露的最近完整季度累计基本 EPS 年化，与网关的滚动 PE 分列。 |
| 双均线回测 | `ma_backtest` | 返回实际成交日、股数、开盘成交价、费用、逐日净值与回撤。使用未复权日线、整百股、统一费率，跳过一字线。用于策略基准对照。 |
| 公司画像、财务、公告、机构预测、同比与多维评价 | 现有 `cn_market`、`cn_research`；新增 `equity_review`、`special_financials`、`research_snapshot` | 个股分析师可生成公共数据快照，比较同期收入和现金利润比，读回质量、成长、风险六项检查的字段与原值。商誉、应收票据、合同资产、减值等分表列报告期和披露日。 |
| 研报原文与观点 | `research_report_lookup`、`evidence_page` | 研究员逐篇尝试原件，列发表日、机构、原件可读状态、目录所载财年预测和单独的市场一致预期。可按 PDF 物理页读取文字。 |
| 公告发现、账龄、回款、专项报告 | `filing_evidence`、`cash_quality`、`research_snapshot`、`evidence_page` | 个股分析师取证，报告员沿同一 SHA 复核。保留原件、检索窗口、来源与缺页。分开合并与母公司、原值与净额、累计与单季、项目实收与审计抽查。 |
| 比率、EPS×PE、FCFF | `financial_ratio`、`valuation_scenarios`、`discounted_cashflow` | 个股分析师与投资专家可复算分子、分母、逐年现金流、终值、净债务和每股结果。PE 需要正盈利，DCF 的折现率须高于永续增长率。 |
| 基金榜单、季度明细、交集与增减 | `fund_ranking`、`fund_holdings`、`fund_study_job`、`fund_holdings_changes` | 研究员可启动后台研究，按任务状态查快照，再按股票或分页查股数差、权重差和共同持有份额。同日同参数重用已完成任务，排名及明细存证。 |
| 盯盘、自选、定时、档案 | 既有 cn_watch 的 `price_cross`、自选列表、Chives routines、profile 和 Bot 记忆 | 阈值重新武装、消息去重、关注理由、历史问题和私人研究沿现有链路。研究快照编号可与私人记录关联。 |
| 成交登记和持仓 | 私有 portfolio 的 `portfolio_record_trade`、`portfolio_trade_history`；原持仓、现金、估值和导入工具 | 投资专家先预览，用户确认后按 UUID 登记，成交与余额同文件、同锁、原子落盘；重复录入不增加股数，冲突和超卖返回错误。历史成交从相应期初持仓按时间顺序导入。 |
| 报告、证据与历史查询 | `save_report`、Bot 工作区、任务时间线、`research_snapshot` | 报告员用相同证据生成私人交付物。归档 PDF 在本机和经身份验证的公网入口可打开。 |

## A 股个股估值测算器

测算时将已取得的公开财报版本按证券、内容和首次采集日期保存在 `data/equity-research/market/valuation-financial-vintages.sqlite`。供应商日后替换报表时，回放可以找回当时留存的版本。首次采集之前的历史日期仍依赖有披露日和修订日的公开数据。

总经理在对话、用户关注的「重新评估」和涉及合理价的筛选中调用 `estimate_equity_value(code, as_of)`。默认北京时间当天；16 时前使用上一日或更早的已收盘数据。公开结果按证券、请求日期和内容哈希保存在 `data/equity-research/valuations/`，`input_snapshot` 对应 `data/equity-research/snapshots/` 的原始输入和入选同行。服务器根据本次证券、请求日期和哈希读回价格，用户关注只保存摘要、版本和编号。老记录可继续查看。用户持仓的「合理估值」读取同一测算工具的最新有效回执，缺少回执时可点击「测算」，无需先加入用户关注。[实现](../packages/equity-evidence/src/equity_evidence/valuation.py) · [估值 Skill](../skills/valuation-model/SKILL.md)

盈利企业以最近四季归母与扣非净利中的较低值除当期股本。银行以财报每股净资产估 PB，重资产周期行业以跨周期利润率选择 PB 同行。中性样本采用近五年上证综指、深证成指过去 60 个交易日涨跌均在 10% 以内、最接近横盘的至多 18 个月末。各月排除目标股，同行充足时按盈利对净资产的回报就近选样。每月算低、中、高三个分位，再分别取跨月中位数。归母或扣非滚动利润为零或负的非金融企业，采用每股营收乘以同行市销率估值。按净利率匹配，亏损同行充足时优先选择亏损同行，并标为有限信心。盈利企业同时计算可比市销率区间；两种方法的区间不重合时，披露方法分歧。同行样本或原始财报不足时返回具体原因。[行业与个股估值数据](https://data.eastmoney.com/gzfx/) · [财报数据](https://data.eastmoney.com/bbsj/)

20 日动态模型观察沪深趋势、融资净买入占流通市值，以及同机构近 45 日个股评级升降。融资和研报至少滞后一个自然日使用。评级只代表卖方观点，政策及新闻尚未纳入。具备历史数据时，可用 Chives Python 运行 `python -m equity_evidence.valuation_replay 600919.SH --start 2018-01-01 --through YYYY-MM-DD`，日期替换为已结束的交易日。隔离回放可设置 `CHIVES_RESEARCH_LIBRARY` 指向测试目录。每份回执记录可用月数、缺口、因子检验与留出表现；训练标签须在预测前结束。只有通过跨年滚动检验和独立的最后 18 个月验证，且胜过静态和收盘价基准的股票模型才能调整价格。有效期一年，从验收截止日次日开始匹配；没有合格模型就标注「静态参考」。[回放入口](../packages/equity-evidence/src/equity_evidence/valuation_replay.py) · [校准与验收](../packages/equity-evidence/src/equity_evidence/valuation_calibration.py)

20 日方向与估值区间分别验证。工具按个股过去 20、60 日走势、相对宽基表现和历史 PB 分位，与已走完的非重叠窗口对照。对比基准是该股截至判断日历史最常见方向。已完成的窗口提供每只股票的基准倾向，完全没有已结束窗口时才给一级趋势观察。组合信号单独保留候选结果，本版跨证券检验未验证增益。涨跌以随后 20 个交易日除权口径收盘中位数相对当日超过 ±2% 为界。返回方向、强度、历史命中数、基准和信心限制。用户关注凭同一编号读回价格和方向。[方向算法与逐期回放](../packages/equity-evidence/src/equity_evidence/valuation_direction.py)

### 用历史股票池验证预测

可用 `python -m equity_evidence.valuation_cohort --pool 历史样本快照 --out 测试结果目录 --split 2025-01-01 --through 2026-11-23 --showcase 2026-05-28` 离线回放。每个预测日读取当日沪深 300 的完整成分，对照未来 20 日、120 日的交易记录。示例日单独报告。训练只纳入结果在分界日前已经走完的观察，留出期固定参数。逐股证据写入 `observations.json`，按期限、日期、参照方法汇总至 `metrics.json`。

样本快照按交易日保存成分和全市场估值截面，按证券保存历史价格、财报及交易状态，并包含双宽基交易日历。先核对快照的 SHA-256 清单，再把同一份只读原始数据交给不同的工具。每次实验指定自己的输出目录。生产方向、生产静态估值、研究候选和现价基准分别计分，报告同时给出预测覆盖、方向命中、区间宽度、区间覆盖及中点误差。[离线回放入口](../packages/equity-evidence/src/equity_evidence/valuation_cohort.py)

后续筛选、量价、风险及财务类工具共用同一批次的公共样本。开发前在工作区公共样本库的 `catalog.json` 查日期、证券及字段覆盖，再到版本内的 `manifest.json` 找分区。缺少的字段或日期单独补采，新版本保留来源及 SHA-256；原始快照和各工具的预测输出分别保存。

新测算按最终报价校验上限比下限高不到 20%。同行中央 50% 区间过宽时，用同行中央 30% 情景重算，仍过宽则返回「依据不足」。已有校准的动态估值同样校验宽度。
