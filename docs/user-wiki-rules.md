# Chives 用户记忆写入规则

只记录本人和研究对象的关系。用户问过什么、委托核实什么、当时怎样判断、自己说做过什么，分别注明说话人、日期和原消息编号。用户的投资计划、Bot 的建议、已经执行的成交要分开。持仓、成交和公司公告按相应正本核对。

同一主题沿用同一页。自动更新只能追加有原句支持的新事件，不覆盖手工记录。没有值得长期保存的内容时跳过。短期摘要只保留仍有用的关注、本人表达的状态和未完事项。先前提过卖出、后来没有回复时，可以记下这个断点，不能据此登记已成交。

后台复盘只处理启用用户资料和记忆写入后的本人直接会话。受托任务、模拟例子、凭据、联系方式、账户号码及与研究无关的私事跳过。对能力或偏好的新判断须向属性审核台账提案。任务开始时只读取已发布且获授权的两份摘要。
