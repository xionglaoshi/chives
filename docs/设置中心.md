# Chives 设置中心

在 Mac 打开[设置](http://127.0.0.1:8888/#/settings)。左栏可搜索设置名称、分组和说明，右栏显示选中项目。每一页都有独立地址，例如[模型设置](http://127.0.0.1:8888/#/settings?tab=models)。私有设置在本机管理。

| 分区 | 可以设置什么 | 生效方式 |
|---|---|---|
| 用户资料 | 名称、头像、邮箱、电话 | 点击保存后留在本机。头像会裁成方形。 |
| 风格评估 | 百题问卷、风险承受能力、风格解读与投资人物卡 | 独立百题问卷逐题自动保存，支持自述、资料摘录和重新评测。五个 Bot 在每轮任务中读取最新画像。 |
| 用户数据 | Bot 记忆、研究过的股票、问过的问题 | 读取实际研究索引，问题和证券分别显示最近 100 项。尚未开展研究时显示空记录。 |
| 消息权限 | 主动消息开关、浏览器及系统通知、重要程度 | 浏览器通知需要当前浏览器授权。系统通知由 Mac 投递。定时任务仍按各自交易日规则运行。 |
| 通讯频道 | 微信、企业微信、飞书、Telegram、Slack、Discord | 前四者可扫码。Slack、Discord 当前用应用机器人 Token 接入。微信首次先扫码。手动配置会校验身份，投递还需要正确的接收会话和权限。保存目标、启用频道并允许主动消息后，符合级别的后台提醒才会投递；可查看最近的投递结果。 |
| 外观设置 | 语言、显示时区、疏密、字号、主题、涨跌配色 | 语言影响设置导航、Bot 回答和时间格式，部分控件与工作台业务文案仍为中文。显示时区作用于聊天时刻，行情交易日使用交易所时区。 |
| 对话细节 | 内核公开的实时推理摘要、工具步骤、忙时的新消息 | 排队会在当前轮次结束后继续；优先引导会结束本轮，将追问放在队首。待处理消息保存到本机，同一 Bot 最多排 32 条。 |

| 任务管理 | 定时任务总开关、单项开关、Bot 档案和执行时间 | [Agent 设置 → 任务管理](http://127.0.0.1:8888/#/settings?tab=tasks)集中展示 Bot、定时任务和执行时间。右侧可逐项或一键全部启停；关闭后仍在列表中，方便重新开启。「高级」中的观察模式暂停自动分析和定时运行。 |
| 内核设置 | 显示 dsh 的运行版本与候选更新 | 本机点击检查更新后，可保持当前版本或手动升级；公网仅展示版本。 |
| 模型设置 | 添加、验证、管理模型连接 | 用户可选择全局默认模型，也可在 Bot 档案指定独立连接。 |
| 技术文档 | 常见问题 | 在页首输入关键词可同时搜索问题和答案，点击问题展开，清空搜索可查看全部。 |
| 备份及导入 | 个人资料、画像、持仓文件、外观及消息偏好、Bot 配置与记忆 | 下载 JSON，再在目标 Mac 选择文件并确认，按同名项合并。导入前自动保存本机当前配置。模型密钥与频道凭证需单独授权。聊天、任务和交付索引有单独的研究记录导出。 |

### 调整模型、思考强度和速度

在「模型设置」找到连接，点「编辑」。选择 GPT 模型后，「思考强度」列出订阅和当前内核都能使用的档位。选「跟随模型」可交给服务端决定。支持优先处理的订阅模型还有独立的「处理速度」选项。快速模式可能消耗更多额度。终端启动台的「思考强度与速度」读写同一条连接。启用了 DeepSeek 思考协议的手动连接可选择高或最高强度。

点「保存模型」，使用这条连接的 Bot 从下一轮开始采用新设置，原会话可以继续追问。已经开始的回答会先完成。「验证订阅连接」会发送一次短请求。要核对 Bot 的真实调用，向它提问后回到模型设置，点「刷新实际调用记录」。每个 Bot 只保留最近一次 Codex 请求的时间、请求参数和服务端回报。即使选择了快速，服务端也可能按标准档处理。

[工作台 · 用户持仓](http://127.0.0.1:8888/#/workspace/holdings)可管理 A 股股票与场内基金。持仓成本合计按数量乘以单位成本逐项相加。个人备份收录同一份本地 JSON 账本 `data/profile/finance-portfolio.json`。

每轮 Bot 任务读取 `data/profile/USER.md` 的身份标签、情境偏好及文件地图。账户资料及权限在 `account-settings.json`，外观、通知和侧栏顺序分别在 `appearance.json`、`notifications.json`、`sidebar-order.json`。早期手动投资档案在 `finance-profile.json`，内核会话与各 Bot 私有记忆按原权限保管。正式评测、确认的会话更正和恢复备份后从 `investor.json` 重建此摘要；问卷区间和历史资产比例属于自报口径，实际持仓以持仓账本为准。

### 如何读风格报告

「综合解读」先列风险承受能力与投资风格，展开风险等级可查看中基协指引。接下来的两至三段解释资金安排、风险取舍和投资方法。五类风格为无明确风格、激进型、平衡型、稳健型、极度保守型。模型结合目标、亏损接受度、资金条件和补充资料判断，规则见[评价依据](../presets/style-assessment/评价依据.md)。资金用途、生活开支或能接受的亏损变化时，选「重新评测」。上传脱敏成交记录可以让模型对照自述与实际操作。旧版评估保留在原位置，重新作答后生成新版报告。初次打开可阅读标有「虚构答卷」的示例。

「您像谁」收录 27 位投资人物，包括段永平。头像为 288 × 288 的本地 JPEG，卡片等比显示为 88 × 88。每张保留图片出处、署名与裁剪说明。登录公网工作台后也可查看同一批 27 张头像。有方法依据时，模型用约百字说明您的风格融合了哪三位人物的特点，并结合一次具体选择，写出您的长处与潜力。下方逐人解释相似之处。资料不足时提示可补充的经历。「综合解读」用「您」直接解释回答与判断的关系。「您像谁」可点击人物全名查看百度百科。「风格解读」逐项展示解释和量表位置。位置图的横轴表示波动接受度，纵轴表示可用资金的回旋余地。「上涨时买，还是跌下来再买」使用 2016 年深交所受访样本，选择仅用于本页对照。[原始调查](https://www.szse.cn/aboutus/trends/news/t20170316_518921.html)

人群分位读取 `presets/style-assessment/norms.json` 中与题版和作答范围一致的匿名汇总。当前目录为空。引入样本时需注明受访群体、期间、公开来源及该维度 0–100 整数分布的 101 个频数；至少 100 条有效观察才计算同分中位排名。没有匹配样本时仅展示量表位置。

## 安装和恢复

### 为 Bot 接入第三方 MCP

在 [Agent 设置 → 能力管理](http://127.0.0.1:8888/#/settings?tab=capabilities) 中，打开「MCP 市场」，选择服务并填写供应商密钥。首批预设为 [Alpha Vantage](https://github.com/alphavantage/alpha_vantage_mcp) 和 [Context7](https://github.com/upstash/context7)。Alpha Vantage 目前使用供应商兼容的 API Key 接入方式。供应商的套餐决定可用数据和额度。

在本机也可点「手动添加」，填写远程地址与可选 Bearer Token，或粘贴供应商的单项 MCP JSON。JSON 支持 HTTP 的 `url`、`headers`，SSE 的 `type: "sse"`，以及 stdio 的 `command`、`args`、`env`。填写可执行命令前请核对发布者，测试连接会在 Mac 启动该程序。验证并保存会实际完成握手、读取工具清单。需浏览器 OAuth 的服务尚待接入。

在「已添加」核对工具，打开目标 Bot 档案，在「技能、工具与 Bot 指令 → MCP 服务」中勾选并保存。停用会阻止新的工具调用，已发出的请求可能完成。第三方连接及密钥存于本机 `data/secrets/mcp-connections.json`，文件权限为 0600。更换 Mac 时需另行安全迁移此文件以保留原授权标识，或重新添加服务并授权。

「官方内置」展示随 Chives 发布的服务。在受管部署中设置 `CHIVES_MCP_POLICY=approved` 后重启，用户只能接入认可目录内固定地址的第三方服务。本版本的连接属于本地单用户，云端多租户隔离列入后续开发。

运行环境在公共区。使用[安装脚本](../scripts/install-chives.sh)准备工作台和独立通讯适配器。dsh 版本、更新和恢复步骤见[Bot 配置](专家内核与配置.md)。

在项目目录执行 `./start start` 启动，执行 `./start restart` 使程序更新生效。配置和研究数据在 `data/`，模型及通讯密钥位于 `data/secrets/`，恢复前的个性化副本在 `data/personal-backups/`。数据库、资金记录及凭证留在本机。恢复到新 Mac 时，应先准备同一版本的程序和相应 Bot，再导入其个性化数据。

## 风格评估与 Bot 的使用方式

进入「用户信息 → 风格评估」，选择「开始评测」。先选本次填写个人资产还是家庭共同资产。资产表从「其他」的 100 点分配，各类金额只填区间。题下说明解释每一题会影响哪种判断。每次选择、输入和翻页都会自动写入本机的 `data/profile/interview-draft.json`，显示「已保存到本机」后可关页。再次打开会回到上次的题目，正式提交后的重测会带出上次答案。首次评测前看到的是虚构答卷的示例。

第 100 题之后可留下自述并上传补充资料。提交时，答卷、自述、已确认的资料摘录和评价依据一起送给当前模型。问卷计算资金条件、风险意愿与风格卡的证据状态，模型负责解读。完整报告可展示三位投资人物各自与您相近的做法、鼓励语和人物简介。全部 32 张风格卡直接展示，精选最多八张在前。每张卡用同款连续圆点条标示倾向，证据不足时居中标注「中性位置」。买入习惯以文字附上深交所 2016 年受访者的回答比例。[调查原文](https://investor.szse.cn/institute/bookshelf/report/P020180703407851145112.pdf)答卷不足以支持的结论会留待补充。[问卷题库](../presets/style-assessment/interview100.json) · [评价依据](../presets/style-assessment/评价依据.md) · [卡片定义](../presets/style-assessment/cards.json)

正式画像保存在 `data/profile/investor.json`，记录本次统计范围、答卷、资料、参数、风险档、卡片状态、模型解读和确认过的更正。评估结果通过格式和来源校验后一次写入，页面直接读取已保存的版本。五位 Bot 在每轮对话或任务中使用最新摘要，也可按编号调取风格卡及对应工作建议。

在对话里可以直接说「更新我的画像：今后新增资金，我首选宽基指数基金」。如果只是说起一个与评测不同的习惯，Bot 会先核对这是长期变化还是单次安排。可以继续回答澄清问题，也可以明确确认更正。重新打开评估页即可核对结果。

「投资人物卡」为可扩充的本地目录，现有 27 人。新增人物时添加稳定 ID、风格特征、简介、百科链接和相应的本地头像资料。评测从目录读取候选人。[投资人物卡](../presets/investor-styles/catalog.json)
