# Chives 安装分发维护

本机 /Users/xiong/.chives/deploy/installer 是安装分发源码正本。150.158.11.154 的 /opt/chives-install 用于运行部署。2026-11-20 已将服务器现行的九个文件，包括依赖镜像模块和服务配置，同步到本机并核对 SHA-256。

以后在本机编辑并检查差异、语法及受影响的平台。部署前备份服务器对应文件，部署后核对文件哈希。若修改 systemd 或 Caddy，先验证配置，再按改动重新加载或重启相应服务。最后核对公网状态、脚本下载、授权访问和匿名拒绝。有 Windows 安装改动时另做原生主机验收。

部署只传源码和服务模板。安装码、密钥、缓存、启停状态及运行日志留在各自运行目录。Chives 公开仓库按熊翔明确的 GitHub 同步指令更新。

分发包在本机服务启动成功后，由当前 release 的 Python 执行 `scripts/chives_cli.py release --register`。命令指向该 release 的独立环境。更新安装器时需同时发布包含注册脚本的 GitHub 源码和云端 `install.py`，先推源码再切换分发脚本。

安装服务打包整个 `skills/` 目录，技能单项更新也包含这个目录。组件声明随各自的文件分发。[随附组件许可](../../skills/NOTICE.md)

发布此次清单变更时，先更新分发服务器的 `server.py`，再发布移除根目录旧索引的源码。新打包清单已分别使用两种源码布局验证。
